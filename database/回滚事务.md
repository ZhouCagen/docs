<mark>✅ 事务基础   </mark> 

SQL Server 里的事务语法只有三句：

```
BEGIN TRANSACTION;   -- 开启事务
COMMIT TRANSACTION;  -- 提交事务（生效）
ROLLBACK TRANSACTION;-- 回滚事务（取消）
```

简称：  
BEGIN = 开始  
COMMIT = 生效  
ROLLBACK = 取消

<mark>✅ 事务模板</mark>  

```
BEGIN TRANSACTION;

    -- 这里写你的 SQL 操作
    INSERT ...
    UPDATE ...
    DELETE ...

IF (成功)
    COMMIT TRANSACTION;
ELSE
    ROLLBACK TRANSACTION;
```
   
<mark>✅ROLLBACK TRANSACTION 的作用</mark>

把本次事务中的所有修改全部撤销，数据库恢复到事务开始前的状态。  
包括：  
插入的行全部取消（不会进入表）  
更新的行恢复为旧值  
删除的行恢复回来  

<mark>✅ 触发器中的 ROLLBACK </mark>

```
ROLLBACK TRANSACTION; 
```
成功回滚原因：SQL Server 在执行 INSERT / UPDATE / DELETE 时自动开启一个“隐式事务”。  
也就是说，当你执行：  
INSERT INTO S VALUES (...);  
SQL Server 实际流程是：  
BEGIN TRAN （系统自动）  
│  
├─ 写入 inserted 临时表  
│
├─ 执行触发器 tri_Insert_S  
│   │    
│   ├─ 如果触发器执行 ROLLBACK TRAN → 整个插入被取消  
│   └─ 否则继续   
└─ COMMIT TRAN（系统自动）  

所以你在触发器里写：  
ROLLBACK TRANSACTION;  
就能把这个自动事务“整单退掉”，该插入不会进入表中。

<mark>✅ ROLLBACK 的几种写法</mark>

1. 最常见写法（你现在用的）

```
ROLLBACK TRANSACTION;
```
2. 带事务名（一般不用）
2
```
BEGIN TRAN MyTran;
ROLLBACK TRAN MyTran;
```
3. 回滚到保存点（高级用法）

```
BEGIN TRAN;
SAVE TRAN SavePoint1;
-- 一些操作…
ROLLBACK TRANSACTION SavePoint1;
COMMIT TRAN;
```
