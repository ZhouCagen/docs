一、DML 触发器（针对表：INSERT / UPDATE / DELETE）

<mark>⭐1. 最基本语法模板（AFTER / FOR）</mark>  
```
CREATE TRIGGER 触发器名
ON 表名
AFTER INSERT, DELETE, UPDATE   -- 或者写 FOR INSERT, UPDATE
AS
BEGIN
    SET NOCOUNT ON;

    -- 在这里写逻辑
    -- 可以访问 inserted / deleted 两张“伪表”
END;
GO

```

AFTER / FOR：几乎等价，表示语句执行完成以后触发。  
inserted 表：被插入 / 更新 后的新数据。  
deleted 表：被删除 / 更新 前的旧数据。  

<mark>⭐2. 只针对某一种操作 </mark>
```
-- 只在插入时触发
CREATE TRIGGER trg_Table_Insert
ON 表名
AFTER INSERT
AS
BEGIN
    -- 使用 inserted 做逻辑
END;
GO

-- 只在删除时触发
CREATE TRIGGER trg_Table_Delete
ON 表名
AFTER DELETE
AS
BEGIN
    -- 使用 deleted 做逻辑
END;
GO

-- 只在更新时触发
CREATE TRIGGER trg_Table_Update
ON 表名
AFTER UPDATE
AS
BEGIN
    -- inserted: 新值，deleted: 旧值
END;
GO

```

<mark>⭐3. 多行操作 & inserted / deleted 的用法</mark>  


触发器 一次执行对应一条 DML 语句，而不是一行，所以要把 inserted / deleted 当成表来用：
```

CREATE TRIGGER trg_Log_ScoreChange
ON SC
AFTER UPDATE
AS
BEGIN
    SET NOCOUNT ON;

    -- 例子：找出分数发生变化的记录
    INSERT INTO ScoreChangeLog(Sno, Cno, OldScore, NewScore, ChangeTime)
    SELECT d.Sno, d.Cno, d.Score AS OldScore, i.Score AS NewScore, GETDATE()
    FROM deleted AS d
    JOIN inserted AS i
        ON d.Sno = i.Sno AND d.Cno = i.Cno
    WHERE d.Score <> i.Score;
END;
GO

```

<mark>⭐4. INSTEAD OF 触发器（替代原本操作）</mark>  
```
CREATE TRIGGER trg_Table_InsteadOfDelete
ON 表名
INSTEAD OF DELETE
AS
BEGIN
    SET NOCOUNT ON;

    -- 拦截删除，改为别的行为
    -- deleted 里面是“想要被删”的那批行
END;
GO

```

INSTEAD OF：不会执行原来的 INSERT/UPDATE/DELETE，而是执行你在触发器里写的逻辑。
常用在视图上，或者做“软删除”。

```
注： SET NOCOUNT ON 的作用是阻止 SQL Server 在每条语句执行后返回
“(N 行受影响)”的提示，从而减少网络流量，提高存储过程和触发器
的执行效率。

在存储过程中加入 SET NOCOUNT ON 可以避免返回多余的消息，
使外部应用程序（如 C#）只接收 SELECT 的结果集，避免受到干扰。
```

二、触发器的维护语法（ALTER / DROP / 启用 / 禁用）  

<mark>⭐1. 修改触发器 </mark>
```
ALTER TRIGGER 触发器名
ON 表名
AFTER INSERT, DELETE, UPDATE
AS
BEGIN
    SET NOCOUNT ON;
    -- 新逻辑
END;
GO
```

<mark>⭐2. 删除触发器 </mark>
```
DROP TRIGGER 触发器名;
GO
```

<mark>⭐3. 启用 / 禁用触发器</mark>

```
-- 禁用某个表上的指定触发器
DISABLE TRIGGER 触发器名 ON 表名;
GO

-- 启用
ENABLE TRIGGER 触发器名 ON 表名;
GO

-- 禁用/启用某表上的所有触发器
DISABLE TRIGGER ALL ON 表名;
ENABLE TRIGGER ALL ON 表名;
GO
```

<mark>⭐4. 查看触发器定义（源码）</mark>
```
-- 用系统存储过程
EXEC sp_helptext '触发器名';

-- 或直接查系统视图
SELECT name, object_definition(object_id) AS Definition
FROM sys.triggers
WHERE name = '触发器名';
```

三、DDL 触发器（针对 CREATE / ALTER / DROP 等）  

<mark>⭐1. 数据库级 DDL 触发器</mark>

```
CREATE TRIGGER trg_DDL_Database
ON DATABASE
FOR CREATE_TABLE, ALTER_TABLE, DROP_TABLE
AS
BEGIN
    SET NOCOUNT ON;

    -- EVENTDATA() 返回 XML，里边有操作信息、对象名等
    DECLARE @x XML = EVENTDATA();

    INSERT INTO DDL_Log(EventType, ObjectName, PostTime)
    VALUES (
        @x.value('(/EVENT_INSTANCE/EventType)[1]', 'NVARCHAR(100)'),
        @x.value('(/EVENT_INSTANCE/ObjectName)[1]', 'NVARCHAR(100)'),
        @x.value('(/EVENT_INSTANCE/PostTime)[1]', 'DATETIME')
    );
END;
GO
```

<mark>⭐2. 服务器级 DDL 触发器 </mark>
```
CREATE TRIGGER trg_DDL_Server
ON ALL SERVER
FOR CREATE_LOGIN, ALTER_LOGIN, DROP_LOGIN
AS
BEGIN
    -- 记录或禁止某些操作
END;
GO
```
