<mark>⭐ 1.创建存储过程（Template） </mark>
```
CREATE PROCEDURE 存储过程名  
AS  
BEGIN  
    -- 逻辑  
END;  
GO  
```

示例： 
```  
CREATE PROCEDURE sp_GetAllStudents  
AS  
BEGIN  
    SELECT * FROM Student;  
END;  
GO  
```

<mark>⭐ 2. 修改存储过程（ALTER）  </mark>
```
ALTER PROCEDURE 存储过程名  
AS  
BEGIN  
    -- 新逻辑  
END;  
GO  
```

<mark>⭐ 3. 删除存储过程  </mark>

```
DROP PROCEDURE 存储过程名;  
GO  
```

<mark>⭐ 4. 执行存储过程  </mark>
```
EXEC 存储过程名;  
-- 或  
EXEC 存储过程名 参数1, 参数2;  
```

<mark>⭐ 5. 授予执行存储过程的权限  </mark>

```
GRANT EXECUTE ON 存储过程名 TO 用户名;  

举例：  
GRANT EXECUTE ON sp_GetAllStudents TO  studentUser;  
```

<mark>⭐ 6. 从存储过程中返回数据给应用程序  </mark>

直接用 SELECT 就能返回数据：

```
CREATE PROCEDURE sp_GetActiveStudents  
AS  
BEGIN  
    SELECT StudentId, Name  
    FROM Student  
    WHERE Status = 1;  
END;  
GO  
```

应用程序执行后直接拿到结果。  

<mark>⭐ 7. 重新编译存储过程  </mark>
```
EXEC sp_recompile 存储过程名;
```
<mark>⭐ 8. 重命名存储过程  </mark>
```
EXEC sp_rename '旧名称', '新名称';
```
示例： 
``` 
EXEC sp_rename 'sp_GetAllStudents',  'sp_ListStudents';
```
<mark>⭐ 9. 查看存储过程的定义（源码）  </mark>
```
EXEC sp_helptext 存储过程名;
```
<mark>⭐ 10. 查看存储过程的依赖关系  </mark>
```
查看某个过程依赖了哪些表：  
EXEC sp_depends 存储过程名;
```
<mark>⭐ 11. 在存储过程中使用参数（带输入参数）  </mark>
```
CREATE PROCEDURE sp_FindStudentById  
    @StudentId NVARCHAR(50)  
AS  
BEGIN  
    SELECT *  
    FROM Student  
    WHERE StudentId = @StudentId;  
END;  
GO  
```
<mark>⭐ 12. 带输出参数的存储过程  </mark>
```
CREATE PROCEDURE sp_CountStudents
    @Total INT OUTPUT
AS
BEGIN
    SELECT @Total = COUNT(*)
    FROM Student;
END;
GO
```


调用：
```
DECLARE @cnt INT;
EXEC sp_CountStudents @cnt OUTPUT;
SELECT @cnt AS TotalStudents;
```
<mark>⭐ 13. 带输入 + 输出参数的存储过程  </mark>
```
CREATE PROCEDURE sp_CountStudentsByDept
    @Dept NVARCHAR(50),
    @Total INT OUTPUT
AS
BEGIN
    SELECT @Total = COUNT(*)
    FROM Student
    WHERE Department = @Dept;
END;
GO
```

<mark>⭐ 14. 存储过程模板（带事务）——课程设计必备  </mark>
```
CREATE PROCEDURE sp_选课
    @StudentId NVARCHAR(50),
    @OfferingId INT
AS
BEGIN
    SET NOCOUNT ON;

    BEGIN TRY
        BEGIN TRAN;

        INSERT INTO Enrollment(StudentId, OfferingId)
        VALUES (@StudentId, @OfferingId);

        COMMIT TRAN;
    END TRY
    BEGIN CATCH
        ROLLBACK TRAN;

        THROW;  -- 抛出错误给前端
    END CATCH;
END;
GO
```
