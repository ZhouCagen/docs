# 第二章 正规式与有穷自动机

> 本章整理正规式、DFA、NFA、五元组、文法与状态图转换、子集法、ε 闭包以及带 ε 边的确定化。保留完整例题，重点解释“读一个字符后，到底应该留下哪些状态”。

记号约定：公式采用可直接阅读的文本。`D_0` 中的 `_0` 表示下标；
`P —a→ Q` 表示读 a 后从 P 转到 Q；正规式中的 `∣` 表示或者，`*` 表示重复零次或多次。

## 1. 正规式、正规集和有穷自动机

正规式也叫正则表达式，用简洁的式子描述一类字符串；它描述的语言称为正规集或正规语言。

有穷自动机也叫有限自动机，逐个读取输入字符，通过状态转移判断输入串是否属于某个语言。

- 正规式：描述哪些串符合规则。
- 正规文法：规定这些串如何生成。
- 有穷自动机：检查一个输入串是否符合规则。

**正规式、正规文法、DFA、NFA 在描述语言的能力上等价，都刻画正规语言。** 表达方式和构造大小可以不同。

## 2. 正规式的基本运算

### 2.1 基本含义

| 正规式 | 对应语言或含义 |
| --- | --- |
| `∅` | 空语言，没有任何串 |
| `ε` | `{ε}`，只包含空串 |
| `a` | `{a}` |
| `a ∣ b` | `{a, b}`，选 `a` 或 `b` |
| `ab` | `{ab}`，先 `a` 后 `b` |
| `a*` | `{ε, a, aa, aaa, …}` |
| `(a ∣ b)*` | 所有由 `a`、`b` 组成的有限串，包括空串 |

最基本的三种组合运算：选择、连接、闭包。

### 2.2 选择、连接、闭包

设正规式 `r, s` 描述的语言为 `L(r), L(s)`：

```text
L(r ∣ s) = L(r) ∪ L(s)
```

```text
L(rs) = {xy ∣ x ∈ L(r), y ∈ L(s)}
```

```text
L(r*) = L(r)⁰ ∪ L(r)¹ ∪ L(r)² ∪ …
```

其中 `L(r)ⁿ` 表示从 `L(r)` 中取 n 个串依次连接所得到的全部串；
`L(r)⁰ = {ε}`。

常用扩展记号 `r+` 表示重复一次或多次，可写成 `rr*`。

注意：对字母表 `Σ`，`Σ+` 不包含空串；但对一般正规式 `r`，
若 `r` 本身就能产生空串，重复一次也可能得到空串，因此 `r+` 未必排除空串。

### 2.3 运算优先级

默认优先级：**闭包高于连接，连接高于选择**。括号可以改变结合范围。

- `ab*`：一个 `a` 后接零个或多个 `b`。
- `(ab)*`：整组 `ab` 重复零次或多次。
- `a ∣ bc`：选 `a` 或整个 `bc`。
- `(a ∣ b)c`：先选 `a` 或 `b`，然后接 `c`。

### 2.4 常用等价关系

```text
r ∣ ∅ ≡ r, rε ≡ εr ≡ r
```

```text
r∅ ≡ ∅r ≡ ∅
```

```text
ε* ≡ ε, ∅* ≡ ε
```

这里 `≡` 表示描述相同语言。`∅*` 包含重复零次的结果，因此对应 `{ε}`。

## 3. 正规式怎么读、怎么写

### 3.1 基础例子

设 `Σ = {a, b}`：

| 要描述的串 | 正规式 |
| --- | --- |
| 长度为 2 | `(a ∣ b)(a ∣ b)` |
| 任意多个 `a`，包括空串 | `a*` |
| 任意非空的 `a, b` 串 | `(a ∣ b)+` |
| 以 `a` 开头 | `a(a ∣ b)*` |
| 以 `ab` 结尾 | `(a ∣ b)*ab` |
| 零个或多个 `a`，最后接一个 `b` | `a*b` |

### 3.2 “至少含一处 aa 或 bb”

```text
(a ∣ b)*(aa ∣ bb)(a ∣ b)*
```

拆成三段：

1. 前面任意接 `a, b` 串，可以为空。
2. 中间必须有 `aa` 或 `bb`，不能省略。
3. 后面任意接 `a, b` 串，可以为空。

| 串 | 判断 | 一种分解 |
| --- | --- | --- |
| `aa` | 符合 | `ε · aa · ε` |
| `baab` | 符合 | `b · aa · b` |
| `abbab` | 符合 | `a · bb · ab` |
| `aaa` | 符合 | `ε · aa · a` |
| `abab` | 不符合 | 没有相邻相同字符 |
| `ε` | 不符合 | 中间必需部分缺失 |

**不是恰好两个 `a` 或两个 `b`，而是至少存在一处相邻的 `aa` 或 `bb`。**

### 3.3 从文法中找重复块与结束方式

已知：

```text
S → aA ∣ b, A → bS ∣ a
```

从 `S` 出发：

- `S ⇒ b`：以 `b` 结束。
- `S ⇒ aA ⇒ aa`：以 `aa` 结束。
- `S ⇒ aA ⇒ abS`：增加一组 `ab`，回到 `S`，可继续重复。

因此正规式为：

```text
(ab)*(aa ∣ b)
```

星号只管前面的重复块，后面的 `aa` 或 `b` 必须选一个，因此不能生成空串。

做题步骤：先找可以反复走的部分，再找结束方式，最后按顺序连接起来；用最短串和明显不合法的串检查是否多写或漏写。

## 4. 状态图的基本读法

### 4.1 图上的符号

| 图形 | 意义 |
| --- | --- |
| 单圈 | 普通状态 |
| 双圈 | 接受状态，也叫终态 |
| 外部箭头指向某状态 | 标记初态，外部箭头本身不消耗输入 |
| `P —a→ Q` | 在 `P` 读一个 `a`，转到 `Q` |
| `P —a→ P` | 自环：读一个 `a`，仍在 `P` |

一条边标记 `a, b` 通常是“读 `a` 或读 `b` 都沿此边”，不是一次读取两个字符。

字母只表示名字：`S` 常用于初态、`F` 常用于终态，但最终要看初态和终态集合的实际规定。

### 4.2 如何判断接受

从初态出发，按输入顺序逐个读取字符。

**全部字符读完，并且此时处于终态，才接受。**

- 中途到过终态，不能直接宣布接受，后面还可能读到非法部分。
- 初态可以同时是终态；如果是，则接受空串。
- 终态可以有出边、自环，不是“到这就必须停机”。
- 终态与死状态不是一个概念：终态表示读完输入停在此处可以接受；死状态表示以后再读什么都不能接受。

## 5. DFA 与五元组

### 5.1 什么是 DFA

DFA：确定有穷自动机，英文 Deterministic Finite Automaton。

- 有穷：状态数量有限。
- 确定：当前状态与输入字符确定后，下一状态唯一。
- DFA 不使用 ε 转移。

完整 DFA 的每个状态对字母表中的每个字符都必须有唯一转移。有些教材省略通向死状态的边，按“无边即拒绝”的约定画简图。

### 5.2 五元组

```text
D = (K, Σ, M, S, F_集)
```

| 项 | 含义 |
| --- | --- |
| `K` | 有限状态集合 |
| `Σ` | 输入字母表 |
| `M` | 状态转移函数，常也记作 `δ` |
| `S` | 初始状态，`S ∈ K` |
| `F_集` | 终态集合，`F_集 ⊆ K` |

完整 DFA 的转移函数形式：

```text
M:K × Σ → K
```

例如 `M(S, a) = A`，就是从 `S` 读 `a` 转到 `A`。

**五元组最后一项是集合。** 只有一个终态 `F` 时，也要写 `{F}`，不是单独的 `F`。

`M` 是函数的名字，写五元组时可以先保留这个名字，再用转换表或逐条等式给出完整定义，不能完全不交代它是什么。

## 6. 右线性、左线性文法转换为状态图

### 6.1 右线性文法

1. 每个非终结符对应一个状态。
2. 原文法开始符号对应初态。
3. 新增一个终态 `F`。
4. 把每条产生式转成边。

| 产生式 | 边 |
| --- | --- |
| `A → aB` | `A —a→ B` |
| `A → a` | `A —a→ F` |

如果有 `A → ε`，可直接把 `A` 标为终态，或用 `A —ε→ F` 的统一构造再确定化。

### 6.2 左线性文法

1. 每个非终结符对应一个状态。
2. 新增初态 `I`。
3. 原文法开始符号对应终态。
4. 按左线性规则转边。

| 产生式 | 边 |
| --- | --- |
| `A → Ba` | `B —a→ A` |
| `A → a` | `I —a→ A` |

为什么 `A → Ba` 要画成 `B —a→ A`？因为“B 生成的串后面再接
一个 a”，就能成为 A 生成的串；读完 B 对应的部分后，再读 a，就进入 A。

若有 `A → ε`，可加 `I —ε→ A`。

### 6.3 易错比较

```text
Z → Aa ⟹ A —a→ Z
```

```text
Z → aA ⟹ Z —a→ A
```

同样三个符号，排列不同，转换方向就不同。

> 文法转换出来的通常先是 NFA；是否恰好已经确定，要检查同一状态读同一字符有没有多个去向。

## 7. 完整例题：右线性文法 → DFA

文法：

```text
S → aA ∣ b, A → bS ∣ a
```

### 7.1 逐条画边

| 产生式 | 应画的边 |
| --- | --- |
| `S → aA` | `S —a→ A` |
| `S → b` | `S —b→ F` |
| `A → bS` | `A —b→ S` |
| `A → a` | `A —a→ F` |

手绘方法：画三个圆圈 `S, A, F`，外部箭头指向 `S`；`S` 到 `A` 标
`a`，`A` 回 `S` 标 `b`，两条边分开画；`S` 到 `F` 标 `b`，`A` 到
`F` 标 `a`；`F` 用双圈。

### 7.2 转换表与五元组

省略死状态的表：

| 状态 | `a` | `b` |
| --- | --- | --- |
| `S` | `A` | `F` |
| `A` | `F` | `S` |
| `F` | 无转移 | 无转移 |

对应五元组可按省略死状态的约定写为：

```text
({S, A, F}, {a, b}, M, S, {F})
```

### 7.3 补全死状态

若要求完整 DFA，新增死状态 `D_dead`：

| 状态 | `a` | `b` |
| --- | --- | --- |
| `S` | `A` | `F` |
| `A` | `F` | `S` |
| `F` | `D_dead` | `D_dead` |
| `D_dead` | `D_dead` | `D_dead` |

新增状态后，`K` 要包含死状态，但终态集合仍是 `{F}`。

**F 有出边之后仍是终态；死状态不是新的终态。** 输入恰好在 `F` 处读完时接受；还有字符时才继续走。

### 7.4 输入串判断

| 串 | 行走过程 | 结果 |
| --- | --- | --- |
| `ε` | 留在 `S` | 拒绝 |
| `b` | `S —b→ F` | 接受 |
| `aa` | `S —a→ A —a→ F` | 接受 |
| `ab` | `S —a→ A —b→ S` | 拒绝 |
| `abb` | `S —a→ A —b→ S —b→ F` | 接受 |
| `abaa` | `S —a→ A —b→ S —a→ A —a→ F` | 接受 |
| `aab` | `S —a→ A —a→ F —b→ D_dead` | 拒绝 |

从 `S` 读 `ab` 正好回到 `S`，最后读 `aa` 或 `b` 到终态，所以语言仍为 `(ab)*(aa ∣ b)`。

## 8. NFA：为什么一个输入可以有多个去向

NFA：非确定有穷自动机，英文 Nondeterministic Finite Automaton。

同一状态读同一字符，可以有零个、一个或多个去向。允许 ε 边的扩展常称为 ε-NFA，有些教材也统一称 NFA。

例如：

```text
M(S, a) = {S, A}
```

表示从 `S` 读 `a` 可以去 `S`，也可以去 `A`。

不含 ε 边时，NFA 的转移函数可写成：

```text
M:K × Σ → 2^K
```

`2^K` 表示 `K` 的全部子集组成的集合。含 ε 边时，输入标签范围再加入 `ε`。

### 8.1 接受规则

**只要存在一条路径能够读完整个串并到达终态，就接受。** 不是要求全部分支成功。

有 ε 边时，读完最后一个字符后还可以继续沿 ε 边走到终态。

### 8.2 与 DFA 的区别

| 项 | DFA | NFA / ε-NFA |
| --- | --- | --- |
| 同一状态读同一字符 | 完整定义下恰好一个去向 | 可能有多个，也可能没有 |
| ε 边 | 不允许 | ε-NFA 允许 |
| 处理输入时记录 | 唯一状态 | 所有可能所在状态 |
| 接受条件 | 读完停在终态 | 存在一条读完后到终态的路径 |
| 可识别语言范围 | 正规语言 | 正规语言 |

非确定性不是文法二义性；NFA 存在多条路径并不等于某个文法有二义性。

## 9. 无 ε 边的子集法

### 9.1 核心思想

把 NFA 中“一组可能所在的状态”，整体当成 DFA 的一个状态。

例如 `{S, A}` 在原 NFA 中表示可能在 `S` 或 `A`，在新 DFA 中是**一个状态的名字**。

### 9.2 操作步骤

1. 单初态且无 ε 边时，新初态是 `{S}`。
2. 取一个还没处理的新集合，对每个输入字符分别计算转移。
3. 集合内各状态读该字符，把结果取并集。
4. 出现没见过的集合，就新增一行，继续处理。
5. 直到不再出现新集合。
6. 集合中包含原终态的，标为新终态。
7. 给集合改名，写表、画图、写五元组。

只需枚举从初态可达的集合，不必列出 `2^K` 中的全部子集。

### 9.3 完整例题

原 NFA 初态为 `S`，终态集合为 `{F}`：

| 状态 | `a` | `b` |
| --- | --- | --- |
| `S` | `{S, A}` | `{S}` |
| `A` | `∅` | `{F}` |
| `F` | `∅` | `∅` |

令：

```text
D_0 = {S}, D_1 = {S, A}, D_2 = {S, F}
```

例如：

```text
M_D(D_1, b) = {S} ∪ {F} = {S, F} = D_2
```

```text
M_D(D_2, b) = {S} ∪ ∅ = {S} = D_0
```

完整转换表：

| 新状态 | `a` | `b` |
| --- | --- | --- |
| `D_0` | `D_1` | `D_0` |
| `D_1` | `D_1` | `D_2` |
| `D_2` | `D_1` | `D_0` |

初态为 `D_0`，终态集合为 `{D_2}`。

M 展开写就是：

```text
M_D(D_0, a) = D_1, M_D(D_0, b) = D_0
M_D(D_1, a) = D_1, M_D(D_1, b) = D_2
M_D(D_2, a) = D_1, M_D(D_2, b) = D_0
```

五元组：

```text
D = ({D_0, D_1, D_2}, {a, b}, M_D, D_0, {D_2})
```

### 9.4 这一题的两个易错点

**错一：`{S, F}` 读 `b` 还保留 F。**

F 没有 b 边，这个分支读不下去，因此消失。只有自环才表示读完字符仍留在原状态。

**错二：额外处理单独的 `{A}`。**

从初态实际只出现上述三个集合；`A` 是其中一个元素，不代表 `{A}` 自动成为可达的新状态。

## 10. ε 边与 ε 闭包

### 10.1 ε 边不是普通字符边

```text
P —ε→ Q
```

表示不消耗输入字符，就能从 `P` 到 `Q`。不需要等输入中出现一个“ε 字符”。

普通边 `P —a→ Q` 必须消耗一个 `a`，不能免费走。

### 10.2 ε 闭包是什么

`ε-closure(T)`：从集合 `T` 中的状态出发，只走零条或多条 ε 边能够到达的全部状态的集合。

直接读成：**不用再读字符，还能去哪？全部算上。**

例如：

```text
S —ε→ A —ε→ B
```

```text
ε-closure({S}) = {S, A, B}
```

必须注意：

- 包含自身，因为允许走零条 ε 边。
- 连续多条 ε 边都要追踪。
- 只能顺着箭头走，不能反向。
- 不走 `a, b` 等普通字符边。
- 同一状态只记录一次；ε 环不会让集合无限增长。
- `ε-closure(∅) = ∅`。

### 10.3 为什么到达一个状态后还要算闭包

若读完一个字符到达 `B`，且 `B —ε→ F`，那么此时不再读字符也可能到 `F`。

若只记 `{B}`，就漏掉了已经能到终态的可能性。正确结果应为 `{B, F}`。

**这里是 ε 闭包，不是 Σ 闭包；ε 是空串，Σ 是字母表。**

## 11. 有 ε 边的子集法

### 11.1 三步口诀

> 起点先闭包，读字走一步，走完再闭包。

初态：

```text
D_0 = ε-closure({S})
```

设 `T` 是已经求过 ε 闭包的新状态集合，读字符 `c` 时：

```text
move(T, c) = 所有 M_N(q, c) 的并集，其中 q 遍历 T
```

```text
M_D(T, c) = ε-closure(move(T, c))
```

含义：各状态先读**同一个字符一次**，结果取并集，再追踪所有 ε 边。

### 11.2 为什么不用每次在读之前重新补闭包

初态已经求过闭包，此后每个新状态也都是“读完再闭包”的结果，所以当前集合本身已经包含读之前免费可达的位置。

如果从一个未经闭包处理的任意集合开始，则应先求它的闭包，再读字符。

### 11.3 终态判断

设原 NFA 终态集合为 `F_N`。新状态 `T` 是终态，当且仅当：

```text
T ∩ F_N ≠ ∅
```

只要含有一个原终态就够了，不要求集合中所有元素都是终态。

如果初态闭包就包含原终态，那么新 DFA 的初态也是终态，接受空串。

### 11.4 新 DFA 不保留 ε 边

ε 边的作用已经合并进状态集合，新 DFA 的转移边只标输入字符。

## 12. 带 ε 边的基础例题

初态 S，终态 F，只有以下边：

```text
S —ε→ A, A —a→ A, A —b→ B, B —ε→ F
```

### 12.1 初态与新状态

```text
D_0 = {S, A}
```

读 a：S 没有 a 边，A 读 a 回 A；A 没有 ε 出边，所以得到 `D_1 = {A}`。

读 b：A 到 B，再沿 ε 边到 F，所以得到 `D_2 = {B, F}`。

从 `D_2` 读 a 或 b 都没路，得到 `D_3 = ∅`。

### 12.2 完整转换表

| 新状态 | 集合 | `a` | `b` |
| --- | --- | --- | --- |
| `D_0`，初态 | `{S, A}` | `D_1` | `D_2` |
| `D_1` | `{A}` | `D_1` | `D_2` |
| `D_2`，终态 | `{B, F}` | `D_3` | `D_3` |
| `D_3`，死状态 | `∅` | `D_3` | `D_3` |

该自动机识别 `a*b`，例如 `b, ab, aab`；不接受空串或 `aba`。

### 12.3 为什么可以省略 `D_3`，又何时必须写

- 教材允许省略死状态时，可以把对应位置写为无转移，画图不画 `D_3`。
- 题目要求完整 DFA、补全转换表、每个状态对每个输入都有转移时，必须加入空集对应的死状态。

两种表示接受的语言相同。

**`D_3` 不是终态，终态仍是 `D_2`。** 死状态是走不下去的记录，不是“结束成功”的意思。

## 13. 带连续 ε 边的综合例题

原 NFA 初态 S，终态集合 `{F}`，输入字母表 `{a, b}`：

| 原状态 | `a` | `b` | ε |
| --- | --- | --- | --- |
| S | `∅` | `∅` | `{A}` |
| A | `{A}` | `∅` | `{B}` |
| B | `{C}` | `{B}` | `∅` |
| C | `∅` | `{F}` | `{B}` |
| F | `∅` | `∅` | `∅` |

### 13.1 先把容易读反的边认清

```text
A —ε→ B, B —a→ C, C —ε→ B
```

- A 到 B 免费。
- B 到 C 必须读 a。
- C 到 B 免费。

**不能因为 C 可以免费到 B，就认为 B 也能免费到 C。**

### 13.2 初态

```text
D_0 = ε-closure({S}) = {S, A, B}
```

因为存在 `S —ε→ A —ε→ B`。

### 13.3 从 `D_0` 产生新集合

读 a：A 到 A，B 到 C，先得到 `{A, C}`；A、C 都可以沿 ε 边到 B，闭包为：

```text
D_1 = {A, B, C}
```

读 b：只有 B 可以沿 b 自环留下，得到：

```text
D_2 = {B}
```

### 13.4 关键：为什么 `D_1` 读 b 是 BF，而不是 ABCF

`D_1 = {A, B, C}`，先要求每个分支都读一个 b：

| 读之前的位置 | 读 b 后的位置 |
| --- | --- |
| A | 无 b 边，这个直接读 b 的分支消失 |
| B | B |
| C | F |

先得到 `{B, F}`。B、F 都没有 ε 出边，闭包不再增加元素，因此：

```text
D_3 = {B, F}
```

A 在读 b 前可以先免费到 B，这个可能性已经由旧集合里的 B 表示了；从 B 读 b 还是 B，不能因此把 A 保留下来。

C 免费到 B 的可能性也已计入 B；但 B 不能反向沿 ε 边回 C。

**旧集合表示读之前可能在哪，新集合表示读完这个字符后可能在哪，不是把历史上到过的所有状态积累起来。**

### 13.5 为什么“读 b 和不读 b 都能到 B”仍不一样

从 A 出发：

```text
A —ε→ B
```

不读字符能到 B；也可以：

```text
A —ε→ B —b→ B
```

读一个 b 后仍在 B。终点一样，但输入读取进度不同。

当前计算读一个 b，就只能消耗这个 b。想从 B 再到 C，还需要额外输入一个 a，不能顺便走。

### 13.6 最终答案

| 编号 | 状态集合 | `a` | `b` |
| --- | --- | --- | --- |
| `D_0`，初态 | `{S, A, B}` | `D_1` | `D_2` |
| `D_1` | `{A, B, C}` | `D_1` | `D_3` |
| `D_2` | `{B}` | `D_4` | `D_2` |
| `D_3`，终态 | `{B, F}` | `D_4` | `D_2` |
| `D_4` | `{B, C}` | `D_4` | `D_3` |

只有 `D_3` 包含 F，所以终态集合为 `{D_3}`。所有可达状态对 a、b 都有转移，没有出现空集，不需要额外新增死状态。

五元组：

```text
({D_0, D_1, D_2, D_3, D_4}, {a, b}, M_D, D_0, {D_3})
```

`M_D` 由上表给出。命名顺序不是本质，不同答案只要集合与转移对应一致就可以。

### 13.7 输入串判断

| 串 | 状态序列 | 结果 |
| --- | --- | --- |
| `ab` | `D_0 —a→ D_1 —b→ D_3` | 接受 |
| `aab` | `D_0 —a→ D_1 —a→ D_1 —b→ D_3` | 接受 |
| `abb` | `D_0 —a→ D_1 —b→ D_3 —b→ D_2` | 拒绝 |
| `bab` | `D_0 —b→ D_2 —a→ D_4 —b→ D_3` | 接受 |
| `ε` | 留在 `D_0` | 拒绝 |

## 14. 子集法与画图的答题模板

### 14.0 补充：为什么正规式转换常会产生 ε 边

从正规式构造自动机时，经常先构造 ε-NFA，再用子集法确定化。常用构造思路如下：

- **单个字符 `a`**：初态到终态连一条标 `a` 的边。
- **选择 `r ∣ s`**：新增初态，通过两条 ε 边分别进入 `r` 和 `s` 的子图；两个子图的出口再通过 ε 边接到新增终态。
- **连接 `rs`**：把 `r` 子图的出口用 ε 边接到 `s` 子图的入口。
- **闭包 `r*`**：新增初态和终态；初态可用 ε 边直接到终态，表示重复零次；也可进入 `r` 子图。`r` 的出口既可用 ε 边回到入口继续重复，也可去新增终态结束。

组合时各子图使用不同的状态名，原子图的出口只作为连接点，整张图的接受状态按整体构造重新指定，不能把所有中间出口都保留为全局终态。

其中 ε 边负责“不额外读取字符的衔接、选择或重复”，所以不能把它当成需要在输入中出现的普通字符。正规式中的元符号 `∣`、`*` 本身也不会变成输入边上的实际字符。

### 14.1 从 NFA 开始的标准步骤

1. 读清初态、终态、输入字母表。
2. 把原图转成表，多个去向用集合，无转移写 `∅`。
3. 若有 ε 边，先求初态闭包。
4. 对每个新集合逐项计算 a、b 等字符的转移；读完后补 ε 闭包。
5. 新集合去重，没出现过才另起一行。
6. 处理到没有新集合。
7. 包含原终态的集合标双圈；若初态也包含，则初态同样标双圈。
8. 给集合重命名，按表画边。
9. 按题意保留或省略死状态。
10. 写五元组，用表或等式明确 M。

### 14.2 按转换表画标准状态图

每个新状态画一个圆圈。初态加一根外部入箭头，终态画双圈。

转换表中每一格 `M(D_i, a) = D_j` 都对应一条：

```text
D_i —a→ D_j
```

- `i = j` 时画自环。
- 同一对状态有反向边时，用两条弧线分开，分别标字母和箭头。
- 两个字符都转到同一状态，可合并为一条标记 `a, b` 的边。
- 圆圈在纸上的摆放不影响结果，方向、标签、初终态不能错。

### 14.3 确定化不等于最小化

子集法只保证结果是确定的，不保证状态数最少。

当前阶段保留不同的可达集合即可。不要因为“看着差不多”就随意合并；DFA 最小化是后续独立步骤，需要按状态等价性判断。

## 15. 考前易错点速查

- 正规式是表达式，正规集是它描述的语言；`ab` 表示连接，不是集合 `{a, b}`。
- `(ab)*` 重复整组 ab；`ab*` 只重复 b。
- 终态不是不能出边，读完输入时停在终态才接受。
- 加死状态后，原终态仍是终态，死状态不画双圈。
- NFA 有一条成功路径就接受；其他路径失败不妨碍接受。
- 新 DFA 的一个状态可以用一个集合命名，这不代表新 DFA 同时处于多个状态。
- 没有普通字符边的分支在读该字符时消失，不会默认留在原处。
- ε 闭包含自己、可连续走、只走 ε 边、不能逆着走。
- 有 ε 边时：初态先闭包，每次读完一个字符再闭包。
- 不要把原状态集合直接并入新集合；新集合记录读完后的可能位置，不是历史轨迹。
- 集合中含一个原终态，就成为新终态；最后一项仍要写成终态集合。
- 子集法只处理实际可达的新集合；遇到已出现的集合直接引用，不重复建立状态。
- 题目要求完整 DFA 才必须补缺失转移；若所有可达集合本来就有转移，不必硬加死状态。
