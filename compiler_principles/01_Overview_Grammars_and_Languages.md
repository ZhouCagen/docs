# 第一章 概述文法和语言

> 本章整理符号串、文法、推导、句型与句子、文法分类、递归、二义性和语法分析。重点是理解定义、辨认易错点，并能完成相关题目。

记号约定：公式采用可直接阅读的文本。`V_N` 中的 `_N` 表示下标，
`xⁿ` 表示 n 次幂；`Σ*`、`Σ+` 分别表示星闭包、正闭包。

## 1. 先理解：这些知识在编译中有什么用

编译程序需要识别源程序中的单词，并判断单词如何组成合法结构。

- **词法分析**：识别标识符、关键字、常数、运算符等单词。正规式与有穷自动机常用于这一阶段。
- **语法分析**：检查这些单词如何组成表达式、语句等结构。文法、推导、语法树是这一阶段的基础。

例如 `a+b*c`：词法分析识别其中的标识符和运算符；语法分析确定加法、乘法的组合结构。

编译的常见阶段还包括语义分析、中间代码生成、代码优化和目标代码生成。语义分析检查类型、声明等是否合理；例如一个表达式结构合法，但其中变量未声明，仍可能有语义错误。不要把“符合文法”理解成“程序的所有方面都正确”。

### 1.1 语法、文法、语言

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| 语法 | 规定符号怎样组织才合法的规则 | 标识符必须以字母开头 |
| 文法 | 用符号和产生式形式化描述生成规则的体系 | `S → aS ∣ b`（竖线表示或者） |
| 语言 | 符号串的集合；文法生成的语言是它的全部句子组成的集合 | `{b, ab, aab, …}` |

**文法是规则，句子是一个结果，语言是所有句子的集合。**

## 2. 符号、字母表与符号串

### 2.1 符号与字母表

符号是讨论中的基本单位，例如 `a, b, 0, 1`。

**字母表**通常记作 `Σ`，是非空有限符号集。例如：

```text
Σ = {a, b}
```

`Σ` 读作大写 sigma（西格玛）。它是集合，不是一个符号串。

### 2.2 符号串与串长

符号串是字母表中的符号按一定顺序排列形成的有限序列。

- `ab`、`ba`、`aab` 都是串。
- 顺序不同，串可能不同：`ab ≠ ba`。
- 串 `x` 的长度记为 `∣x∣`，表示符号个数。例如 `∣aab∣ = 3`。

### 2.3 空串、包含空串的集合、空集

空串记作 `ε`，也可写作 `ϵ`，读 epsilon（艾普西隆）。

```text
∣ε∣ = 0
```

| 写法 | 是什么 | 数量 |
| --- | --- | --- |
| `ε` | 一个空串 | 串长为 0 |
| `{ε}` | 包含空串的集合 | 有 1 个元素 |
| `∅` | 空集 | 有 0 个元素 |

> 空串是一个存在的串，只是没有符号；空集是一个没有任何元素的集合。

## 3. 串的连接、幂与闭包

### 3.1 串的连接

把两个串首尾相接，称为连接。设 `x = ab`、`y = ba`，则：

```text
xy = abba
```

基本性质：

```text
∣xy∣ = ∣x∣ + ∣y∣, xε = εx = x
```

连接满足结合律，一般不满足交换律。

串的幂表示重复连接：`x⁰ = ε`，`x¹ = x`，`x² = xx`。例如 `(ab)³ = ababab`。

### 3.2 字母表的幂

`Σⁿ` 表示由 `Σ` 中符号组成的、长度恰好为 `n` 的所有串的集合。

设 `Σ = {a, b}`：

| 写法 | 结果 |
| --- | --- |
| `Σ⁰` | `{ε}` |
| `Σ¹` | `{a, b}` |
| `Σ²` | `{aa, ab, ba, bb}` |
| `Σ³` | `{aaa, aab, aba, abb, baa, bab, bba, bbb}` |

若字母表有 `k` 个符号，则长度为 `n` 的串有 `kⁿ` 个。

**单个符号通常也看成长度为 1 的串，所以写 `Σ¹ = Σ`。** 但要记得：`Σⁿ` 整体是集合，不是某一个串。

### 3.3 星闭包与正闭包

```text
Σ* = Σ⁰ ∪ Σ¹ ∪ Σ² ∪ …
```

```text
Σ+ = Σ¹ ∪ Σ² ∪ Σ³ ∪ …
```

- `Σ*`：所有有限长度的串，包括空串。
- `Σ+`：所有非空串。

```text
Σ* = Σ+ ∪ {ε}
```

**不是乘一个空串，而是在集合里多包含一个空串。** 串与空串连接后不变，并不会因此新增一个集合元素。

记忆：星号从 0 开始，加号从 1 开始。

## 4. 头、尾、固有头与固有尾

### 4.1 头与尾：切一刀

若 `z = xy`，则 `x` 是 `z` 的头（前缀），`y` 是 `z` 的尾（后缀）。

这是把串切成前后两部分，不是默认给串添加新的字符。切在两端时，其中一部分是空串。

以 `z = abc` 为例：

| 分解 | 头 `x` | 尾 `y` |
| --- | --- | --- |
| `abc = ε · abc` | `ε` | `abc` |
| `abc = a · bc` | `a` | `bc` |
| `abc = ab · c` | `ab` | `c` |
| `abc = abc · ε` | `abc` | `ε` |

因此：

- 全部头：`ε, a, ab, abc`。
- 全部尾：`ε, c, bc, abc`。

### 4.2 固有头与固有尾

**固有头、固有尾排除的是整个串本身，不是空串。**

在 `z = xy` 中：

- `x` 是固有头，要求 `y ≠ ε`：后面还剩东西。
- `y` 是固有尾，要求 `x ≠ ε`：前面还剩东西。

所以 `abc` 的固有头为 `ε, a, ab`，固有尾为 `ε, c, bc`。

> 要求非空的是“剩下的那部分”，不是正在判断的固有头或固有尾。

原串长度为 `n>0` 时，固有头和固有尾的长度均满足 `0 ≤ l<n`；还必须从相应端连续取。

- `b` 虽然比 `abc` 短，却不是它的头，因为不是从开头取的。
- 非空串有空串这个固有头和固有尾。
- 空串本身只有空串这个头和尾，没有固有头、固有尾。

### 4.3 练习结论

串 `aba`：

- 固有头：`ε, a, ab`。
- 固有尾：`ε, a, ba`。

串 `ababa`：

- 固有头：`ε, a, ab, aba, abab`。
- 固有尾：`ε, a, ba, aba, baba`。
- `aba` 既是固有头，也是固有尾。
- `bab` 出现在中间，不是头，也不是尾。

## 5. 文法的四元组与产生式

### 5.1 四元组

```text
G = (V_N, V_T, P, S)
```

| 项 | 名称 | 含义与记忆 |
| --- | --- | --- |
| `V_N` | 非终结符集 | `N`：Nonterminal，还能按规则展开 |
| `V_T` | 终结符集 | `T`：Terminal，最终句子中出现的符号 |
| `P` | 产生式集合 | Production，允许怎样替换 |
| `S` | 开始符号 | Start，从它开始推导 |

`V` 常联系 Vocabulary（词汇表）记忆。

必须满足：

```text
V_N ∩ V_T = ∅, S ∈ V_N, V = V_N ∪ V_T
```

### 5.2 产生式与“或者”

`A → β` 表示可以把 `A` 替换为 `β`。

```text
A → Sb ∣ b
```

是两条规则的简写：

```text
A → Sb, A → b
```

**竖线表示或者，不是生成的串中的字符。** 这里不是生成 `Sb|b`。

### 5.3 标识符例子

```text
〈标识符〉 → 〈字母〉 ∣ 〈标识符〉〈数字〉 ∣ 〈标识符〉〈字母〉
〈字母〉 → a ∣ b ∣ … ∣ z
〈数字〉 → 0 ∣ 1 ∣ … ∣ 9
```

- 非终结符：`〈标识符〉`、`〈字母〉`、
  `〈数字〉`。
- 终结符：具体的小写字母和数字。
- 开始符号：`〈标识符〉`。

这套规则规定：以小写字母开头，后面接零个或多个小写字母、数字。

- 合法：`a`、`abc`、`a1b2`。
- 不合法：`1ab`、`a_b`、空串。这里严格按上述文法判断。

**“字母”这个类别是非终结符，具体的 `a` 是终结符。尖括号不属于最终名字。**

## 6. 推导、归约与推导长度

### 6.1 直接推导

根据一条产生式替换一次，叫直接推导，记作 `v ⇒ w`。

例如有 `〈字母〉 → a`：

```text
233〈字母〉666 ⇒ 233a666
```

只替换匹配部分，其余符号原样保留。

注意：`→` 用于写产生式，`⇒` 用于写推导步骤。小写 `v, w` 可表示串，不要与符号集 `V` 混淆。

### 6.2 推导长度与箭头标记

| 记号 | 含义 |
| --- | --- |
| `v ⇒ w` | 一步推导 |
| `v ⇒+ w` | 一步或多步推导 |
| `v ⇒* w` | 零步或多步推导 |

**推导长度数的是使用产生式的次数，不是最终串长。**
教材通常把 `+`、`*` 标在箭头上方；本文用 `⇒+`、`⇒*` 表示相同含义。

任何串都有：

```text
v ⇒* v
```

因为可以零步不动。但 `v ⇒+ v` 不一定成立，必须真的经过至少一步又回到整个原串。

### 6.3 归约

归约是沿推导反方向，把匹配的产生式右部还原为左部。

例如 `S ⇒ aA ⇒ ab`，对应反向归约：

```text
ab —归约→ aA —归约→ S
```

不是看到某个子串长得像产生式右部，就一定应该立即归约；要选择符合正确语法结构的部分。

## 7. 句型、句子与文法生成的语言

### 7.1 句型与句子

句型：从开始符号出发，经过零步或多步推导能得到的串。

```text
S ⇒* x, x ∈ V*
```

句子：只含终结符的句型。

```text
S ⇒* x, x ∈ V_T*
```

所以：句子一定是句型，句型不一定是句子；开始符号本身也是句型。

例如 `S → aS ∣ b`：

```text
S ⇒ aS ⇒ aaS ⇒ aab
```

`S, aS, aaS, aab` 都是句型，只有 `aab` 是句子。

> “全是终结符”还不够，必须能从开始符号推导出来。例如 `ba` 不是该文法的句子。

若 `S ⇒* ε`，空串也是该文法的句子。

### 7.2 语言

```text
L(G) = {x ∣ S ⇒* x, x ∈ V_T*}
```

文法生成的语言，是它的全部句子组成的集合；只收集最终的终结符串，不把含非终结符的中间句型放进去。

```text
L(G) ⊆ V_T*
```

## 8. 递归规则

### 8.1 直接递归

产生式左部的非终结符直接出现在右部，例如：

```text
S → aS
```

可以反复展开：

```text
S ⇒ aS ⇒ aaS ⇒ aaaS ⇒ …
```

### 8.2 间接递归

先通过其他非终结符，经过多步又出现自身。例如：

```text
S → aA, A → bS
```

```text
S ⇒ aA ⇒ abS
```

一般的递归关系可表示为：

```text
A ⇒+ αAβ
```

### 8.3 递归的作用与易错点

递归可以用有限条规则描述反复出现的结构，从而可能生成无限多个句子。

但“有递归”不保证“有无限多个句子”：

- 只有 `S → aS` 时，永远消不掉 `S`，一个句子都生成不了，`L(G) = ∅`。
- `S → S ∣ a` 有递归，但只生成句子 `a`。

**递归表示再次出现某个非终结符，不代表整个串回到原样。**
`S ⇒ aA ⇒ abS` 并不能证明
`S ⇒+ S`，因为 `abS ≠ S`。

## 9. 文法唯一确定语言与文法等价

### 9.1 为什么一个文法只确定一个语言

固定规则后，所有能生成的句子组成的集合就确定了。

“唯一”不是说只能生成一个句子，也不是说每个句子只能有一种推导。

例如 `S → aS ∣ b` 生成无限多个句子，但它们始终属于同一个确定的集合：

```text
L(G) = {b, ab, aab, aaab, …}
```

就像自然数有无限多个，但自然数集是一个确定的集合。

### 9.2 等价文法

若 `L(G_1) = L(G_2)`，则称两个文法等价。

规则、非终结符名字、推导步数可以不同，只要生成的全部句子相同。

例如：

```text
G_1:S → aA ∣ b, A → bS ∣ a
```

```text
G_2:T → abT ∣ aa ∣ b
```

两者生成的都是零组或多组 `ab`，最后接 `aa` 或 `b`：

```text
L(G_1) = L(G_2) = {(ab)ⁿaa ∣ n ≥ 0} ∪ {(ab)ⁿb ∣ n ≥ 0}
```

因此它们等价。文法唯一确定语言，语言不唯一确定文法。

## 10. 0、1、2、3 型文法

约定 `A, B` 是单个非终结符，`a, b` 是单个终结符，`α, β` 表示符号串。

### 10.1 分类表

| 类型 | 名称 | 产生式的主要限制 |
| --- | --- | --- |
| 0 型 | 无限制文法 | `α → β`，左部至少含一个非终结符 |
| 1 型 | 上下文有关文法 | 在上述要求上，按非缩短形式要求 `∣α∣ ≤ ∣β∣` |
| 2 型 | 上下文无关文法 | `A → β`，左部必须是单个非终结符 |
| 3 型 | 正规文法 | 统一符合右线性或左线性形式 |

0 型也不是任何规则都允许：`ab → A` 左部没有非终结符，不合法。

1 型数长度时，终结符和非终结符都各算一个符号。例如 `AB → aBC` 不缩短；`AB → a` 缩短，不符合非缩短要求。

2 型右部可以有多个符号，例如 `A → aAB`；通常也允许 `A → ε`。

### 10.2 上下文有关、无关是什么意思

上下文有关规则的典型形式：

```text
αAβ → αγβ, γ ≠ ε
```

表示 `A` 需要在左边是 `α`、右边是 `β` 的环境中，才能替换为 `γ`。按非缩短形式判题时，不要求每条规则都直接长成这个样子。

上下文无关规则 `A → β` 则不需要检查 `A` 左右是什么，只要出现 `A` 就可替换。

### 10.3 左线性与右线性

常用的单终结符形式：

```text
右线性： A → aB 或 A → a
```

```text
左线性： A → Ba 或 A → a
```

**看的是产生式右部的非终结符在哪一端，不是看箭头左边的符号。**

| 规则 | 判断 |
| --- | --- |
| `A → aB` | 右线性 |
| `A → Ba` | 左线性 |
| `A → a` | 左右两种形式都允许 |
| `A → aBa` | 两种都不是，非终结符在中间 |
| `A → AB` | 不符合上述形式，右部有两个非终结符 |

整套规则要统一左线性或统一右线性。

- `A → Sb ∣ b` 整体符合左线性，`A → b` 不造成冲突。
- 如果再加 `S → aA`，就出现了左右线性混用，不能据此判为 3 型。

有些教材允许一般形式 `A → wB` 或 `A → w`，其中 `w` 是终结符串；左线性同理。多字符边可以借助新增状态或非终结符拆开。若题目严格限定单个终结符形式，按它的形式要求判断，不要把等价语言与原产生式形式混淆。

### 10.4 空产生式与包含关系

语言类的严格包含关系是：

```text
正规语言 ⊊ 上下文无关语言 ⊊ 上下文有关语言 ⊊ 递归可枚举语言
```

这里采用统一处理空串的约定。1 型通常允许特例 `S → ε`，并要求 `S` 不出现在任何产生式右部；3 型的空产生式约定也应以教材为准。

**不要因为允许空产生式的 2 型文法有 `A → ε`，就机械地说这条规则也符合 1 型“不缩短”。语言类包含不等于原产生式不加改写就符合所有形式。**

### 10.5 判题顺序

1. 先按教材约定处理空产生式。
2. 检查能否统一符合 3 型形式。
3. 不行，再检查左部是否全部为单个非终结符，判断 2 型。
4. 再检查是否全部不缩短，判断 1 型。
5. 否则，只要每条左部至少含一个非终结符，就是 0 型。

题目问“最严格类型”，就填满足的限制最多的那一类。

## 11. 语法树、最左推导与最右推导

语法树记录句子的组成结构：

- 根是开始符号。
- 内部节点表示非终结符。
- 用产生式 `A → X_1 … X_n` 展开时，把 `X_1, …, X_n` 按顺序作为 `A` 的子节点。
- 完整句子的叶子从左到右读出该句子；空产生式可按教材画出 `ε` 叶子，空串不增加实际字符。

最左推导：每一步都替换当前最左边的非终结符。

最右推导：每一步都替换当前最右边的非终结符。

“最左、最右”规定的是选择哪个非终结符展开，不是要求选择哪条产生式。

## 12. 二义性

### 12.1 判断标准

一个上下文无关文法有二义性，当且仅当存在某个句子具有两棵不同的语法树。

等价说法：同一个句子存在两种不同的最左推导，或两种不同的最右推导。

> 只要找出一个这样的句子，就能证明文法有二义性；想证明没有二义性，不能只检查一个例子。

### 12.2 什么叫树不同

看同一个串的父子关系、分组结构是否不同，不看画图的位置，也不看先画了哪一支。

文法：

```text
E → E+E ∣ E*E ∣ a
```

句子 `a+a*a` 有两种结构：

| 结构 | 根使用的规则 | 左子表达式 | 右子表达式 |
| --- | --- | --- | --- |
| `a+(a*a)` | `E → E+E` | `a` | `a*a` |
| `(a+a)*a` | `E → E*E` | `a+a` | `a` |

括号只是展示结构，不是原句子中的字符。这套文法没有编码乘法优先级，所以两种结构都允许。

两种不同的最左推导分别是：

```text
E ⇒ E+E ⇒ a+E ⇒ a+E*E ⇒ a+a*E ⇒ a+a*a
```

```text
E ⇒ E*E ⇒ E+E*E ⇒ a+E*E ⇒ a+a*E ⇒ a+a*a
```

因此该文法有二义性。

### 12.3 两个常见错误

**错误一：有竖线，所以有二义性。**

`S → a ∣ b` 生成两个不同句子，但每个句子的结构唯一，没有二义性。

**错误二：推导顺序不同，所以有二义性。**

设 `S → AB, A → a, B → b`：

```text
S ⇒ AB ⇒ aB ⇒ ab
```

```text
S ⇒ AB ⇒ Ab ⇒ ab
```

只是先展开 `A` 或 `B` 的区别；始终是 `S` 生出 `A, B`，`A` 生出 `a`，`B` 生出 `b`，树没有变。

“两种不同推导”不足以证明二义性；“两种不同最左推导”才是充分证据之一。

二义性不影响文法唯一确定语言：句子集合可以确定，但其中某个句子的结构可能不唯一。

### 12.4 补充：怎样把乘法优先写进文法

一种常用改写是分成表达式、项和因子：

```text
E → E+T ∣ T
T → T*F ∣ F
F → (E) ∣ a
```

- `E`：表达式，由项相加组成。
- `T`：项，由因子相乘组成。
- `F`：因子，可以是 `a` 或括号表达式。

这里产生式 `F → (E)` 的括号是真正的终结符，属于输入；与前面仅为展示结构而额外添加的括号不同。

这样，不带括号的 `a+a*a` 只能按 `a+(a*a)` 的结构分析，因为顶层加法
右边的 `T` 可以包含乘法，而普通 `T` 不能直接包含未加括号的加法。
`E → E+T` 和 `T → T*F` 的左递归形式还体现了同级运算的左结合。

这也说明：有左递归不等于有二义性。是否需要消除左递归，取决于准备采用的分析方法。

## 13. 自上向下、自底向上与句柄

### 13.1 两种分析方向

| 比较项 | 自上向下 | 自底向上 |
| --- | --- | --- |
| 出发点 | 开始符号 | 输入串 |
| 基本动作 | 按规则展开 | 按规则归约 |
| 语法树建立方向 | 从根到叶 | 从叶到根 |
| 典型方法 | 递归下降、LL | LR |

例如 `S → aA, A → b`：

```text
推导： S ⇒ aA ⇒ ab
```

```text
归约： ab —归约→ aA —归约→ S
```

两种方法都能由计算机实现。自上向下常便于手写；典型 LR 方法能处理比 LL 更广的文法，但分析表与实现更复杂。

朴素递归下降直接处理左递归 `E → E+a ∣ a` 时可能无限递归，通常要先改写；LR 可以处理适当的左递归文法。

### 13.2 句柄：当前正确该归约的那一段

句柄不是“任意一个匹配产生式右部的子串”。

在逆最右推导的规范归约中，句柄是**当前应该归约的产生式右部及其位置**，归约它才能回到前一个右句型。

形式化地，若存在最右推导：

```text
S ⇒*(最右) αAw ⇒(最右) αβw
```

这里 `⇒*(最右)` 表示零步或多步最右推导，`⇒(最右)` 表示一步最右推导。
其中 `w` 是终结符串，则对应产生式 `A → β` 的这处 `β` 是当前右句型的一个句柄。

例子见下一节：`abaa` 第一次应归约最后一个 `a`，不是随便找一个 `a` 就替换。

## 14. 综合例题：把本章概念串起来

已知：

```text
S → aA ∣ b, A → bS ∣ a
```

### 14.1 四元组、类型和递归

```text
V_N = {S, A}, V_T = {a, b}
```

```text
P = {S → aA, S → b, A → bS, A → a}
```

开始符号是 `S`。这是 3 型右线性文法，存在间接递归：

```text
S ⇒ aA ⇒ abS
```

### 14.2 推导与归约

推导 `abaa`：

```text
S ⇒ aA ⇒ abS ⇒ abaA ⇒ abaa
```

推导长度为 4。

归约过程：

```text
abaa —归约→ abaA —归约→ abS —归约→ aA —归约→ S
```

依次归约：最后一个 `a`、末尾 `aA`、末尾 `bS`、整个 `aA`。

### 14.3 句型与句子判断

| 串 | 句型 | 句子 | 原因 |
| --- | --- | --- | --- |
| `S` | 是 | 否 | 零步可达，含非终结符 |
| `aA` | 是 | 否 | 可达，含非终结符 |
| `abS` | 是 | 否 | 可达，含非终结符 |
| `ab` | 否 | 否 | 没有 `S → ε`，不能删掉末尾 `S` |
| `aa` | 是 | 是 | 可达且全为终结符 |
| `abaa` | 是 | 是 | 可达且全为终结符 |
| `ε` | 否 | 否 | 不能生成空串 |

`S ⇒* S` 正确；`S ⇒+ S` 错误，因为至少展开一次就会留下无法消除的终结符。

### 14.4 语言与二义性

长度不超过 4 的全部句子：

```text
{b, aa, abb, abaa}
```

整个语言由正规式 `(ab)*(aa ∣ b)` 描述，句子无限多。

该文法没有二义性：在 `S` 处，后续首字符为 `a` 时只能选
`S → aA`，为 `b` 时只能选 `S → b`；在 `A` 处，为 `b` 时只能选
`A → bS`，为 `a` 时只能选 `A → a`。每个中间句型又至多只有一个
非终结符，因此给定合法句子，整个推导被唯一确定。

## 15. 考前易错点速查

- `Σ` 是符号集；`Σ*` 是串的集合；某个 `ab` 才是一个串。
- `Σ⁰ = {ε}`，不是空集。
- 非空串的固有头、固有尾可以是空串，但不能是整个串。
- 产生式的竖线是“或者”，不进入生成结果。
- 推导长度数步骤，不数字符。
- 递归后再次出现 `S`，不等于整个串变回 `S`。
- 句子既要全是终结符，又要能从开始符号推导出来。
- 同一语言可以有不同文法；同一文法只确定一个语言。
- 右线性看右部非终结符在右端；左线性看它在左端。
- 二义性看同一句子的结构是否不同，不看任意推导顺序是否不同。
- 自上向下是展开，自底向上是归约；句柄是应当归约的那一处，不是随意匹配。
