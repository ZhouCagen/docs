# 第一节 马克思主义的创立和发展

## 考点一 马克思主义的内涵及构成

### 1. 马克思主义的构成

马克思主义主要由三部分构成：

| 组成部分                 | 地位       |
| ------------------------ | ---------- |
| **马克思主义哲学**       | 基础、方法 |
| **马克思主义政治经济学** | 主体内容   |
| **科学社会主义**         | 目的、归宿 |

---

## 考点二 马克思主义的基本立场、基本观点和基本方法

### 1. 马克思主义的基本立场

马克思主义的基本立场是：

- 以**无产阶级的解放和全人类解放**为己任
- 以**人民为中心**
- 坚持**一切为了人民、一切依靠人民**
- 全心全意为人民谋幸福

### 2. 马克思主义的基本观点

马克思主义的基本观点是：

> 关于**自然、社会和人类思维发展一般规律**的科学认识。

特点：研究方向非常全面，涵盖自然、社会和人的思维。

### 3. 马克思主义的基本方法

马克思主义的基本方法是：

> **辩证唯物主义和历史唯物主义**

主要包括：

- 实事求是的方法
- 辩证分析的方法
- 社会基本矛盾和主要矛盾分析的方法
- 历史分析的方法
- 阶级分析的方法
- 群众路线的方法

---

## 考点三 马克思主义的创立

### 1. 《共产党宣言》

马克思、恩格斯将工人组织**“正义者同盟”**改组为**“共产主义者同盟”**，并为其起草了世界上第一个无产阶级政党的党纲：

> **《共产党宣言》**

《共产党宣言》的发表：

- 标志着**马克思主义的公开问世**
- 标志着**科学社会主义的诞生**
- 标志着**马克思主义的诞生**
- 是世界上第一个无产阶级政党的党纲

---

### 2. 马克思主义产生的条件

马克思主义的产生具有深刻的：

- 社会根源
- 阶级基础
- 思想渊源

#### （1）社会根源

> **资本主义生产方式在西欧已经有了相当的发展 (也是时代背景)**

#### （2）阶级基础

> **无产阶级在反抗资产阶级剥削和压迫的斗争中不断发展壮大。(也是实践基础)**
>
> 法国、英国、德国工人运动的兴起：标志着**现代无产阶级作为独立的政治力量登上历史舞台**。

注意区分：

> **中国无产阶级登上历史舞台的标志：五四运动。**

#### （3）思想渊源

马克思主义的三大思想渊源：

| 思想渊源               |
| ---------------------- |
| **德国古典哲学**       |
| **英国古典政治经济学** |
| **英法空想社会主义**   |

> **德国哲学 + 英国经济学 + 英法社会主义**

## 考点四 马克思主义的发展

### 1. 列宁主义

列宁指出：

> **经济政治发展的不平衡已经成为资本主义发展的绝对规律。**

在此基础上，列宁提出：

> **社会主义革命可能在一国或数国首先发生并取得胜利。**

逻辑关系：

> 资本主义世界**经济政治发展不平衡**  
> ↓  
> 各资本主义国家不可能同时灭亡  
> ↓  
> 社会主义革命可能在**一国或数国首先取得胜利**

## 考点五 马克思主义的基本特征

马克思主义具有四个基本特征：

> **科学性、人民性、实践性、发展性**

| 基本特征   | 含义                                                             |
| ---------- | ---------------------------------------------------------------- |
| **科学性** | **正确反映**自然、社会和人类思维发展的客观规律                   |
| **人民性** | 马克思主义的**本质属性**；**人民至上**是马克思主义的基本立场     |
| **实践性** | **实践观点**是马克思主义**首要的和基本**的观点（**独有观点**）   |
| **发展性** | 马克思主义是**不断发展的开放的学说**，具有**与时俱进的理论品质** |

### 马克思主义科学性和革命性的统一

马克思主义的基本特征可以概括为：

> **科学性和革命性的统一**

其中：

> **革命性是马克思主义的内在品质。**

革命性是马克思主义的：

- 人民性
- 实践性
- 发展性

的应有之义和必然要求。

可以简单记忆为：

> **人民性 + 实践性 + 发展性 → 革命性**

最终：

> 马克思主义 = 科学性和革命性的统一
