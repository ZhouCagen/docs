# 马克思主义哲学

马克思主义哲学主要包括四个板块：

| 板块     | 研究的问题                           |
| -------- | ------------------------------------ |
| 唯物论   | 世界是什么？世界的本原是什么？——物质 |
| 辩证法   | 物质世界是怎样存在和发展的？         |
| 认识论   | 人如何认识世界？                     |
| 唯物史观 | 人类社会及其历史发展的规律是什么？   |

# 第一章 辩证唯物论

## 第一节 哲学及其基本问题

### 考点1 哲学基本问题及不同哲学流派

恩格斯指出：“全部哲学，特别是近代哲学的重大的基本问题，是思维和存在的关系问题。”

- **思维**：精神、意识。
- **存在**：物质。
- 哲学基本问题就是**物质和意识的关系问题**，包括两个方面。

### 一、第一方面：物质和意识何者是第一性？

即：**谁是世界的本原，谁决定谁？**

这是划分**唯物主义和唯心主义**的标准。

#### 1. 唯物主义：物质第一性，意识第二性

物质是世界的本原，物质决定意识。

唯物主义内部的主要分歧是：**如何理解“物质”？**

| 历史形态                             | 对物质的理解                                             | 主要特点或局限                                         |
| ------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------ |
| 古代朴素唯物主义                     | 把物质归结为一种或几种具体的物质形态，如水、火、气       | 坚持唯物主义方向，但具有直观性、猜测性                 |
| 近代形而上学唯物主义（机械唯物主义） | 把物质归结为原子等粒子，认为其属性就是一切物质的共同属性 | 具有机械性、形而上学性和历史观上的唯心主义             |
| 辩证唯物主义                         | 物质是标志客观实在的哲学范畴，共同本质是客观实在性       | 把唯物主义与辩证法结合，并把唯物主义贯彻到社会历史领域 |

**前两种属于旧唯物主义：**

- 在自然观上坚持唯物主义，在历史观上陷入唯心主义。
- 因而被称为“半截子唯物主义”。

**马克思主义哲学的变革：**

- 实现了**唯物主义与辩证法的统一**。
- 创立了**唯物史观**，实现了自然观与历史观上的唯物主义的统一。
- 唯物史观强调：**社会存在决定社会意识**，社会历史发展有其客观规律。

> 注意：不是简单地把“人类历史当作物质”，也不是把前两种唯物主义直接包含进来，而是克服其局限并发展唯物主义。

#### 2. 唯心主义：意识第一性，物质第二性

意识是世界的本原，意识决定物质。

| 基本类型     | 核心观点                                                     |
| ------------ | ------------------------------------------------------------ |
| 主观唯心主义 | 把人的感觉、经验、心灵等**主观精神**看作世界的本原           |
| 客观唯心主义 | 把独立于人之外的**客观精神**看作世界的本原，如理念、绝对精神 |

**区分关键：作为世界本原的精神，是人的主观精神，还是独立于人之外的客观精神？**

#### 3. 二元论

- 认为物质和意识是两个相互独立的本原。
- 试图调和唯物主义与唯心主义，但最终往往倒向唯心主义。
- **二元论不等于不可知论**：二者回答的不是同一个问题。

### 二、第二方面：思维和存在是否具有同一性？

即：**思维能否认识存在，意识能否正确认识物质世界？**

这是划分**可知论和不可知论**的标准。

| 哲学立场 | 核心观点                                       |
| -------- | ---------------------------------------------- |
| 可知论   | 思维能够认识存在，人能够认识世界               |
| 不可知论 | 否认人能够认识世界，或否认彻底认识世界的可能性 |

- **绝大多数唯物主义者和唯心主义者都属于可知论。**
- 唯物主义与唯心主义的分歧，不等于可知论与不可知论的分歧。
- 这里的“同一性”指**能否认识**，不是说物质和意识是同一种东西。

### 三、哲学的另一个重要问题：世界是怎样存在的？

对这个问题的不同回答，形成了**辩证法和形而上学**的对立。

| 比较角度 | 辩证法                       | 形而上学           |
| -------- | ---------------------------- | ------------------ |
| 联系     | 联系地看问题                 | 孤立地看问题       |
| 全面性   | 全面地看问题                 | 片面地看问题       |
| 发展     | 发展地看问题                 | 静止地看问题       |
| 矛盾     | 承认矛盾是事物发展的根本动力 | 否认事物的内部矛盾 |

**根本分歧：是否承认矛盾是事物发展的根本动力。**

### 四、两组划分不要混淆

- **唯物主义与唯心主义**：回答世界的本原是什么。
- **辩证法与形而上学**：回答世界是怎样存在和发展的。

二者可以形成不同结合：

| 结合方式           | 典型代表                 |
| ------------------ | ------------------------ |
| 唯物主义＋辩证法   | 马克思主义的辩证唯物主义 |
| 唯物主义＋形而上学 | 近代形而上学唯物主义     |
| 唯心主义＋辩证法   | 黑格尔的辩证唯心主义     |
| 唯心主义＋形而上学 | 形而上学唯心主义         |

> 马克思以前已有朴素唯物主义与朴素辩证法的结合，但尚未形成科学的辩证唯物主义。
