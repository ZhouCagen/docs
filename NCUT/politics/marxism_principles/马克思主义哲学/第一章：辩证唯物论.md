# 马克思主义哲学

马克思主义哲学主要包括四个板块：

| 板块     | 研究的问题                           |
| -------- | ------------------------------------ |
| 唯物论   | 世界是什么？世界的本原是什么？——物质 |
| 辩证法   | 物质世界是怎样存在和发展的？         |
| 认识论   | 人如何认识世界？                     |
| 唯物史观 | 人类社会及其历史发展的规律是什么？   |

## 第一章 辩证唯物论

### 第一节 哲学及其基本问题

恩格斯指出：“全部哲学，特别是近代哲学的重大的基本问题，是思维和存在的关系问题。”

- **思维**：精神、意识。
- **存在**：物质。
- 哲学基本问题就是**物质和意识的关系问题**，包括两个方面。

#### 一、第一方面：物质和意识何者是第一性？

即：**谁是世界的本原，谁决定谁？**

这是划分**唯物主义和唯心主义**的标准。

##### 1. 唯物主义：物质第一性，意识第二性

物质是世界的本原，物质决定意识。

唯物主义内部的主要分歧是：**如何理解“物质”？**

| 历史形态                             | 对物质的理解                                             | 主要特点或局限                                         |
| ------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------ |
| 古代朴素唯物主义                     | 把物质归结为一种或几种具体的物质形态，如水、火、气       | 坚持唯物主义方向，但具有直观性、猜测性                 |
| 近代形而上学唯物主义（机械唯物主义） | 把物质归结为原子等粒子，认为其属性就是一切物质的共同属性 | 具有机械性、形而上学性和历史观上的唯心主义             |
| 辩证唯物主义                         | 物质是标志客观实在的哲学范畴，共同本质是客观实在性       | 把唯物主义与辩证法结合，并把唯物主义贯彻到社会历史领域 |

**前两种属于旧唯物主义：**

- 在自然观上坚持唯物主义，在历史观上陷入唯心主义。
- 因而被称为“半截子唯物主义”。

**马克思主义哲学的变革：**

- 实现了**唯物主义与辩证法的统一**。
- 创立了**唯物史观**，实现了自然观与历史观上的唯物主义的统一。
- 唯物史观强调：**社会存在决定社会意识**，社会历史发展有其客观规律。

> 注意：不是简单地把“人类历史当作物质”，也不是把前两种唯物主义直接包含进来，而是克服其局限并发展唯物主义。

##### 2. 唯心主义：意识第一性，物质第二性

意识是世界的本原，意识决定物质。

| 基本类型     | 核心观点                                                     |
| ------------ | ------------------------------------------------------------ |
| 主观唯心主义 | 把人的感觉、经验、心灵等**主观精神**看作世界的本原           |
| 客观唯心主义 | 把独立于人之外的**客观精神**看作世界的本原，如理念、绝对精神 |

**区分关键：作为世界本原的精神，是人的主观精神，还是独立于人之外的客观精神？**

##### 3. 二元论

- 认为物质和意识是两个相互独立的本原。
- 试图调和唯物主义与唯心主义，但最终往往倒向唯心主义。
- **二元论不等于不可知论**：二者回答的不是同一个问题。

#### 二、第二方面：思维和存在是否具有同一性？

即：**思维能否认识存在，意识能否正确认识物质世界？**

这是划分**可知论和不可知论**的标准。

| 哲学立场 | 核心观点                                       |
| -------- | ---------------------------------------------- |
| 可知论   | 思维能够认识存在，人能够认识世界               |
| 不可知论 | 否认人能够认识世界，或否认彻底认识世界的可能性 |

- **绝大多数唯物主义者和唯心主义者都属于可知论。**
- 唯物主义与唯心主义的分歧，不等于可知论与不可知论的分歧。
- 这里的“同一性”指**能否认识**，不是说物质和意识是同一种东西。

#### 三、哲学的另一个重要问题：世界是怎样存在的？

对这个问题的不同回答，形成了**辩证法和形而上学**的对立。

| 比较角度 | 辩证法                       | 形而上学           |
| -------- | ---------------------------- | ------------------ |
| 联系     | 联系地看问题                 | 孤立地看问题       |
| 全面性   | 全面地看问题                 | 片面地看问题       |
| 发展     | 发展地看问题                 | 静止地看问题       |
| 矛盾     | 承认矛盾是事物发展的根本动力 | 否认事物的内部矛盾 |

**根本分歧：是否承认矛盾是事物发展的根本动力。**

#### 四、两组划分不要混淆

- **唯物主义与唯心主义**：回答世界的本原是什么。
- **辩证法与形而上学**：回答世界是怎样存在和发展的。

二者可以形成不同结合：

| 结合方式           | 典型代表                 |
| ------------------ | ------------------------ |
| 唯物主义＋辩证法   | 马克思主义的辩证唯物主义 |
| 唯物主义＋形而上学 | 近代形而上学唯物主义     |
| 唯心主义＋辩证法   | 黑格尔的辩证唯心主义     |
| 唯心主义＋形而上学 | 形而上学唯心主义         |

> 马克思以前已有朴素唯物主义与朴素辩证法的结合，但尚未形成科学的辩证唯物主义。

### 第二节 世界的多样性与物质统一性

#### 一、物质及其定义

##### 1. 恩格斯对物质的理解

恩格斯论述的要点是：物质概念是从各种具体事物的总和中**抽象出来的**。

- **具体的物**：具有各自特殊性质的具体事物。
- **物质的概念（范畴）**：舍去具体事物的差异，概括它们的共同本质。
- 这里的“抽象”，可以理解为从各种具体事物中提炼共性；哲学物质范畴所概括的共同本质是**客观实在性**。

**易错辨析：**

| 表述                                       | 判断与理解                           |
| ------------------------------------------ | ------------------------------------ |
| 物质概念是各种具体事物的简单总和           | 错误：把哲学概括等同于具体事物的集合 |
| 物质概念是从各种具体事物的总和中抽象出来的 | 正确：强调对共同本质的概括           |
| 物质就是某一种具体的物                     | 错误：把物质范畴等同于具体物质形态   |

> 记忆：**总和是抽象的出发点，物质范畴是抽象得到的共性概括。**“物质是所有物的总和”不宜直接作为哲学物质范畴的定义。

##### 2. 列宁对物质的定义

**物质是标志客观实在的哲学范畴，这种客观实在是人通过感觉感知的，它不依赖于我们的感觉而存在，为我们的感觉所复写、摄影、反映。**

可以理解为：**物质是不依赖于人的意识而存在，并能为人的意识所反映的客观实在。**

| 关键词                 | 含义                               | 哲学立场       |
| ---------------------- | ---------------------------------- | -------------- |
| 不依赖于人的意识而存在 | 物质的存在不以人的意识为前提       | 坚持唯物主义   |
| 能为人的意识所反映     | 物质世界能够被人认识               | 坚持可知论     |
| 客观实在               | 自然存在和社会存在所具有的共同本质 | 物质的唯一特性 |

这种共同特性是从**自然存在和社会存在**中抽象出来的，体现了自然观和历史观上的唯物主义的统一。

> 注意：不能把物质限定为“一切已经被我们感知的东西”。**尚未被发现、尚未被感知的客观实在，同样属于物质。**“能被反映”强调可知性，不要求它已经被某个人认识。

**记忆核心：物质——客观实在；不依赖意识——唯物主义；能被意识反映——可知论。**

#### 二、物质与运动

##### 1. 运动的含义和地位

**运动是标志一切事物和现象的变化及其过程的哲学范畴。**

- 简记：**运动＝变化**，不限于空间位置的移动。
- **运动是物质的存在方式和根本属性。**
- **矛盾是事物运动、变化和发展的内在原因。**

> 区分：物质的**唯一特性**是客观实在性；物质的**根本属性、存在方式**是运动。

##### 2. 物质和运动不可分割

| 基本表述             | 含义                                         | 割裂二者的错误                                                 |
| -------------------- | -------------------------------------------- | -------------------------------------------------------------- |
| **运动是物质的运动** | 物质是运动的承担者，不存在脱离物质的运动     | 设想没有物质的运动，把运动归结为独立精神的活动，会导致唯心主义 |
| **物质是运动的物质** | 一切物质都处于运动中，不存在完全不运动的物质 | 设想没有运动的物质，会导致形而上学                             |

> 记忆：**离开物质谈运动——唯心主义；离开运动谈物质——形而上学。**这里批判的是把运动归结为脱离物质的精神活动，不是否认人有思维活动。

**辅助理解：把上面两句话分别反过来想。**

- **运动是物质的运动**：问“是什么在运动？”运动总要有物质作为承担者。若把运动归结为脱离物质、独立存在的精神活动，就落入唯心主义；不是说承认人有思维活动就是唯心主义。
- **物质是运动的物质**：问“物质能完全不变化吗？”若认为存在完全不运动、不变化的物质，就是形而上学。“东西放着没动”只是相对位置没变，不代表内部和其他方面没有变化。

#### 三、运动与静止

##### 1. 相对静止的含义

**相对静止是物质运动在一定条件下的稳定状态，是运动的特殊状态。**

具体包括两种情形：

1. **空间的相对位置暂时不变**：例如乘客相对于匀速行驶的车厢保持位置不变。
2. **事物的根本性质暂时不变**：事物虽发生变化，但在一定阶段仍保持其基本性质。

> 静止不是完全不动，而是**在一定条件、一定关系和一定范围内保持相对稳定**。

##### 2. 运动与静止是对立统一的关系

**相互区别：运动是绝对的，静止是相对的。**

| 比较角度 | 运动             | 静止                     |
| -------- | ---------------- | ------------------------ |
| 性质     | 绝对的           | 相对的                   |
| 条件     | 无条件的         | 有条件的                 |
| 体现     | 物质运动的变动性 | 物质运动的确定性、稳定性 |

**相互联系：运动和静止相互依赖、相互渗透、相互包含，即“动中有静，静中有动”。**

- **动中有静**：事物在不断运动中保持一定的相对稳定。
- **静中有动**：处于相对静止状态的事物，仍然在发生运动和变化。

##### 3. 两种错误倾向

| 错误倾向                                 | 哲学判断                           |
| ---------------------------------------- | ---------------------------------- |
| 夸大静止，否认运动，把静止绝对化         | 形而上学                           |
| 夸大运动，否认相对静止，使事物失去确定性 | **诡辩论（这里指相对主义诡辩论）** |

**正确观点：绝对运动与相对静止相统一。**

**辅助理解：**人每天都在变化，但在一定时期仍保持自身的相对稳定。不能借口“今天的我已经变化了”，就说“昨天的承诺和今天的我完全无关”。这就是借变化否认相对稳定的诡辩。

**矛盾论与诡辩论的区别：**矛盾指事物内部和事物之间的对立统一，矛盾是事物运动、变化和发展的内在原因；这里的诡辩论则是片面夸大运动、否认相对静止的错误观点。两者不是一回事，不能互相替换。

##### 4. 关系辨析的记忆方法与辅助解释

**（1）不可分割：你是我的你，我是你的我。**

- 套到物质与运动上：**运动是物质的运动，物质是运动的物质。**
- 强调“谁也离不开谁”：不存在没有物质承担的运动，也不存在完全不运动的物质。
- 套到物质运动与时空上：**时空是物质运动的时空，物质运动是时空中的物质运动。**同样不能把它们拆开、独立起来理解。

**（2）对立统一：既相互区别，又相互联系。**

- **对立（相互区别）**：运动体现变动性，是绝对的、无条件的；静止体现稳定性，是相对的、有条件的。
- **统一（相互联系）**：二者相互依赖、相互渗透、相互包含，即“动中有静，静中有动”。
- **例子**：坐在行驶的车里，乘客相对于车厢的位置不变，相对于路面却在运动。运动和相对静止可以同时存在，但所说的条件、关系不同。

**（3）保留课堂辅助口诀：不可分割——词性不同；对立统一——词性相同。**

理解物质与运动时，可把物质想成“是什么东西”，把运动想成“它在变化”；理解运动与静止时，可联想变动与稳定两个方面。这样帮助回忆本节的两组关系。

> **使用范围：**“词性相同／不同”只是辅助联想，不是严格的语法判断或哲学判定标准；“运动”“静止”在这里都作为哲学范畴使用。哲学关系不只有这两种，“不可分割”与“对立统一”也不是互相排斥的分类。正式答题应根据概念含义写清关系。

#### 四、时间与空间

##### 1. 时间和空间的含义

**时间和空间是运动着的物质的基本存在形式。**

| 范畴 | 含义                         | 特点                                 |
| ---- | ---------------------------- | ------------------------------------ |
| 时间 | 物质运动的**持续性、顺序性** | **一维性**，即时间一去不复返         |
| 空间 | 物质运动的**广延性、伸张性** | **三维性**，即具有长、宽、高三个维度 |

##### 2. 物质运动与时空不可分割

- **时空是物质运动的时空**：不存在脱离物质运动的时间和空间。
- **物质运动是时空中的物质运动**：不存在脱离时间和空间的物质运动。

##### 3. 时间和空间的特点

| 特点       | 含义                                                             |
| ---------- | ---------------------------------------------------------------- |
| **客观性** | 时间和空间不以人的意志为转移                                     |
| **有限性** | 具体事物的时空是有限的                                           |
| **无限性** | 整个物质世界的时空是无限的                                       |
| **绝对性** | 时间和空间作为物质运动的存在形式，其客观实在性是不变的、无条件的 |
| **相对性** | 时间和空间的具体特性是可变的、有条件的，受物质运动及其状态制约   |

**易错辨析：**

- 时空的**绝对性**不是“所有人对时间和空间的认识都一样”，也不是说时间间隔和空间尺度在任何条件下都不变。
- 时空的**相对性**不是“由人的主观感受决定”，也不是只有速度达到某个极限时才出现。相对论中的时间间隔、空间尺度与运动状态有关，可辅助理解其具体特性的相对性。
- **有限性与无限性、绝对性与相对性相统一**，不能只承认其中一方面。

#### 五、物质世界的二重化

人类的出现，特别是**人类改造世界的实践活动**，极大地改变了世界的面貌，使世界发生了二重分化：**从自然界中分化出人类社会，从客观世界中分化出主观世界。**

##### 1. 自然界与人类社会

- **人类出现前**：物质世界与自然界完全等同。
- **人类出现后**：通过实践活动，从自然界中分化出人类社会。**人类社会是最高级的物质存在形式。**
- 分化不等于截然分开：**自然界与人类社会交叉重叠、相互作用**，并不是互不相干的两个世界。

##### 2. 客观世界与主观世界

**主观世界从客观世界中分化出来，具有相对独立性。**

> 辅助理解：**人脑像一面镜子**，面前的物质世界映入人脑，形成主观的意识世界。这个比喻帮助理解“反映”，但意识不是机械照搬。

**相对独立性——从两点理解：**

- **不完全一样**：主观世界是对客观世界的反映，但不与客观世界完全等同。
- **事物消失，记忆仍可保留**：即使某个客观事物已经不存在，主观世界中仍可能保留关于它的记忆。这里“客观世界没有了”指的是**具体事物消失**，不是整个客观世界不存在了。

**相对独立不等于独立存在：**主观世界不是独立存在的实体，也不是超然于客观世界之外的另一个世界；它不能完全脱离客观世界，而是**从属于客观世界**。（批判把二者看成独立本原的二元论。）

##### 3. 分化与统一的关键：实践

**人的实践活动，既是自然界与人类社会、客观世界与主观世界相分化的关键，也是它们相统一的关键。**

| 提问                                   | 答案                                   |
| -------------------------------------- | -------------------------------------- |
| 物质的唯一特性是什么？                 | **客观实在性**                         |
| 物质的根本属性和存在方式是什么？       | **运动**                               |
| 事物运动、变化和发展的内在原因是什么？ | **矛盾**                               |
| 运动着的物质的基本存在形式是什么？     | **时间和空间**                         |
| 物质与运动是什么关系？                 | **不可分割**                           |
| 运动与静止是什么关系？                 | **对立统一：绝对运动与相对静止相统一** |
| 物质运动与时空是什么关系？             | **不可分割**                           |

> 最后一组注意措辞：**运动是物质的存在方式，时空是运动着的物质的基本存在形式。**“运动的存在方式是时空”可作理解提示，正式答题用前面的规范表述。

### 第三节 意识及其与物质的关系

#### 一、意识的起源

##### 1. 意识是自然界长期发展的产物

意识的产生经历了三个发展阶段：

1. 由**一切物质所具有的反应特性**到**低等生物的刺激感应性**。
2. 由低等生物的刺激感应性到**高等动物的感觉和心理**。
3. 由高等动物的感觉和心理到**人类的意识**。

**意识是人所特有的。**不能把一般物质的反应特性、生物的刺激感应性或动物的心理直接等同于人的意识。

##### 2. 意识是社会历史发展的产物

**社会实践，特别是劳动，在意识的产生和发展中起着决定性作用。**在人们的劳动和交往中形成的语言，促进了意识的发展。

意识的产生是多种因素共同作用的结果，其中要区分：

| 因素 | 作用 |
| ---- | ---- |
| **劳动（实践）** | **决定性作用** |
| **语言** | **促进作用、重要影响** |

#### 二、意识的本质

**意识是人脑这样一种特殊物质的机能和属性，是客观世界的主观映像。**

##### 1. 意识是人脑的机能和属性

- **人脑是意识的物质器官**，意识的产生离不开人脑。
- **意识不等于人脑，也不等于人脑的分泌物。**人脑及其分泌物属于物质，不能把意识直接等同于物质。
- 具有人脑这一生理基础，还必须同客观世界发生联系，参与社会实践，才能形成人的意识。

##### 2. 意识是客观世界的主观映像

可用“镜子”辅助理解：客观世界通过人脑的反映，形成意识。但**人脑不是被动照镜子，而是会对反映的内容进行创造性的加工和改造**。

**意识是反映与能动的统一。**

| 理解方式 | 哲学判断 |
| -------- | -------- |
| 只强调能动性，否认意识对客观世界的反映，把意识看成独立的创造者 | **唯心主义** |
| 只强调被动反映，忽视能动性 | **旧唯物主义的直观反映论、机械反映论** |
| 承认意识对客观世界的反映，同时承认这种反映具有能动性 | **辩证唯物主义的能动反映论** |

**意识在内容上是客观的，在形式上是主观的。**

- **内容的客观性**：意识的内容来源于客观世界；即使是错误认识或幻想，也能在客观世界中找到其原型。
- **形式的主观性**：客观内容以感觉、概念、判断等主观形式表现出来，并受到主体经验、立场等因素的影响。
- “内容客观”不等于“所有意识都正确”，也不等于“意识本身是物质”。

马克思指出：

> “观念的东西不外是移入人的头脑并在人的头脑中改造过的物质的东西而已。”

| 关键词 | 理解 |
| ------ | ---- |
| 观念的东西 | **意识** |
| 移入人的头脑 | 强调**反映**，意识来源于客观物质世界 |
| 在人的头脑中改造过 | 强调**能动性**，意识不是机械复制 |

#### 三、意识对物质的反作用——意识的能动作用

**物质决定意识，意识对物质具有反作用。这种反作用就是意识的能动作用。**主要表现在四个方面：

1. **意识具有目的性和计划性。**人在行动前能够确定目标、制定计划。
2. **意识具有创造性。**意识能够加工感性材料、把握事物的本质和规律，并预见、构想未来。
3. **意识具有指导实践改造客观世界的作用。**人通过实践，把观念中的目标转化为现实。
4. **意识具有调控人的行为和生理活动的作用。**人的思想、情绪、意志等会影响行为和生理状态。

> 注意：意识对客观世界的改造作用必须**通过实践**实现，不能仅凭意识直接改变客观事物。意识的能动作用也不都是积极作用，要区分正确意识与错误意识的影响。

#### 四、物质与意识的辩证关系

**物质与意识是对立统一的关系：既相互区别，又相互联系。**

##### 1. 相互区别

- **物质是本原，意识是派生的；物质是第一性的，意识是第二性的。**
- 物质不是意识，意识不是物质，二者不能混同，也不能相互替代。

##### 2. 相互联系

- **物质决定意识，意识反作用于物质。**
- 意识对物质既有**依赖性**，又有**相对独立性**。
- 物质与意识可以在一定条件下相互转化，但要准确理解“转化”的含义：

| 课堂表述 | 准确理解 |
| -------- | -------- |
| 物质转化为意识 | 客观物质世界通过人的实践和认识活动，被反映为主观意识 |
| 意识转化为物质 | 意识通过指导实践，使观念中的目标转化为客观现实 |

> “转化”不是说物质直接变成精神实体，或思想凭空变出物质；关键在于**以实践为中介**。

#### 五、主观能动性与客观规律性的辩证统一

人的实践活动既要**尊重客观规律**，又要**发挥主观能动性**。

> 概念纠正：**主观能动性**指人在认识世界和改造世界中表现出来的自觉活动能力，不能标为“物质”；**客观规律性**是不以人的意志为转移的，不能标为“意识”。这组关系也不能简单等同于物质与意识两个范畴。

##### 1. 二者的辩证关系

- **尊重客观规律是正确发挥主观能动性的前提。**发挥能动性必须以遵循客观规律为基础。
- **只有充分发挥主观能动性，才能正确认识和利用客观规律。**尊重规律不意味着消极等待、无所作为。
- **实践是客观规律性与主观能动性统一的基础。**

##### 2. 正确发挥主观能动性的前提和条件

1. **从实际出发**是正确发挥人的主观能动性的前提。
2. **实践**是正确发挥人的主观能动性的根本途径。
3. 正确发挥人的主观能动性，还要依赖于**一定的物质条件和物质手段**。

**记忆：从实际出发——前提；实践——根本途径；物质条件和手段——保障条件。**

#### 六、意识与人工智能

##### 1. 人工智能的实质

按本节课程的概括，**人工智能实质上是对人脑组织结构与思维运行机制的模仿，是人类智能的物化。**

##### 2. 人工智能与人类意识的区别

人工智能可以模拟和扩展人脑的某些活动，甚至在**计算速度、准确度、程序化任务的执行能力**等方面超出人类所能。

**课堂结论：**即使是计算能力最强大、最先进的智能机器，也达不到人类智能的层级，无法真正具有人的意识，不可能取代或超越人类智能。

> 理解范围：这里的“不能取代或超越”针对的是**具有社会性、情感、意志等内容的人类智能整体**，不否认人工智能在某些具体任务上超过人类。以上按课程理论框架记录。

##### 3. 原因

1. **人类意识是知、情、意的统一体。**人工智能只是对人类理性智能的模拟和扩展，不具备情感、信念、意志等人类意识形式。
   - **知**：认知、认识活动。
   - **情**：情感、情绪等。
   - **意**：意志等。
2. **社会性是人的意识所固有的本质属性。**人工智能不可能真正具备人类的社会属性。
   - 联系人的本质理解：**人的本质在其现实性上是一切社会关系的总和。**
3. **人工智能难以完全具备理解自然语言真实意义的能力。**
4. **人工智能能够获得人类意识中可以化为数字信号的内容，但人脑中总有许多东西是无法被化约的。**即不能把人类意识的全部内容都归结为可数字化的信息。

### 第四节 世界的物质统一性原理

#### 一、原理内容

**世界的统一性在于它的物质性，世界统一于物质。**

1. **自然界是物质的。**自然界的存在和发展不以人的意志为转移。
2. **人类社会本质上是生产实践基础上形成的物质体系。**社会生活虽然离不开人的有意识活动，但人类社会仍具有客观物质性。
3. **人的意识统一于物质。**意识是物质世界长期发展的产物，是人脑的机能和属性，是客观世界的主观映像。

> 注意：**意识统一于物质，不等于意识就是物质。**这里强调意识对物质的依赖性，不能把二者混同。

#### 二、理论地位

**世界的物质统一性原理是辩证唯物主义最基本、最核心的观点，是马克思主义的基石。**

#### 三、方法论要求

**一切从实际出发，是世界的物质统一性原理在现实生活中和实际工作中的生动体现。**

认识问题、作出判断和开展工作，都应以客观实际为依据，从实际情况及其变化出发。

**什么是方法论？**

- **通俗理解**：方法论就是“原理教会我们的道理”，重点在于指导我们**怎样认识问题、怎样做事**。
- **规范理解**：方法论是人们认识世界和改造世界所遵循的根本方法的理论。

| 层次 | 回答的问题 | 本节对应内容 |
| ---- | ---------- | ------------ |
| 原理 | 世界是什么样的？ | **世界统一于物质** |
| 方法论 | 据此应怎样认识问题、开展工作？ | **一切从实际出发** |

> 记忆：**世界统一于物质——一切从实际出发。**术语是“物质统一性”，不要写成“物质同一性”。
