# 第 2 章 物理层

## 2.1 通信基础

### 2.1.1 基本概念

#### 1. 物理层解决什么问题

物理层研究如何利用传输介质，在相邻设备之间传输**原始比特流**。

- 传输单位：**比特（bit）**。
- 关注内容：用什么信号表示 0 和 1、信号如何同步、接口如何连接、传输速率等。
- 向数据链路层提供比特传输服务，尽可能屏蔽底层介质与设备的差异。
- 不负责识别帧的目的 MAC 地址，也不负责选择到目的网络的路由。

> 物理层关心“0 和 1 怎么传过去”；传输介质是承载信号的物理通路，不能直接把“物理层”等同于“一根网线”。

#### 2. 信息、数据与信号

| 概念 | 含义                             | 例子                       |
| ---- | -------------------------------- | -------------------------- |
| 信息 | 通信双方希望表达的内容           | 一段话、一幅图像           |
| 数据 | 信息的载体或表示形式             | 文字编码、图像的二进制数据 |
| 信号 | 数据在传输过程中的电气或电磁表现 | 电压波形、无线电波、光脉冲 |

数据和信号都可以分为模拟与数字两类。

- **模拟数据**：取值连续，例如连续变化的声音。
- **数字数据**：取值离散，例如二进制序列。
- **模拟信号**：表示数据的信号参数连续取值。
- **数字信号**：表示数据的信号状态离散取值。

**注意：数据类型与传输信号类型不是一一绑定的。**

- 数字数据可以用数字信号传，也可以调制成模拟信号传。
- 模拟数据可以用模拟信号传，也可以先数字化，再用数字信号传。

#### 3. 码元：一次信号状态能表示多少信息

**码元（symbol）**：用一段固定时长的信号波形表示一个离散符号时，这段波形就是一个码元。

这段固定时长称为**码元宽度**或**码元周期**。

> 比特是信息量的单位；码元是承载信息的信号单位。**一个码元不一定只携带 1 bit。**

假设共有 `V` 种可区分的码元状态，采用常见的等长二进制映射，且 `V = 2^n`：

```text
每个码元携带的比特数 n = log₂V
码元状态数 V = 2^n
```

| 可区分的状态数 V | 每码元携带信息量 | 可以理解为                     |
| ---------------- | ---------------- | ------------------------------ |
| 2                | 1 bit            | 一次从 0、1 中选一个           |
| 4                | 2 bit            | 一次从 00、01、10、11 中选一个 |
| 8                | 3 bit            | 一次表示 3 位二进制数          |
| 16               | 4 bit            | 一次表示 4 位二进制数          |
| 64               | 6 bit            | 一次表示 6 位二进制数          |
| 256              | 8 bit            | 一次表示 8 位二进制数          |

例如：不是“4 个码元才能表示 2 bit”，而是**有 4 种可选状态时，每发送其中一个状态，就能表示 2 bit**。

**注意：这里的状态不一定只是电压高低，还可能由振幅、频率、相位或它们的组合区分。**

##### （1）为什么 4 种状态能表示 2 bit

先看两位二进制数一共有多少种可能：

| 两位二进制数 | 可以安排的信号状态 |
| ------------ | ------------------ |
| 00           | 状态 A             |
| 01           | 状态 B             |
| 10           | 状态 C             |
| 11           | 状态 D             |

发送端要传 `10`，就发送状态 C。接收端看到 C，查同样的约定，恢复 `10`。

这里的一次发送就完成了两位数据的表达，因此一个码元携带 2 bit。

推广到 n 位二进制数：

```text
每一位有 2 种可能
n 位共有 2^n 种组合

要一次区分这 2^n 种组合，就需要 2^n 种可区分的信号状态
```

##### （2）“状态更多”与“发送次数更多”不同

以每秒发送 1000 个码元为例：

| 方案   | 每秒发送次数 | 可选状态数 | 每次携带信息量 | 比特率   |
| ------ | ------------ | ---------- | -------------- | -------- |
| 方案 A | 1000         | 2          | 1 bit          | 1000 b/s |
| 方案 B | 1000         | 4          | 2 bit          | 2000 b/s |
| 方案 C | 1000         | 16         | 4 bit          | 4000 b/s |

三种方案发送码元的节奏相同，差别在于每次发送能让接收端区分多少种情况。

> 提高数据速率有两个基本方向：**单位时间发送更多码元，或让每个码元表达更多信息。** 两者在真实信道中都受到限制。

##### （3）不要把“码元种类数”当成“本次码元个数”

例如发送 `16` 个四进制码元：

```text
码元个数 = 16 个
码元种类数 V = 4
每码元携带信息量 = log₂4 = 2 bit

总信息量 = 16 × 2 = 32 bit
```

这里不能算 `log₂16`，因为 16 是发送了多少个码元，不是可选状态数。

#### 4. 信源、信道与信宿

| 部分       | 作用                           |
| ---------- | ------------------------------ |
| 信源       | 产生并发送数据的源头           |
| 发送变换器 | 将数据转换为适合信道传输的信号 |
| 信道       | 信号传输的通道                 |
| 接收变换器 | 将接收信号还原为数据           |
| 信宿       | 接收数据的终点                 |
| 噪声源     | 对信号产生干扰的来源           |

单向通信过程：信源产生数据，发送端将其转换为信号；信号经过信道到达接收端，接收端恢复数据并交给信宿。

**信道与物理线路不完全相同：**

- 信道强调某个方向、某种资源上的信号传输。
- 一条双向通信线路可以包含发送和接收两个方向的信道。
- “两个信道”不必机械理解为“两根独立电缆”，同一介质可通过频率等资源划分承载不同信道。

信道的分类：

| 分类依据       | 类型               |
| -------------- | ------------------ |
| 传输的信号形式 | 模拟信道、数字信道 |
| 使用的传输介质 | 有线信道、无线信道 |

#### 5. 基带信号、宽带信号与传输方式

| 概念                 | 含义                                       |
| -------------------- | ------------------------------------------ |
| 基带信号             | 信源发出的、尚未搬移到高频载波上的原始信号 |
| 基带传输             | 在信道中直接传输基带信号                   |
| 宽带传输（本节语境） | 将基带信号调制到高频载波上，再在信道中传输 |

> **基带传输看“直接传”；调制后的传输看“加载到载波上再传”。**

**注意：这里的“宽带传输”是信号传输方式，不能简单理解为日常所说的“网速很快”。**

##### （1）为什么要把信号加载到载波上

原始信号的频率范围不一定适合所用信道。发送端可以用原始数据控制一个较高频率载波的振幅、频率或相位，让它携带数据经过信道。

接收端再根据约定，从载波的变化中恢复数据，这就是解调。

**数据内容可以相同，承载数据的信号形式却发生了变化。**

例如要发送二进制数据 `101`：

- 基带数字传输可直接用电平或电平跳变表示。
- ASK 可用不同振幅表示。
- FSK 可用不同频率表示。
- PSK 可用不同相位表示。

##### （2）模拟信号不意味着携带模拟数据

FSK 发送端根据数据 0、1 选择两种不同频率，信道里传播的是调制后的模拟波形，但所表达的数据仍然是离散的 0、1。

同样，声音原本是模拟数据，经过 PCM 后也能以数字信号传输。

> 遇到分类题要分两次判断：**原始数据是什么类型？经过处理后输出什么信号？**

#### 6. 串行传输与并行传输

| 项目         | 串行传输                   | 并行传输                       |
| ------------ | -------------------------- | ------------------------------ |
| 发送方式     | 比特按顺序逐个发送         | 多个比特通过多条通道同时发送   |
| 通道与布线   | 相对少、简单               | 相对多、复杂                   |
| 本节典型场景 | 长距离数据通信、计算机网络 | 短距离通信、部分计算机内部连接 |

例如：发送一个 8 bit 数据，串行传输按次序发送这 8 位；8 位并行传输可以通过 8 条数据通道同时发送。

**注意：并行不代表实际速率一定比串行高。** 实际速度还受每条通道的工作速率、同步要求和传输距离等因素影响。

#### 7. 单工、半双工与全双工

| 方式   | 能否双向通信 | 能否同时双向 | 例子                                 |
| ------ | ------------ | ------------ | ------------------------------------ |
| 单工   | 否           | 否           | 无线电广播、电视广播                 |
| 半双工 | 能           | 不能         | 对讲机、集线器连接的传统共享式以太网 |
| 全双工 | 能           | 能           | 双方可以同时说话和听话的电话通信     |

- **单工**：只有一个方向。
- **半双工**：双方都能发，但必须轮流发。
- **全双工**：双方可以同时发送和接收。

按本节信道模型：

- 单工只需一个单向信道。
- 半双工可在同一信道上分时双向传输。
- 全双工需要两个可独立工作的方向，每个方向一个信道。

**注意：半双工是“不能同时收发”，不是“只能接收”或“只能发送”。**

#### 8. 波特率、比特率与码元周期

##### （1）波特率

波特率又称**码元传输速率**或**调制速率**，表示每秒传输的码元数，单位为 **Baud（波特）**。

用 `R_s` 表示波特率，用 `T_s` 表示码元周期：

```text
R_s = 1 / T_s
```

例如：每个码元持续 `0.5 ms`，则：

```text
R_s = 1 / (0.5 × 10^-3)
    = 2000 Baud
```

##### （2）比特率

比特率又称**信息传输速率**，表示每秒传输的比特数，单位为 **bit/s 或 b/s**。

用 `R_b` 表示比特率：

```text
R_b = R_s × 每码元携带的比特数
    = R_s × log₂V

R_s = R_b / log₂V
```

例如：波特率为 `2000 Baud`，共有 `16` 种码元状态：

```text
每码元携带的比特数 = log₂16 = 4 bit
R_b = 2000 × 4 = 8000 b/s
```

##### （3）做题容易混淆的地方

- 波特率数的是**码元**，比特率数的是**比特**。
- 在每码元恰好携带 1 bit 的条件下，两者数值相等，但单位和含义不同。
- 在波特率固定时，增加每码元携带的信息量，可以提高比特率。
- 波特率不是“电平每秒跳变的次数”：连续相同码元也要占用各自的码元周期。
- 波特率也不是高频载波的振荡频率，一个码元内可以包含多个载波周期。

##### （4）一个完整的速率与发送时间例题

已知：

- 每个码元持续 `2 μs`。
- 使用 `8` 种可区分状态。
- 要发送 `1500 B` 数据。
- 忽略首部、编码冗余和其他开销。

第一步，算每秒能传多少个码元：

```text
R_s = 1 / (2 × 10^-6)
    = 500000 Baud
```

第二步，算每个码元携带多少比特：

```text
n = log₂8 = 3 bit
```

第三步，算每秒传多少比特：

```text
R_b = 500000 × 3
    = 1500000 b/s
    = 1.5 Mb/s
```

第四步，先将字节换成比特，再算发送时间：

```text
数据量 = 1500 × 8 = 12000 bit

发送时间 = 12000 / 1500000
         = 0.008 s
         = 8 ms
```

也可以先算总码元数：

```text
总码元数 = 12000 / 3 = 4000 个
发送时间 = 4000 × 2 μs = 8000 μs = 8 ms
```

两条计算路径应得到同一结果。

##### （5）同样是“频率”，为什么不能乱乘

本章可能同时出现：

- 载波频率：一秒振荡多少个周期。
- 码元速率：一秒发送多少个码元。
- 采样频率：一秒对模拟信号采样多少次。

三者计数的对象不同。只有题目明确它们之间的关系，才能互相换算。

例如一个码元内载波振荡 10 次，载波频率为 `1 MHz`：

```text
一个载波周期 = 1 / 10^6 s = 1 μs
一个码元持续 = 10 × 1 μs = 10 μs
码元速率 = 1 / 10 μs = 100000 Baud
```

不能直接把 `1 MHz` 当作 `1 MBaud`。

#### 9. 带宽的两种含义

| 使用场景                   | 带宽表示什么                 | 单位 |
| -------------------------- | ---------------------------- | ---- |
| 模拟通信、奈氏与香农公式   | 信道能通过的频率范围宽度     | Hz   |
| 计算机网络中的链路能力描述 | 链路可支持的最大数据传输速率 | b/s  |

频率带宽的计算：

```text
W = 最高频率 - 最低频率
```

例如：信道允许 `300 Hz～3400 Hz` 的频率通过：

```text
W = 3400 - 300 = 3100 Hz
```

**注意：Hz 与 b/s 不能直接互换。** 必须结合调制方式、码元状态数、信噪比等条件。

#### 10. 本章常用单位

```text
1 B = 8 bit

1 kb/s = 10^3 b/s
1 Mb/s = 10^6 b/s
1 Gb/s = 10^9 b/s

1 kHz = 10^3 Hz
1 MHz = 10^6 Hz

1 ms = 10^-3 s
1 μs = 10^-6 s
1 ns = 10^-9 s
```

网络速率中的 `k、M、G` 通常按十进制换算。`B` 是字节，`b` 是比特，做题先统一单位。

### 2.1.2 信道的极限容量

#### 1. 为什么传输速率不能随便提高

实际信道会使信号衰减、失真，并引入噪声。

影响接收端识别信号的因素包括：

- 码元传输速率。
- 信号传输距离。
- 噪声干扰强度。
- 传输介质的质量。
- 信道允许通过的频率范围。

**失真不一定立即导致错误。** 只要接收端还能正确判断原来的符号，就仍然可以恢复数据。

#### 2. 码间串扰

信道带宽有限，信号中的部分高频成分无法有效通过，接收波形会变形、展宽，使前后码元之间的界限不清楚，这种现象称为**码间串扰**。

> 可以理解为：前一个码元的影响拖到了后一个码元的时间内，接收端难以区分。

**注意：码间串扰不等于外界噪声。** 即使没有噪声，带宽有限也会限制码元速率。

#### 3. 奈奎斯特定理（奈氏准则）

##### （1）适用条件

**理想低通信道：无噪声、带宽有限。**

设信道带宽为 `W Hz`，则避免码间串扰时的极限码元传输速率为：

```text
R_s,max = 2W  Baud
```

若每个码元有 `V` 种可区分状态：

```text
R_b,max = 2W log₂V  b/s
```

##### （2）公式如何理解

```text
2W：每秒最多能传多少个码元
log₂V：每个码元携带多少个比特

二者相乘：每秒最多传多少比特
```

##### （3）重要结论

- 在该理想低通模型中，码元速率有 `2W` 的上限。
- 带宽越大，允许的码元速率越高。
- 当 `V` 固定时，比特率也有对应上限。
- 奈氏准则本身没有引入噪声限制；在理想模型中，可通过增加状态数提高每码元信息量。
- 实际有噪声的信道不能靠无限增加状态数，获得无限可靠比特率。

**注意：`2W` 是极限波特率，不应看到 `2W` 就直接写成 b/s；只有每码元携带 1 bit 时才在数值上相等。**

##### （4）例题：求最大比特率

理想低通信道带宽为 `3 kHz`，每个码元有 `16` 种状态。

```text
W = 3000 Hz
R_s,max = 2 × 3000 = 6000 Baud
每码元比特数 = log₂16 = 4

R_b,max = 6000 × 4 = 24000 b/s = 24 kb/s
```

##### （5）例题：反求最少状态数

理想低通信道带宽为 `4 kHz`，希望达到 `32 kb/s`。

```text
R_s,max = 2 × 4000 = 8000 Baud
每码元至少需要的比特数 = 32000 / 8000 = 4
最少状态数 V = 2^4 = 16
```

若题目采用每码元携带整数位的固定长度二进制映射，计算结果不是整数时，应将所需比特数向上取整，再求状态数。

##### （6）例题：反求最小带宽

题目采用理想低通模型，使用 16 种码元状态，希望达到 `48 kb/s`。

```text
R_b ≤ 2W log₂V

W ≥ R_b / (2log₂V)
  = 48000 / (2 × 4)
  = 6000 Hz
  = 6 kHz
```

这是该模型给出的带宽要求。不能在没有其他条件的情况下，将它说成实际设备一定能达到的指标。

##### （7）状态数增加多少，比特率才会翻倍

带宽固定，码元速率也固定时：

```text
R_b 与 log₂V 成正比
```

因此，状态数从 4 增加到 8：

```text
每码元比特数从 2 增加到 3
比特率变为原来的 3/2 倍
```

状态数翻倍，不等于比特率翻倍。

如果每码元信息量从 n bit 翻倍为 2n bit：

```text
旧状态数 = 2^n = V
新状态数 = 2^(2n) = V²
```

例如从 4 种状态增加到 16 种状态，每码元信息量才从 2 bit 翻倍到 4 bit。

##### （8）两个“上限”的区别

当题目没有限定 V 时，奈氏准则直接给出的码元速率上限是 `2W`。

如果还给出 V，才能进一步得到该状态数下的比特率上限 `2Wlog₂V`。

所以，以下两句话并不矛盾：

- 理想低通信道的码元速率受带宽限制。
- 在无噪声的理想模型中，通过增加状态数仍可提高每码元信息量。

**真实噪声信道还受香农容量限制，不能将第二句话无限推广到实际系统。**

#### 4. 香农定理

香农定理给出**带宽有限、存在高斯白噪声的信道**的理论容量。

```text
C = W log₂(1 + S/N)  b/s
```

| 符号 | 含义                                   | 使用要求              |
| ---- | -------------------------------------- | --------------------- |
| C    | 信道容量，即可靠信息传输速率的理论上限 | 单位 b/s              |
| W    | 信道频率带宽                           | 单位 Hz               |
| S    | 信号平均功率                           | 与 N 使用相同功率单位 |
| N    | 噪声平均功率                           | 与 S 使用相同功率单位 |
| S/N  | 信号功率与噪声功率之比                 | 无单位的数值比        |

在相应理论条件下，只要传输速率低于容量，就可以通过适当编码，使误码率任意接近零；这不表示任何实际设备或编码都自动做到无差错。

#### 5. 信噪比与分贝换算

信噪比常见两种表示：

- 直接给功率比，例如 `S/N = 1000`。
- 给分贝值，例如 `30 dB`。

```text
信噪比的分贝值 = 10 log₁₀(S/N)

S/N = 10^(分贝值 / 10)
```

| 分贝值 | 对应 S/N |
| ------ | -------- |
| 0 dB   | 1        |
| 10 dB  | 10       |
| 20 dB  | 100      |
| 30 dB  | 1000     |
| 40 dB  | 10000    |

**注意：**

- 给 `30 dB` 时，先换成 `1000`，再代入香农公式。
- 不能将 `30` 直接作为 `S/N`。
- `0 dB` 表示信号功率与噪声功率相等，不是没有噪声，也不是信噪比为 0。
- 公式是 `log₂(1 + S/N)`，一般不能漏掉 `1 +`。

#### 6. 香农定理的重要结论

- 在其他条件固定时，带宽越大，容量越大。
- 在其他条件固定时，信噪比越大，容量越大。
- 带宽和信噪比给定后，可靠信息传输速率的上限确定。
- 增加码元状态数不能突破香农容量。
- 香农容量是理论极限，实际系统还受到编码、硬件和实现开销等限制。

#### 7. 例题：先换算 dB，再求容量

信道带宽为 `3 kHz`，信噪比为 `30 dB`。

```text
S/N = 10^(30/10) = 1000

C = 3000 × log₂(1 + 1000)
  = 3000 × log₂1001
  ≈ 29.9 kb/s
```

若题目允许近似，可利用 `2^10 = 1024`，将结果估算为约 `30 kb/s`。

#### 8. 奈氏准则与香农定理对比

| 对比点                   | 奈氏准则               | 香农定理                 |
| ------------------------ | ---------------------- | ------------------------ |
| 本节使用模型             | 理想无噪声低通信道     | 带宽受限的高斯白噪声信道 |
| 主要限制来源             | 带宽有限造成的码间串扰 | 有限带宽与噪声           |
| 公式                     | R_b,max = 2W log₂V     | C = W log₂(1 + S/N)      |
| 是否显式使用码元状态数 V | 是                     | 否                       |
| 是否显式使用信噪比       | 否                     | 是                       |
| 核心关注                 | 码元最多能传多快       | 信息最多能可靠传多快     |

##### （1）为什么香农公式里没有码元状态数

奈氏公式中的 V 描述了指定编码或调制方案一次可以区分多少种状态。

香农容量描述的是：给定带宽、信号功率与噪声功率后，这个信道总体上允许多高的可靠信息速率。

因此，香农公式不需要先指定“采用 4 种还是 16 种状态”。选用某个具体调制方案，实际速率还可能受到这个方案本身的限制。

可以这样区分：

| 问法                               | 关注点                 |
| ---------------------------------- | ---------------------- |
| 采用 4 种码元状态时最多多快        | 特定状态数下的传输限制 |
| 给定带宽和信噪比，这个信道容量多大 | 信道的可靠传输理论上限 |

##### （2）容量以下不是“天然不会错”

如果算得信道容量是 `30 kb/s`：

- 使用 `20 kb/s`，不代表不做任何处理就自动没有误码。
- 它表示在适用的理论条件下，有可能通过合适的编码等方法，使误码率非常低。
- 使用超过容量的速率，就不能靠无限改进编码达到任意低误码率的可靠传输目标。

> 香农定理给出可达到目标的理论边界，不直接给出某台设备的具体实现方案。

#### 9. 同时给带宽、状态数和信噪比怎么办

若题目采用本节低通信道模型，同时给出 `W、V、S/N`，通常应分别计算两种约束，取较小值作为允许速率的上界。

```text
奈氏约束 R_N = 2W log₂V
香农约束 R_S = W log₂(1 + S/N)

R_b ≤ min(R_N, R_S)
```

例如：`W = 3 kHz`，`V = 4`，`S/N = 1023`。

```text
R_N = 2 × 3000 × log₂4 = 12000 b/s
R_S = 3000 × log₂1024 = 30000 b/s

取较小值：12000 b/s = 12 kb/s
```

> 题目若问指定调制方式下的最大速率，要看状态数限制；若单独问信道容量，香农公式描述的是噪声信道本身的容量上限。

#### 10. 公式选用步骤

1. 先看问的是**波特率、比特率，还是信道容量**。
2. 找出带宽 `W`，换成 Hz。
3. 给出码元状态数，就求 `log₂V`。
4. 给出信噪比分贝值，就先换算为无单位功率比。
5. 判断适用的信道模型及限制；同时受两者约束时分别计算。
6. 最后标明单位，不把 Baud 写成 b/s。

#### 11. 香农公式的反向计算

##### （1）已知目标速率，求所需信噪比

从公式开始变形：

```text
C = W log₂(1 + S/N)

C/W = log₂(1 + S/N)
2^(C/W) = 1 + S/N

S/N = 2^(C/W) - 1
```

例如：带宽 `4 kHz`，希望容量至少达到 `24 kb/s`。

```text
S/N ≥ 2^(24000/4000) - 1
    = 2^6 - 1
    = 63
```

若需要写成分贝：

```text
信噪比 ≥ 10log₁₀63 dB
       ≈ 18 dB
```

这个数是满足容量约束的理论门槛，实际实现通常还需要裕量。

##### （2）已知信噪比与目标速率，求带宽

```text
W ≥ 目标速率 / log₂(1 + S/N)
```

例如：`S/N = 255`，目标速率 `64 kb/s`。

```text
W ≥ 64000 / log₂256
  = 64000 / 8
  = 8000 Hz
```

##### （3）容量翻倍，信噪比需要怎样变

设带宽固定，原功率比为 x：

```text
旧容量 C₁ = Wlog₂(1 + x)
新容量 C₂ = 2C₁

log₂(1 + 新功率比) = 2log₂(1 + x)
1 + 新功率比 = (1 + x)²

新功率比 = (1 + x)² - 1
```

例如原来 `S/N = 15`：

```text
旧容量 = Wlog₂16 = 4W
翻倍目标 = 8W

新 S/N = 2^8 - 1 = 255
```

**结论：在带宽固定时，容量与信噪比不是线性关系。不能说信噪比翻倍，容量也翻倍。**

#### 12. 信道容量综合例题

已知理想低通模型下带宽为 `4 kHz`，存在噪声，功率比 `S/N = 255`，调制方式使用 `8` 种状态。

##### （1）按状态数计算奈氏约束

```text
每码元信息量 = log₂8 = 3 bit
极限码元速率 = 2 × 4000 = 8000 Baud

R_N = 8000 × 3 = 24000 b/s
```

##### （2）计算香农容量

```text
C = 4000 × log₂(1 + 255)
  = 4000 × 8
  = 32000 b/s
```

##### （3）判断现有方案的上界

```text
R_b ≤ min(24000, 32000)
    = 24000 b/s
```

##### （4）如果改成 16 种状态

```text
R_N = 2 × 4000 × log₂16
    = 32000 b/s
```

两种约束在数值上都为 `32 kb/s`。这说明状态数限制已提高到容量对应的数值，不能据此承诺实际系统恰好达到容量并零误码。

##### （5）如果继续改成 64 种状态

```text
R_N = 2 × 4000 × log₂64
    = 48000 b/s
```

但带宽和信噪比未变，香农容量仍为 `32 kb/s`，所以不能突破这个可靠传输上限。

> 这道题说明：增加状态数一开始可能有用，但增加到一定程度后，限制来自噪声信道容量。

### 2.1.3 编码与调制

#### 1. 编码与调制的区别

按本节的分类口径：

- **编码**：将数据转换为数字信号。
- **调制**：将数据加载到载波上，形成适合传输的模拟信号。

| 原始数据 | 输出信号 | 典型处理方式                              |
| -------- | -------- | ----------------------------------------- |
| 数字数据 | 数字信号 | RZ、NRZ、NRZI、曼彻斯特、差分曼彻斯特编码 |
| 模拟数据 | 数字信号 | PCM：采样、量化、编码                     |
| 数字数据 | 模拟信号 | ASK、FSK、PSK、QAM                        |
| 模拟数据 | 模拟信号 | 直接传输，或采用 AM、FM、PM 等模拟调制    |

**注意：PCM 中文名含“调制”，但在本节分类中，它实现的是模拟数据数字化。不要只看名称判断输出信号类型。**

#### 2. 数字数据编码：先分清位边界与位中间

看波形时，先按**每一位数据占用的时间**划格，再观察：

- 整个位周期内是什么电平？
- 位周期中间是否固定跳变？
- 位周期开始处是否跳变？
- 跳变方向是否用来表示数据？

以下使用 `H` 表示高电平、`L` 表示低电平、`Z` 表示零电平。

**注意：低电平与零电平不是必然相同。** 例如极性归零码可以用正电压、负电压分别表示数据，再返回零电压。

##### （1）为什么收发双方需要时钟同步

发送端按一个个位周期发送数据，接收端也必须知道一个位周期持续多久，以及每一位从哪里开始。

假设发送端连续发送 8 个 1，采用 NRZ，整段时间都维持高电平。接收端不能靠“看到了几个高电平块”判断位数，因为波形上可能只有一整块。

它需要按位周期把这一整段划成 8 个时间间隔。

如果接收时钟越来越偏，采样点可能移到相邻位，造成漏读、重读或误判。

##### （2）自同步编码为什么有帮助

如果编码规则保证周期性出现可识别的跳变，接收端就可以利用这些跳变校准自己的时钟。

曼彻斯特和差分曼彻斯特在每位中间安排一次跳变，所以即使数据长时间全是 0 或全是 1，也有同步线索。

**注意：自同步表示信号自身提供时钟恢复线索，不表示接收端不需要时钟电路。**

##### （3）波形上的竖线不全是信号跳变

教材波形图中常同时出现：

- 用来分隔位周期的虚线。
- 信号电平变化产生的实线竖边。

读图时，先认清辅助线和真正的信号线。不能把每一条位边界虚线都算作电平跳变。

#### 3. 归零编码 RZ

**规则：** 用高、低电平区分 1 和 0，但每个位周期内都要返回零电平。

以下按“高表示 1，低表示 0”的约定：

| 数据位 | 前半位 | 后半位 |
| ------ | ------ | ------ |
| 1      | H      | Z      |
| 0      | L      | Z      |

**特点：**

- 每个位周期都有归零动作，便于提取同步信息。
- 归零占用一部分时间，通常比 NRZ 需要更多带宽。
- 不能把归零中的“零电平”误认为“数据 0”。

#### 4. 非归零编码 NRZ

**规则：** 用不同电平表示 0 和 1，整个位周期保持相应电平，不要求回零。

例如约定 `H = 1，L = 0`：

| 数据位 | 前半位 | 后半位 |
| ------ | ------ | ------ |
| 1      | H      | H      |
| 0      | L      | L      |

**特点：**

- 不额外安排归零，带宽利用率较高。
- 长串相同数据会使电平一直不变，不便于接收端恢复时钟。
- 不具备内在自同步能力，需要另外的同步机制。

> “连续没有跳变”不等于“没有数据”，可能是在连续发送相同的 0 或 1。

#### 5. 反向非归零编码 NRZI

**规则：** 根据位周期开始处是否发生电平跳变表示数据。

本笔记采用教材图中的约定：

```text
位开始处有跳变：0
位开始处无跳变：1
```

**特点：**

- 关注“变不变”，不直接依赖绝对高、低电平。
- 跳变有助于恢复时钟。
- 按上述约定，连续 0 会连续产生边界跳变；连续 1 仍可能长时间无跳变。
- 因此不能仅凭 NRZI 规则就保证任意数据都能自同步，通常还需要限制长串无跳变等机制。

**注意：不同协议可能采用相反约定，做题以题干为准。**

#### 6. 曼彻斯特编码

**规则：每个位周期中间必有一次跳变，跳变方向表示数据，同时提供同步信息。**

本笔记采用教材图中的约定：

```text
位中间高 → 低：1
位中间低 → 高：0
```

| 数据位 | 前半位 | 后半位 | 中间跳变 |
| ------ | ------ | ------ | -------- |
| 1      | H      | L      | 下降沿   |
| 0      | L      | H      | 上升沿   |

**特点：**

- 不论数据是什么，每位中间都有跳变，具有自同步能力。
- 一个数据位由两个半位信号间隔表示。
- 相比 NRZ，需要更高的信号变化能力，通常占用更多带宽。
- **传统以太网**采用曼彻斯特编码，不能推广为所有速率的以太网都采用它。

##### （1）曼彻斯特编码的读图方法

1. 找到位边界。
2. 看每位**中间**的跳变方向。
3. 按题干给出的 0、1 约定译码。

##### （2）带宽或信号速率计算

常见题目若按每个半位信号间隔计一个信号单元：

```text
半位信号单元速率 = 2 × 数据比特率
数据比特率 = 半位信号单元速率 / 2
```

例如：数据速率为 `10 Mb/s`，对应每秒 `20 M` 个半位信号间隔。

**注意：题目对“码元”的计数口径要看清。不要将曼彻斯特的一对半位直接当成两个彼此独立、各携带 1 bit 的码元；它们合起来才表示一个数据位。**

#### 7. 差分曼彻斯特编码

**规则：每个位周期中间必有跳变，但数据由位开始处是否跳变决定。**

按教材约定：

```text
位中间：一定跳变，仅用于同步

位开始处有跳变：0
位开始处无跳变：1
```

**特点：**

- 自同步能力强。
- 根据相对变化判断数据，不依赖绝对电平极性。
- 相比 NRZ 占用更多带宽。
- 传统令牌环网中采用过这种编码。

##### （1）差分曼彻斯特编码的读图方法

1. 先确认每一位中间都有跳变。
2. 比较本位开始时的电平与上一位结束时的电平。
3. 有跳变读 0，无跳变读 1。
4. 若第一位之前的电平未知，且题目未给其他条件，则第一位可能无法唯一判断。

##### （2）与曼彻斯特、NRZI 的区别

| 编码         | 数据看哪里     | 位中间是否强制跳变 |
| ------------ | -------------- | ------------------ |
| NRZI         | 位开始处变不变 | 否                 |
| 曼彻斯特     | 位中间跳变方向 | 是                 |
| 差分曼彻斯特 | 位开始处变不变 | 是                 |

> **曼彻斯特：中间方向定数据。差分曼彻斯特：开头变不变定数据，中间只管同步。**

#### 8. 编码综合示例

待编码数据为 `1 0 1 1`；NRZI 和差分曼彻斯特的初始电平均设为 `L`。

约定与前文一致：曼彻斯特下降沿表示 1；NRZI 和差分曼彻斯特的位开始处跳变表示 0。

| 数据位置                 | 第 1 位 | 第 2 位 | 第 3 位 | 第 4 位 |
| ------------------------ | ------- | ------- | ------- | ------- |
| 数据                     | 1       | 0       | 1       | 1       |
| RZ：前半／后半           | H／Z    | L／Z    | H／Z    | H／Z    |
| NRZ：整位电平            | H       | L       | H       | H       |
| NRZI：整位电平           | L       | H       | H       | H       |
| 曼彻斯特：前半／后半     | H／L    | L／H    | H／L    | H／L    |
| 差分曼彻斯特：前半／后半 | L／H    | L／H    | H／L    | L／H    |

差分曼彻斯特第 2 位为什么仍是 `L／H`？第 1 位结束在 H，第 2 位是 0，因此位开始先从 H 跳到 L；中间再从 L 跳到 H。

##### （1）差分曼彻斯特示例逐位推导

仍取数据 `1 0 1 1`，初始电平 L。

| 第几位 | 数据 | 上一位末电平 | 位开始是否跳变 | 本位前半 | 中间固定跳变后 |
| ------ | ---- | ------------ | -------------- | -------- | -------------- |
| 1      | 1    | L（初始）    | 否             | L        | H              |
| 2      | 0    | H            | 是             | L        | H              |
| 3      | 1    | H            | 否             | H        | L              |
| 4      | 1    | L            | 否             | L        | H              |

做这类题时，**每处理完一位，要把该位的结束电平带到下一位**。不能每一位都重新从初始电平 L 开始。

##### （2）差分曼彻斯特反向译码

已知初始电平 H，四个位周期的前、后半位分别为：

| 位周期 | 前半 | 后半 |
| ------ | ---- | ---- |
| 1      | H    | L    |
| 2      | H    | L    |
| 3      | L    | H    |
| 4      | L    | H    |

按“边界跳变表示 0，边界不变表示 1”：

1. 第 1 位：初始 H，本位开始也是 H，没有跳变，读 1。
2. 第 2 位：上一位结束 L，本位开始 H，有跳变，读 0。
3. 第 3 位：上一位结束 L，本位开始 L，没有跳变，读 1。
4. 第 4 位：上一位结束 H，本位开始 L，有跳变，读 0。

```text
译码结果：1 0 1 0
```

每一位的中间虽然都在变，但这里不靠中间跳变方向判 0、1。

##### （3）NRZI 反向译码

已知初始电平 H，各位周期内电平为：

```text
H、L、L、H、H
```

按“有边界跳变为 0，无边界跳变为 1”：

| 位序号 | 之前电平 | 本位电平 | 有无跳变 | 数据 |
| ------ | -------- | -------- | -------- | ---- |
| 1      | H        | H        | 无       | 1    |
| 2      | H        | L        | 有       | 0    |
| 3      | L        | L        | 无       | 1    |
| 4      | L        | H        | 有       | 0    |
| 5      | H        | H        | 无       | 1    |

```text
译码结果：1 0 1 0 1
```

NRZI 不要求位中间强制跳变，不能额外给它套用差分曼彻斯特的中间翻转规则。

##### （4）曼彻斯特的位边界为什么有时也会跳变

采用“1 = H/L，0 = L/H”：

| 相邻数据 | 两位的半位状态 | 两位交界处   |
| -------- | -------------- | ------------ |
| 11       | H/L，H/L       | L 到 H，跳变 |
| 00       | L/H，L/H       | H 到 L，跳变 |
| 10       | H/L，L/H       | L 到 L，不变 |
| 01       | L/H，H/L       | H 到 H，不变 |

所以曼彻斯特是**每位中间必跳变，位边界可能跳变**，不能说“整个波形每位只可能有一次跳变”。

##### （5）识别编码不能只凭局部一条边

建议按下面顺序判断：

1. 位周期内是否返回零电平？若是，考虑 RZ。
2. 每位中间是否固定有跳变？若是，考虑两种曼彻斯特编码。
3. 题目用中间跳变方向表示数据，还是用位开始处变不变表示数据？据此区分两种曼彻斯特。
4. 若中间无固定跳变，再看绝对电平表示数据，还是边界变化表示数据，区分 NRZ 与 NRZI。

**注意：一小段特殊数据可能使不同编码的局部波形看起来相似。最终仍需结合完整波形、位边界和题干规则。**

#### 9. 模拟数据编码为数字信号：PCM

**脉冲编码调制（PCM）**包括三个步骤：**采样、量化、编码**。

##### （1）采样：让时间离散

每隔一定时间测量一次模拟信号幅值。

- 原信号在时间上连续。
- 采样后，只保留一个个采样时刻上的数值。
- 此时样本幅值仍可能连续取值。

对最高频率为 `f_max` 的低通带限信号，教材采用的采样条件为：

```text
采样频率 f_s ≥ 2f_max
最大采样间隔 T_s ≤ 1 / (2f_max)
```

**注意：这是采样条件，不能与奈氏准则中的“最大码元速率 2W”混淆。前者给最低采样频率，后者给特定信道模型下的最高码元速率。**

##### （2）量化：让幅值离散

将每次采样得到的连续幅值，映射到预先规定的有限个等级。

- 例如把幅值划分成 256 个量化等级。
- 原幅值与量化后的代表值可能不同，因此存在量化误差。
- 其他条件相同，等级更多，表示更精细，但需要更多编码位数。

##### （3）编码：把等级编号写成二进制

若使用 `L` 个量化等级：

```text
每个样本所需位数 n = ⌈log₂L⌉

当 L = 2^n 时，n = log₂L
```

例如：`256` 个等级需要 `8 bit`；`100` 个等级至少需要 `7 bit`。

##### （4）PCM 数据速率

不计额外开销时：

```text
一路 PCM 比特率 = 每秒采样次数 × 每样本编码位数
                = f_s × n

k 路合计比特率 = k × f_s × n
```

例如：最高频率为 `4 kHz`，按最低要求采样，采用 `256` 级量化：

```text
f_s = 2 × 4000 = 8000 次/s
n = log₂256 = 8 bit/次

R_b = 8000 × 8 = 64000 b/s = 64 kb/s
```

> 采样解决“多久取一个值”；量化解决“这个值归到哪一级”；编码解决“这个等级用什么二进制数表示”。

##### （5）采样之后为什么还要量化

假设某次采样得到幅值 `1.237 V`。

采样只确定“在这个时刻测得这么大的值”，并没有自动把它变成某个有限位数的整数。

若规定将这个幅值划到第 5 个量化等级，就先用该等级的代表值近似它；再用二进制编码表示等级编号。

例如等级编号为 5，每样本编码长度为 3 bit：

```text
采样值：1.237 V
量化结果：等级 5
编码结果：101
```

**量化误差来自连续幅值被近似为有限等级，不是把十进制整数 5 写成二进制 101 这一步造成的。**

##### （6）量化等级不是越多越不占带宽

采样频率固定为 `8000 次/s`：

| 量化等级 | 每样本位数 | 一路输出速率 |
| -------- | ---------- | ------------ |
| 16       | 4 bit      | 32 kb/s      |
| 64       | 6 bit      | 48 kb/s      |
| 256      | 8 bit      | 64 kb/s      |

量化更精细通常需要更多位，输出数据量也会增加。

##### （7）PCM 多路与额外开销例题

已知：

- 4 路模拟信号，每路最高频率 `4 kHz`。
- 按最低采样要求，每路每秒采样 8000 次。
- 每个样本用 8 bit 编码。
- 题目规定每轮取各路一个样本，另加 8 bit 同步信息。

每一轮的数据量：

```text
4 路样本数据 = 4 × 8 = 32 bit
每轮总长度 = 32 + 8 = 40 bit
```

每秒需要 8000 轮，才能保证每一路都有 8000 次采样：

```text
总速率 = 40 × 8000
       = 320000 b/s
       = 320 kb/s
```

如果忽略同步位，才是 `4 × 64 = 256 kb/s`。

**注意：这是给定组帧规则下的计算示例，不是所有 PCM 系统都固定增加 8 bit 同步信息。**

##### （8）PCM 反推量化等级

已知一路 PCM 比特率为 `48 kb/s`，采样频率为 `8 kHz`，忽略额外开销：

```text
每样本位数 n = 48000 / 8000 = 6 bit
最多可表示等级数 L = 2^6 = 64
```

若题目问“最少需要几位”，用等级数反求并向上取整；若问“n 位最多能表示几级”，用 `2^n`。

#### 10. 数字数据调制为模拟信号

载波常可用正弦波描述。数字调制利用载波的不同状态表示数字数据。

| 方法 | 中文名       | 改变的参数 | 判图抓手                 |
| ---- | ------------ | ---------- | ------------------------ |
| ASK  | 幅移键控     | 振幅       | 波形高低或有无载波       |
| FSK  | 频移键控     | 频率       | 同样时长内波形疏密       |
| PSK  | 相移键控     | 相位       | 波形相对参考的位置或翻转 |
| QAM  | 正交幅度调制 | 振幅与相位 | 多种复合信号状态、星座点 |

##### （1）ASK

通过不同振幅表示不同数字。例如有载波表示 1，无载波表示 0。

- 实现较简单。
- 振幅容易受噪声与衰减影响，教材比较中抗干扰能力较差。

##### （2）FSK

通过不同频率表示不同数字。例如 `f₁` 表示 1，`f₂` 表示 0。

- 看波形时比较单位时间内振荡次数。
- 教材比较中抗干扰能力较强。

##### （3）PSK 与 DPSK

- **PSK**：根据载波相对于参考的相位表示数据，属于绝对相位判别。
- **DPSK**：差分相移键控，根据当前码元与前一码元之间的相位差表示数据，属于相对相位判别。

**注意：相位不等于频率。** 波形疏密可以相同，但相对于参考时刻的位置不同。

##### （4）QAM

QAM 同时利用振幅和相位形成多种可区分状态，提高每个码元携带的信息量。

它使用两路同频、相位相差 90° 的正交载波。两路分量的幅值组成一个信号状态，在星座图中对应一个点。

| 调制方式           | 星座点数／状态数 | 每码元携带信息量 |
| ------------------ | ---------------- | ---------------- |
| 16-QAM（QAM-16）   | 16               | 4 bit            |
| 64-QAM（QAM-64）   | 64               | 6 bit            |
| 256-QAM（QAM-256） | 256              | 8 bit            |

```text
QAM 比特率 R_b = 波特率 R_s × log₂(状态总数 V)
```

若题目给“`m` 种相位，每个相位都可配 `n` 种振幅”，且组合均有效、可区分：

```text
状态数 V = m × n
R_b = R_s log₂(mn)
```

若给的是两路正交分量各有 `q` 种幅值，则：

```text
状态数 V = q × q = q²
```

**注意：不要混淆“相位数×每相位振幅数”与“两路分量各自的幅值数”。最终都应先求真正可区分的状态总数。**

例如：波特率为 `2400 Baud`，采用 16-QAM：

```text
R_b = 2400 × log₂16
    = 9600 b/s
```

不能因为 QAM 有两路正交分量，在已经按 16 个状态算完后又额外乘 2。

**状态数越多不代表总能无代价提速。** 在功率等条件受限时，状态越密越难区分，对信噪比和设备精度的要求通常越高。

##### （5）QAM 星座图到底在画什么

星座图不是“信号随着时间走出的运动轨迹”。一个点表示某个可选信号状态。

- 横轴通常表示一路正交分量的幅值。
- 纵轴表示另一路正交分量的幅值。
- 两个坐标合起来确定一次发送的复合状态。
- 接收端估计收到的状态，并依据映射恢复相应比特组。

例如两路分量各可取 4 个不同值：

```text
第一路：4 种选择
第二路：4 种选择

组合总数 = 4 × 4 = 16
每次组合携带 = log₂16 = 4 bit
```

不能把两路“4 种选择”相加为 8 种，也不能把算出的 4 bit 再乘一次 2。

##### （6）状态数与比特率两种题型

**题型 A：已知状态总数。**

例如使用 64-QAM，波特率 `5 MBaud`：

```text
每码元携带 = log₂64 = 6 bit
R_b = 5 × 10^6 × 6 = 30 Mb/s
```

**题型 B：已知每个维度的可选数量。**

例如题目规定 8 种相位，每个相位有 2 种可区分振幅，波特率 `1200 Baud`：

```text
V = 8 × 2 = 16
每码元携带 = log₂16 = 4 bit
R_b = 1200 × 4 = 4800 b/s
```

前提是题目明确这些组合都有效且可区分。

##### （7）给了比特率，如何反求波特率

采用 64-QAM，希望传输 `12 Mb/s`：

```text
每码元携带 = 6 bit
R_s = 12 × 10^6 / 6
    = 2 × 10^6 Baud
    = 2 MBaud
```

做题时先判断 `12 Mb/s` 已经是比特率，不能又乘 `log₂64`。

#### 11. 模拟数据用模拟信号传输

- 可以直接传输模拟基带信号，例如传统电话本地线路上的语音信号。
- 也可以通过模拟调制搬移到载波上。

| 调制方式 | 缩写 | 改变参数 |
| -------- | ---- | -------- |
| 调幅     | AM   | 振幅     |
| 调频     | FM   | 频率     |
| 调相     | PM   | 相位     |

**注意：ASK、FSK、PSK 在这里对应数字数据调制；AM、FM、PM 对应模拟数据的模拟调制。**

## 2.2 传输介质

### 2.2.1 双绞线、同轴电缆、光纤与无线传输介质

#### 1. 传输介质的分类

传输介质也称传输媒体，是发送器与接收器之间承载信号的物理通路。

| 类型           | 特点                         | 例子                                 |
| -------------- | ---------------------------- | ------------------------------------ |
| 导向传输介质   | 信号受到固体介质引导         | 双绞线、同轴电缆、光纤               |
| 非导向传输介质 | 电磁波在自由空间等环境中传播 | 无线电波、微波、红外线、自由空间激光 |

**注意：光纤虽然传的是光，仍属于导向介质；光在自由空间传播才属于本节所说的非导向传输。**

#### 2. 双绞线

##### 1. 结构与绞合目的

双绞线由两根相互绝缘的铜导线按一定规则绞合而成。

**绞合的主要目的是减少电磁干扰和串扰。**

选择题问“两根线为什么绞合”，优先选**减少干扰**，不是增大机械抗拉强度。

##### 2. UTP 与 STP

| 类型 | 全称         | 特点                           |
| ---- | ------------ | ------------------------------ |
| UTP  | 非屏蔽双绞线 | 没有额外金属屏蔽层，结构较简单 |
| STP  | 屏蔽双绞线   | 增加金属屏蔽层，进一步抑制干扰 |

##### 3. 传输特点

- 成本相对低，安装使用方便。
- 可用于模拟传输，也可用于数字传输。
- 教材中的典型用途包括局域网和传统电话网。
- 能支持的带宽和距离与线材规格、线径及具体传输标准有关。
- 不能把双绞线在某种电话传输条件下的距离，直接当成所有以太网链路的允许距离。

距离较远，需要补偿信号时：

| 信号类型 | 典型设备 | 主要处理                           |
| -------- | -------- | ---------------------------------- |
| 模拟信号 | 放大器   | 放大衰减信号，也可能连噪声一起放大 |
| 数字信号 | 中继器   | 再生、整形并转发信号               |

##### 4. 绞合和屏蔽为什么都与抗干扰有关

两根导线绞合，使它们沿线路对外界干扰的相对位置不断交换，有助于让外界干扰对两线产生较相近的影响。配合差分接收，可抑制共同引入的干扰。

屏蔽层则通过导电屏蔽结构进一步减少外部电磁场的影响。

因此：

- 绞合与屏蔽可以同时使用。
- 没有屏蔽层，不代表两根线就不绞合。
- 有屏蔽层，也不代表可以取消信号编码与同步要求。

**考试抓主因：问“绞合”或“屏蔽”的目的，核心都与减少干扰相关；具体结构不同。**

#### 3. 同轴电缆

##### 1. 结构

从内到外依次是：

1. 内导体。
2. 绝缘层。
3. 外导体屏蔽层。
4. 绝缘保护套层。

外导体屏蔽层使其具有较好的抗干扰性能。

##### 2. 教材中的典型分类

| 类型          | 典型用途                   |
| ------------- | -------------------------- |
| 50 Ω 同轴电缆 | 基带数字传输，早期以太网   |
| 75 Ω 同轴电缆 | 宽带信号传输，有线电视系统 |

> 记忆：**50 Ω 对应早期基带局域网；75 Ω 对应有线电视。**

#### 4. 光纤

##### 1. 传输原理

光纤利用光导纤维传输光信号。教材的简单示例用有、无光脉冲分别表示 1、0。

基本结构包括**纤芯和包层**：

- 纤芯折射率高于包层。
- 光从高折射率介质射向低折射率介质，在满足临界角条件时发生全反射。
- 光被约束在光纤内向前传播。

**注意：用有、无光脉冲表示二进制只是基本说明，不能据此认定所有光通信每个符号都只能携带 1 bit。**

##### 2. 多模光纤与单模光纤

| 对比项       | 多模光纤                   | 单模光纤                 |
| ------------ | -------------------------- | ------------------------ |
| 可传播模式   | 多个模式                   | 单一模式                 |
| 纤芯         | 相对较粗                   | 相对较细                 |
| 教材直观示意 | 光沿多条路径传播           | 光集中沿轴向传播         |
| 模间色散     | 存在，不同模式到达时间不同 | 不存在多模式间的这种色散 |
| 脉冲展宽     | 相对更明显                 | 相对较小                 |
| 典型距离     | 较短距离                   | 较长距离                 |

多模光纤中，不同传播路径的到达时间不同，原本较窄的脉冲在接收端可能变宽，限制远距离高速传输。

单模光纤只允许一个传播模式，适合远距离、高速率通信，教材指出通常使用方向性好的半导体激光器作为光源。

**注意：**

- “单模／多模”中的“模”指传播模式，不是发送了几位数据。
- 单模不等于单工，多模不等于全双工。
- 单模没有模间色散，不代表完全没有其他色散或损耗。

##### 3. 光纤的优点

1. **容量大**：可利用的频率资源丰富，具有很大的带宽潜力。
2. **损耗小**：适合长距离传输，中继距离较长。
3. **抗电磁干扰强**：尤其适合电磁干扰较强的环境。
4. **串扰小、保密性较好**：不易通过普通电磁感应方式窃听。
5. **体积小、重量轻**：便于布设大量链路。

**注意：保密性好不等于绝对无法窃听；光纤也不是无损传输。**

##### 4. 衰减与色散有什么不同

| 现象           | 主要改变         | 可以怎样理解 |
| -------------- | ---------------- | ------------ |
| 衰减           | 信号强度下降     | 脉冲变弱     |
| 色散导致的展宽 | 脉冲在时间上展开 | 脉冲变宽     |

多模光纤中，不同模式的传播时间不同，原来同时发出的能量不再同时到达，这是模间色散产生脉冲展宽的直观原因。

接收端面临的困难不只是“信号太弱看不清”，也可能是“前后脉冲拖在一起分不清”。

所以不能认为只要把光信号变强，就一定能解决高速长距离传输中的全部问题。

##### 5. 为什么多模不等于带宽必然更大

“模式更多”表示允许多种传播模式，不等于像独立车道一样，各模式都能在本节简单模型中随意独立装载数据而互不影响。

多种模式到达时间不同，反而可能加重脉冲展宽，限制数据速率和距离。

> 单模、多模题目重点比较传播模式与色散；不要仅根据“多”字判断容量更大。

#### 5. 无线传输介质

##### 1. 无线电波

本节将通常具有较广覆盖能力的无线电波，与强调方向性的微波、红外线等作对比。

- 可用于移动通信和无线局域网。
- 通常不要求像定向光链路那样严格对准。
- 穿透能力和传播距离受频率、功率及环境影响，不能认为所有频段都能轻易穿墙。

##### 2. 地面微波

- 频率较高，可提供较大带宽与通信容量。
- 方向性强，典型链路要求视距传播。
- 受地球曲率、地形和障碍物限制。
- 长距离地面微波通信通常需要中继站。

##### 3. 卫星通信

本节以**地球同步卫星作为中继节点**的情况说明。

**优点：**

- 覆盖范围广。
- 适合远距离通信。
- 可突破地面微波视距链路的覆盖限制。

**缺点：**

- 信号传播路径长，传播时延较大。
- 广域无线覆盖下，保密需要额外措施。

**注意：传播时延大来自距离远，不是因为每个比特发送得慢。** 也不要将同步卫星的时延特点不加区分地套用到所有轨道高度的卫星系统。

##### 4. 红外线与自由空间激光

- 将电信号转换为相应光信号，在自由空间中传输。
- 方向性较强，典型链路需要对准和无遮挡路径。
- 常用于短距离点对点链路或室内通信。
- 容易被障碍物阻挡，不能像某些无线电波那样穿透墙壁。

##### 5. 无线通信中的三个独立问题

| 问题             | 决定或影响的内容                 |
| ---------------- | -------------------------------- |
| 能否穿过障碍物   | 与频率、材料、厚度和传播环境有关 |
| 能否覆盖很远     | 与路径、功率、天线、损耗等有关   |
| 数据能否传得很快 | 与带宽、信噪比、调制编码等有关   |

这三个问题相互有关，但不能画等号。

- 覆盖远，不代表比特率一定高。
- 频率高，不代表能够轻易穿透墙壁。
- 带宽大，也不代表传播时延小。

卫星链路可以有较大的通信容量，同时因为路径长而有较大的传播时延。

##### 6. 常见介质横向比较

| 介质                 | 主要承载形式       | 教材中的核心优势           | 核心限制或识别点                   |
| -------------------- | ------------------ | -------------------------- | ---------------------------------- |
| 双绞线               | 导线中的电信号     | 成本低、使用方便           | 绞合减少干扰，速率和距离受规格限制 |
| 同轴电缆             | 同轴结构中的电信号 | 屏蔽性能较好               | 50 Ω 与 75 Ω 的典型用途不同        |
| 光纤                 | 受引导的光信号     | 容量大、损耗小、抗电磁干扰 | 单模、多模；连接与光电转换要求     |
| 无线电波             | 自由空间电磁波     | 接入灵活、可移动           | 干扰和传播环境影响明显             |
| 地面微波             | 定向电磁波         | 带宽大、容量高             | 视距、地形、地球曲率               |
| 同步卫星链路         | 经卫星中继的电磁波 | 覆盖广、距离远             | 传播路径长、时延大                 |
| 红外线、自由空间激光 | 自由空间光信号     | 方向性强                   | 对准与障碍物遮挡                   |

### 2.2.2 物理层接口的特性

物理层定义设备与传输介质接口的四类特性：**机械、电气、功能、过程**。

| 特性     | 规定内容                                   | 题目关键词                   | 直观理解         |
| -------- | ------------------------------------------ | ---------------------------- | ---------------- |
| 机械特性 | 接线器形状、尺寸、引脚数目与排列、固定装置 | 形状、尺寸、引脚数量         | 接口长什么样     |
| 电气特性 | 电压范围、相关传输速率与距离限制等         | 几伏、电平范围、速率         | 电信号的数值要求 |
| 功能特性 | 各线路的用途及特定电平的意义               | 某引脚做什么、某电平表示什么 | 这些信号代表什么 |
| 过程特性 | 功能事件发生的顺序和时序关系               | 先后顺序、建立、传输、释放   | 按什么顺序操作   |

**过程特性也称规程特性。**

#### 1. 电气特性与功能特性怎么分

- “这条线上允许出现多大的电压”：**电气特性**。
- “这条线处于某个电平时代表发送请求”：**功能特性**。

> **电气看数值，功能看含义。**

#### 2. 常见选择题判断

| 表述                           | 属于哪一类 |
| ------------------------------ | ---------- |
| 连接器有多少个引脚             | 机械特性   |
| 引脚按几排排列                 | 机械特性   |
| 信号的电压允许范围             | 电气特性   |
| 某引脚用于发送数据             | 功能特性   |
| 某线路高电平表示设备就绪       | 功能特性   |
| 先发请求，再等确认，然后传数据 | 过程特性   |

**注意：“物理地址”通常指 MAC 地址，属于数据链路层范畴，不是物理层接口特性。**

#### 3. 四类接口特性的成组例子

假设某接口规范有以下要求：

1. 接口是某种形状，共 9 个引脚，排成两行。
2. 电压只能处于规定的范围内。
3. 第 3 个引脚用于发送数据，某控制线有效表示发送请求。
4. 发送请求出现后，等待对方就绪，再开始发送。

对应关系：

| 要求                     | 特性 | 判断依据             |
| ------------------------ | ---- | -------------------- |
| 形状、9 个引脚、两行排列 | 机械 | 几何结构与连接方式   |
| 电压范围                 | 电气 | 信号的电气数值要求   |
| 第 3 个引脚发送数据      | 功能 | 引脚承担什么任务     |
| 控制线有效表示请求       | 功能 | 电平状态代表什么意义 |
| 请求、就绪、发送的顺序   | 过程 | 事件先后与时序       |

这里的引脚编号只是解释用的假设，不对应某个实际接口标准。

#### 4. 为什么要规定接口，而不只规定“传 0、1”

即使两个设备都说自己能传二进制数据，也可能出现：

- 插头形状不同，根本插不上。
- 对电压的规定不同，无法识别甚至可能损坏设备。
- 相同引脚用途不同，一端发数据，另一端却当作控制信号。
- 一端还没有准备好，另一端已经开始发送。

四类特性分别把这些问题规定清楚，才能让双方在物理层配合工作。

## 2.3 物理层设备

### 2.3.1 中继器

#### 1. 作用与原理

**中继器（Repeater）**对衰减、失真的数字信号进行再生、整形并转发，以扩展传输距离。

教材中的中继器通常有两个端口，一端接收信号，另一端转发恢复后的信号。

> 关键是**恢复信号后再转发**，不能只理解成“把所有波形连同噪声一起放大”。

| 设备   | 本节主要处理对象 | 处理方式                             |
| ------ | ---------------- | ------------------------------------ |
| 放大器 | 模拟信号         | 放大衰减信号，可能同时放大噪声       |
| 中继器 | 数字信号         | 再生整形，恢复可识别的数字信号并转发 |

**注意：再生信号不等于纠正所有比特错误。** 如果噪声已使原来的 0 被判成 1，中继器不具备链路层差错校验与重传功能。

#### 2. 所在层次与能力边界

- 工作在**物理层**。
- 处理信号和比特，不按 MAC 地址选择转发方向。
- 不分析帧内容，不进行网络层路由选择。
- 不具备帧级缓存与存储转发能力。
- 不能完成不同数据链路层协议之间的转换。
- 在本节传统共享式局域网场景下，连接的网段仍属于同一个局域网。
- 不能分割冲突域，也不能分割广播域。

**注意：不同网段不等于不同 IP 子网。** 不能把“中继器连接网段”理解成“中继器能完成路由器连接子网的功能”。

#### 3. 中继器能不能无限串联

不能。

虽然再生信号能延长传输距离，但标准还会限制整体传播时延等条件。增加电缆和中继器会增加时延，可能破坏网络正常工作所需的条件。

> 能恢复信号，不代表能消除距离和设备带来的时延。

##### （1）中继器为什么既能延长距离，又不能无限延长

信号经过长电缆可能衰减、失真。中继器恢复信号后，相当于为后续线路提供一份重新整形的信号。

但从源主机到目的主机的总路径更长了，中继设备本身也需要处理时间。

在传统共享式以太网中，发送方需要在规定的时间关系内发现冲突。如果冲突返回太晚，就可能破坏正常的冲突检测机制。

因此，“接收端还能认出 0、1”和“整个共享网络符合协议的时序要求”是两个不同条件，都要满足。

##### （2）中继器能否跨介质连接

要看设备是否支持两侧物理接口，以及相关信号、编码与速率要求是否兼容。

不能简单说中继器只能接完全相同材质的电缆，也不能说只要都传二进制就一定能互连。

**抓住层次：中继器能够处理其支持的物理信号，但不会通过读取帧内容来转换链路层协议。**

##### （3）“没有缓存”到底指什么

本章设备比较中的“没有缓存”，主要指不具备将整个帧存储下来、排队并按需要转发的能力。

不必把这个结论扩大成“设备内部绝对不能存在任何电路状态或寄存元件”。做题比较的是网络设备的帧级转发能力。

#### 4. 5-4-3 规则

在教材举例的传统 **10BASE5 共享式以太网**条件下：

- 最多连接 **5 段电缆**。
- 通过 **4 个中继器**连接。
- 最多 **3 段**可以连接主机。
- 另外 **2 段**只用于连接中继器、扩展距离。

> 记忆：**5 段、4 中继、3 段挂主机。**

**注意：这是特定传统以太网场景的规则，不能推广成所有网络的通用上限。**

### 2.3.2 集线器

#### 1. 集线器是什么

**集线器（Hub）本质上是多端口中继器，工作在物理层。**

一个端口接收到信号后，集线器对信号进行再生整形，再转发到**除输入端口外的其他工作端口**。

例如：A、B、C、D 接在同一台集线器上，A 向 B 发送时，信号也会被转发到 C、D 所在端口。

**原因：集线器不读取目的 MAC 地址，不知道应该只转发给谁。**

#### 2. 集线器的主要特点

1. **多端口中继器**：作用是再生和转发信号。
2. **共享式设备**：端口共享同一传输资源。
3. **不能定向转发**：不按目的地址挑选端口。
4. **没有帧级缓存能力**：不等待完整帧到齐再按地址转发。
5. **工作在半双工模式**：共享介质中，多个节点同时发送会发生冲突。
6. **不能转换链路层协议**：转发比特不代表能够解释不同格式的帧。

#### 3. 物理拓扑与逻辑拓扑

| 观察角度 | 集线器网络的拓扑 | 原因                               |
| -------- | ---------------- | ---------------------------------- |
| 物理连接 | 星形             | 每台主机用独立线缆连接到中心集线器 |
| 逻辑通信 | 总线形           | 所有主机共享同一个传输资源         |

> 线缆看起来各走各的，不代表每台主机拥有独立带宽。

#### 4. 冲突域与广播域

**冲突域**：多个节点同时发送时，可能相互产生冲突的范围。

**广播域**：一个链路层广播能够到达的范围。

对集线器：

- 所有端口属于**同一个冲突域**。
- 所有端口处于同一个广播域。
- 增加端口或继续连接集线器，不会自动分割这些范围。
- 主机越多、同时争用越频繁，冲突越可能影响吞吐率。

**注意：集线器把信号转发到其他端口，不意味着它把原来的单播帧改造成了广播帧。它只是不会按地址筛选信号。**

##### （1）A 给 B 发，为什么 C、D 也能收到信号

集线器不认识帧里的目的地址，收到 A 的信号后，就把它送到其他工作端口。

因此，B、C、D 的端口都会看到这段信号。后续是否接收这个帧，由各主机网卡等链路层机制依据目的地址判断。

**信号到达 C 的端口，不等于 C 的应用程序必然接收这份数据。**

##### （2）如果 A 给 B、C 给 D 同时发送

虽然目的主机不同，但它们仍共享同一个冲突域。

两组发送可能发生冲突，不能像独立交换链路那样认为两组通信一定可以同时成功进行。

```text
目的主机不同 ≠ 使用不同的共享信道
使用不同端口 ≠ 自动拥有独立冲突域
```

##### （3）两个集线器连接，冲突域有几个

假设两台集线器按兼容要求连接，且两侧主机通过该共享式网络通信。

由于集线器不会隔离冲突，连接后整体仍是**一个冲突域**，而不是按集线器台数算成两个。

如果中间使用的是具有隔离冲突域功能的网桥或交换机，才需要按后续章节的规则重新判断。

##### （4）冲突与误码有什么不同

| 情况                         | 主要原因                   | 是否同一个概念       |
| ---------------------------- | -------------------------- | -------------------- |
| 多个节点争用共享介质产生冲突 | 发送时间重叠、信号相互影响 | 属于共享介质访问问题 |
| 噪声使某个比特被识别错误     | 传输干扰、信号质量问题     | 属于传输差错问题     |

两者都可能使接收数据失败，但原因不同。集线器不能通过再生整形，让同时冲突的两组数据自动变成两条独立成功的通信。

#### 5. 共享带宽如何计算

若一台集线器的共享速率为 `R`，有 `N` 台主机持续争用，题目假定理想平均分配并忽略开销：

```text
每台主机平均可分得的速率 ≈ R / N
```

例如：一台 `10 Mb/s` 集线器连接 `8` 台主机，各主机按题意平均分享：

```text
每台平均速率 = 10 / 8 = 1.25 Mb/s
```

**注意：**

- 不是每个端口各有独享的 `10 Mb/s`。
- `R/N` 是题目给定理想均分条件下的平均结果，不是固定给每台主机划出这么多。
- 如果只有一台主机发送，它可以使用大部分共享容量。
- 多台主机实际争用时存在冲突、退避和协议开销，有效速率可能更低。
- 不要把“同时工作”理解为能同时成功传输 N 组独立数据。
- 一个 `10 Mb/s` 半双工共享介质也不能因为有发送方和接收方，就额外乘 2 算成 `20 Mb/s`。

##### （1）共享速率的三个提问角度

设一台 `10 Mb/s` 集线器连 8 台主机。

| 题目问法                                 | 在题设理想条件下如何答    |
| ---------------------------------------- | ------------------------- |
| 这个共享网络的标称传输速率               | 10 Mb/s                   |
| 8 台持续争用并平均分享，每台平均多少     | 1.25 Mb/s，忽略开销       |
| 只有一台主机发数据，是否也只能 1.25 Mb/s | 否，没有预先固定切成 8 份 |

**先看题目问整体、单机平均，还是单机独占时的速率，再决定是否除以主机数。**

##### （2）发送时间与平均分配结合

假设 4 台主机理想平均分享一个 `10 Mb/s` 集线器，每台要发送 `1 MB` 数据，忽略所有额外开销，MB 按十进制。

```text
每台平均速率 = 10 / 4 = 2.5 Mb/s
每台数据量 = 1 × 10^6 × 8 = 8 × 10^6 bit

t = (8 × 10^6) / (2.5 × 10^6)
  = 3.2 s
```

也可以从总量计算：

```text
总数据量 = 4 × 1 MB = 32 × 10^6 bit
总完成时间 = (32 × 10^6) / (10 × 10^6) = 3.2 s
```

该例是平均分享的理想估算，不表示四台主机在每一个瞬间都各自以 2.5 Mb/s 同时发送成功。

#### 6. 不同速率的连接限制

纯中继式设备没有帧级缓存，不能像存储转发设备那样把完整帧存下来，再按另一种速率发送。

教材给出的情形：一侧支持 `10 Mb/s`，另一侧支持 `10/100 Mb/s`，若作为同一中继式共享网络互通，应在共同支持的 `10 Mb/s` 下工作。

**注意：如果两端没有共同支持的工作速率，不能简单认为“自动取较小值就一定能连接”。**

### 2.3.3 设备对比与选择题抓手

#### 1. 中继器与集线器

| 对比项            | 中继器               | 集线器                     |
| ----------------- | -------------------- | -------------------------- |
| 所在层            | 物理层               | 物理层                     |
| 教材典型端口数    | 两个                 | 多个                       |
| 核心功能          | 信号再生、整形、转发 | 向其他端口再生、转发信号   |
| 识别目的 MAC 地址 | 否                   | 否                         |
| 帧级缓存          | 无                   | 无                         |
| 分割冲突域        | 不能                 | 不能                       |
| 分割广播域        | 不能                 | 不能                       |
| 主要目的          | 扩展距离             | 连接多个节点并扩展传输范围 |

#### 2. 与后续设备的最小区别

以下用于避免把物理层设备与后面章节的设备混淆。

| 设备             | 典型层次   | 转发依据           | 是否分割冲突域                   | 是否隔离链路层广播域           |
| ---------------- | ---------- | ------------------ | -------------------------------- | ------------------------------ |
| 集线器           | 物理层     | 不看地址，转发信号 | 否                               | 否                             |
| 网桥／二层交换机 | 数据链路层 | MAC 地址           | 是，各端口分开；全双工链路无冲突 | 默认同一 VLAN 内不隔离         |
| 路由器           | 网络层     | IP 地址与路由表    | 是                               | 是，默认不跨接口转发链路层广播 |

**注意：这里只作层次对照。VLAN、交换机转发表和路由的详细原理留到对应章节。**

## 2.4 本章做题速查

### 2.4.1 公式汇总

| 题目要算什么       | 公式                | 先检查什么                    |
| ------------------ | ------------------- | ----------------------------- |
| 每码元携带比特数   | n = log₂V           | V 是可区分状态数，常为 2 的幂 |
| 状态数             | V = 2^n             | n 是每码元信息位数            |
| 波特率             | R_s = 1/T_s         | 时间换成秒                    |
| 比特率             | R_b = R_s log₂V     | 不把波特率当比特率            |
| 理想低通极限波特率 | R_s,max = 2W        | W 的单位为 Hz                 |
| 奈氏极限比特率     | R_N = 2W log₂V      | 理想低通模型、状态数          |
| 香农容量           | C = W log₂(1 + S/N) | S/N 必须是无单位功率比        |
| 分贝转功率比       | S/N = 10^(dB/10)    | 不能直接代入 dB 值            |
| 最低采样频率       | f_s ≥ 2f_max        | 低通带限信号的最高频率        |
| 每样本编码位数     | n = ⌈log₂L⌉         | L 是量化等级数                |
| PCM 数据速率       | R_b = f_s × n       | 多路再乘路数，题目开销另加    |
| QAM 数据速率       | R_b = R_s log₂V     | 先数状态，不重复乘分量数      |
| 理想平均共享速率   | R/N                 | 题目明确平均共享，忽略开销    |

### 2.4.2 高频易错判断

| 表述                                             | 判断             | 理由                                 |
| ------------------------------------------------ | ---------------- | ------------------------------------ |
| 一个码元只能携带 1 bit                           | 错               | 多状态码元可携带多个比特             |
| 波特率就是每秒传输的比特数                       | 错               | 波特率数码元，比特率数比特           |
| 波特率就是电平跳变次数                           | 错               | 相邻码元可以同状态而不跳变           |
| 只要增加状态数，噪声信道速率就能无限增加         | 错               | 不能突破有限带宽和信噪比下的容量限制 |
| 30 dB 可直接作为香农公式中的 S/N = 30            | 错               | 应换算为 1000                        |
| 曼彻斯特每位中间都有跳变                         | 对               | 中间跳变用于同步并表示数据           |
| 差分曼彻斯特靠中间跳变方向表示数据               | 错               | 看位开始处是否跳变                   |
| PCM 的步骤是采样、量化、编码                     | 对               | 时间离散、幅值离散、二进制表示       |
| 数字数据只能通过数字信号传输                     | 错               | 也可经数字调制形成模拟信号           |
| 双绞线绞合主要为了减少干扰                       | 对               | 减少电磁干扰和串扰                   |
| 光纤属于无线传输介质                             | 错               | 光受固体介质引导，属于导向介质       |
| 单模光纤表示只能单向通信                         | 错               | 模式数与双工方式是不同概念           |
| MAC 地址属于物理层接口特性                       | 错               | 物理地址名称不代表归属物理层         |
| 中继器只是把衰减信号简单放大                     | 不准确／通常判错 | 核心是数字信号再生整形               |
| 中继器能无限串接扩展网络                         | 错               | 整体时延等受到标准限制               |
| 集线器会根据目的地址选择输出端口                 | 错               | 不看 MAC 地址                        |
| 集线器本质是多端口中继器                         | 对               | 都工作在物理层                       |
| 集线器每个端口构成独立冲突域                     | 错               | 所有端口共享一个冲突域               |
| 集线器物理星形、逻辑总线形                       | 对               | 布线方式与共享通信方式不同           |

### 2.4.4 自测题与逐步答案

下面的题目为根据本章知识点编写的练习，用来检查计算与概念是否掌握，不是对未上传教材题目的转录。

#### 1. 码元与数据量

某系统使用 32 种码元状态，每个码元持续 `5 μs`。忽略开销，发送 `1000 B` 数据需要多久？

**解答：**

```text
每码元信息量 = log₂32 = 5 bit
波特率 = 1 / (5 × 10^-6) = 200000 Baud
比特率 = 200000 × 5 = 1000000 b/s

数据量 = 1000 × 8 = 8000 bit
发送时间 = 8000 / 1000000 = 0.008 s = 8 ms
```

**检查点：** 32 是状态数；1000 B 要乘 8；5 μs 要换成秒。

#### 2. 奈氏公式反推

理想低通信道带宽为 `5 kHz`，采用等长二进制映射，要达到 `50 kb/s`，每码元至少携带几位？至少需要几种状态？

**解答：**

```text
极限码元速率 = 2 × 5000 = 10000 Baud
每码元至少携带 = 50000 / 10000 = 5 bit
最少状态数 = 2^5 = 32
```

**检查点：** 先算每秒码元数，再分摊比特数，最后才求状态数。

#### 3. 香农公式与分贝

带宽 `1 MHz`，信噪比 `20 dB`，求理论容量。

**解答：**

```text
S/N = 10^(20/10) = 100
C = 10^6 × log₂101
  ≈ 6.658 × 10^6 b/s
  ≈ 6.66 Mb/s
```

**检查点：** 不能写成 `10^6 × log₂21`。

#### 4. PCM 量化位数向上取整

一个低通带限模拟信号最高频率 `6 kHz`，至少划分 100 个量化等级，采用固定长度二进制编码，按最低采样条件计算输出速率。

**解答：**

```text
最低采样频率 = 2 × 6000 = 12000 次/s
每样本位数 = ⌈log₂100⌉ = 7 bit

输出速率 = 12000 × 7 = 84000 b/s = 84 kb/s
```

**检查点：** 6 bit 只有 64 种组合，不够表示 100 个等级，必须用 7 bit。

#### 5. QAM 两路分量

两路正交分量各有 8 种可区分幅值，全部组合有效，波特率为 `3000 Baud`，比特率是多少？

**解答：**

```text
V = 8 × 8 = 64
每码元携带 = log₂64 = 6 bit
R_b = 3000 × 6 = 18000 b/s
```

**检查点：** 不是 `8 + 8 = 16` 种状态，也不是算完 6 bit 后再乘 2。

#### 6. 曼彻斯特译码

题目规定下降沿表示 1、上升沿表示 0。已知四个位周期的前后半位分别为 `L/H、H/L、H/L、L/H`，求数据。

**解答：**

```text
L/H：中间上升 → 0
H/L：中间下降 → 1
H/L：中间下降 → 1
L/H：中间上升 → 0

数据：0110
```

**检查点：** 普通曼彻斯特在给出方向约定后，看位中间的方向，不需要用上一位结束电平判数据。

#### 7. 光纤概念判断

“多模光纤允许多种模式，所以一定比单模光纤更适合长距离高速通信。”是否正确？

**解答：不正确。**

多种模式的传播时间不同，会产生模间色散，使脉冲展宽。教材比较中，单模光纤更适合长距离高速通信。

**检查点：** 模式数不能直接当作独立数据通道数。

#### 8. 接口特性判断

“某个控制引脚有效表示允许发送”属于哪种特性？“必须先请求，再确认，最后传数据”属于哪种特性？

**解答：**

- 前者是功能特性，说明引脚状态的意义。
- 后者是过程特性，说明事件顺序。

**检查点：** 虽然都涉及控制信号，一个问含义，一个问先后。

#### 9. 集线器的冲突域

两台兼容的集线器连接起来，各连接 4 台主机。一共是几个冲突域？A 给 B 发、C 给 D 发，能否因为收发主机不同就保证同时成功？

**解答：**

- 整体仍为一个冲突域。
- 不能保证两组同时发送成功，它们争用同一个共享式传输资源。

**检查点：** 冲突域不是按主机数、端口数或集线器台数直接计数。

#### 10. 把四种“时间”分开

题目给出码元周期、采样周期、发送时延、传播时延时，各自描述什么？

| 时间     | 描述对象                         | 常用关系        |
| -------- | -------------------------------- | --------------- |
| 码元周期 | 一个码元占用多长时间             | 1 / 波特率      |
| 采样周期 | 隔多久采样一次                   | 1 / 采样频率    |
| 发送时延 | 把所有数据放上链路所需时间       | 数据量 / 比特率 |
| 传播时延 | 信号沿介质从一端到另一端所需时间 | 距离 / 传播速度 |

**检查点：** 介质更长主要增加传播时延；在数据量不变时提高比特率主要缩短发送时延。两者不要混为一谈。
