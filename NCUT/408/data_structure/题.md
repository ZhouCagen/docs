**03.** 链式存储设计时，结点内的存储单元地址（　）。

A. 一定连续

B. 一定不连续

C. 不一定连续

**09.** 单链表中，增加一个头结点的目的是（　）。

A. 使单链表至少有一个结点

B. 标识表结点中首结点的位置

C. 方便运算的实现

D. 说明单链表是线性表的链式存储

**答案：C。** 设置头结点可以统一首个数据结点与其他数据结点的插入、删除操作，也便于统一处理空表和非空表，减少特殊情况的判断。

**23.** 设栈的初始状态为空，当字符序列“n1\_”作为栈的输入时，输出长度为 3，且可用作 C 语言标识符的序列有（　）个。

**24.** 采用共享栈的好处是（　）。

A. 减少存取时间，降低发生上溢的可能

B. 节省存储空间，降低发生上溢的可能

C. 减少存取时间，降低发生下溢的可能

D. 节省存储空间，降低发生下溢的可能

**答案：B。** 两个栈从同一数组的两端向中间增长，可以共用空闲空间，提高存储空间利用率，降低因单个栈空间不足而发生上溢的可能。共享空间不改变空栈不能出栈的条件，不能降低下溢的可能。

**11.** 与顺序队列相比，链式队列的（　）。

A. 优点是队列的长度不受限制

B. 优点是入队和出队时间效率更高

C. 缺点是不能进行顺序访问

D. 缺点是不能根据队首指针和队尾指针计算队列的长度

**答案：D。** 链式队列的结点地址不要求连续，不能仅凭队首、队尾指针直接计算长度；需要遍历计数，或额外维护长度变量。链式队列的长度仍受可用内存限制；在维护队首、队尾指针的通常实现中，链式队列与循环顺序队列的入队、出队均为 $O(1)$，且链式队列可以沿链顺序访问。

**15.** 用链式存储方式的队列进行删除操作时需要（　）。

A. 仅修改头指针

B. 仅修改尾指针

C. 头尾指针都要修改

D. 头尾指针可能都要修改

**答案：D。** 出队通常只需修改队首指针（带头结点时修改头结点的 `next`）；删除最后一个数据结点时，还需调整队尾指针。带头结点时将队尾指针指回头结点，不带头结点时将队首、队尾指针均置为 `nullptr`。因此是否需要同时调整头、尾取决于删除后队列是否为空。

**08.** 设二叉树有 $2n$ 个结点，且 $m<n$，则不可能存在（　）的结点。

A. $n$ 个度为 0

B. $2m$ 个度为 0

C. $2n$ 个度为 1

D. $2m$ 个度为 2

**答案：C。** 非空二叉树至少有一个叶子结点，不可能全部 $2n$ 个结点的度都为 1。也可由边数判断：若全部结点的度都为 1，则度数之和为 $2n$，但树的边数应为 $2n-1$，矛盾。

设度为 0、1、2 的结点数分别为 $n_0,n_1,n_2$，则

$$
n_0=n_2+1,\qquad n_0+n_1+n_2=2n.
$$

**注意：** $m<n$ 并不保证 B、D 对每组参数都能实现；B 还需 $2m\le n$，D 还需 $2m\le n-1$。它们在适当参数下可以存在，而 C 始终不可能。

**28.【2020 统考真题】** 对于任意一棵高度为 5 且有 10 个结点的二叉树，若采用顺序存储结构保存，每个结点占 1 个存储单元（仅存放结点的数据信息），则存放该二叉树的存储单元数量至少是（　）。

A. 31

B. 16

C. 15

D. 10

**答案：A。** 关键是题干中的**“任意一棵”**：分配的空间必须能存放所有满足条件的二叉树，因此要按最大可能位置预留空间。二叉树顺序存储按完全二叉树的位置编号保存结点，空缺位置也必须保留。根结点编号为 1，编号为 $i$ 的结点，其左、右孩子位置分别为 $2i$、$2i+1$。

高度为 5 的二叉树，其结点最大可能编号为第 5 层最右位置的 $2^5-1=31$。例如占用编号 $1,2,3,4,5,6,7,8,15,31$ 的位置，恰好有 10 个结点且高度为 5，其中最右路径为 $1\to3\to7\to15\to31$。因此，即使只有 10 个实际结点，也可能需要存储到第 31 个位置；为保证存放任意这样的二叉树，至少应分配 **31 个存储单元**。

**易错：** 16 只能满足部分结点排列，不能保证存放题目要求的任意一棵二叉树；10 仅是实际结点数，未计入顺序存储必须保留的空位置。

**21.** 某二叉树 $T$ 采用二叉链表存储结构，$T$ 的中序遍历序列为一个升序序列，要求采用某种方法对 $T$ 进行某种操作之后得到一棵新的二叉树 $T'$，要求 $T'$ 的中序遍历序列为一个降序序列，则下列关于该算法的叙述中，正确的是（　）。

A. 采用中序遍历的方法最合适

B. 采用后序遍历的方法最合适

C. $T'$ 中的根结点一定不是原 $T$ 中的根结点

D. $T'$ 中的叶结点不一定是原 $T$ 中的叶结点

**答案：B。** 将每个结点的左右子树交换，即得到原树的镜像，其中序序列就是原中序序列的逆序。采用后序遍历，先处理左右子树，再交换当前结点的左右孩子，过程直接清晰。根结点仍是原根结点，叶结点集合也不变，因此 C、D 错误。普通中序遍历若访问当前结点时直接交换左右孩子，容易重复访问或遗漏子树。

**27.** 二叉树在线索化后，仍不能有效求解的问题是（　）。

A. 先序线索二叉树中求先序后继

B. 中序线索二叉树中求中序后继

C. 中序线索二叉树中求中序前驱

D. 后序线索二叉树中求后序后继

**答案：D。** 后序遍历顺序为“左、右、根”。某结点若有右孩子，其右指针指向真实右孩子，不能用作后继线索；寻找后继时可能需要访问双亲，普通二叉线索链表没有双亲指针，因此不能方便地求出后序后继。

**知识点：线索二叉树中查找前驱、后继的便利性。** 以下针对通常不含双亲指针的二叉线索链表，“方便”表示可利用孩子指针和线索直接寻找，无须从根重新查找双亲，并不表示一定为 $O(1)$。

| 线索二叉树 | 前驱 | 后继 |
| --- | --- | --- |
| 先序 | 不方便 | 方便 |
| 中序 | 方便 | 方便 |
| 后序 | 方便 | 不方便 |

- **先序求后继：** 有左孩子则后继为左孩子；无左孩子但有右孩子则后继为右孩子；没有孩子则沿右线索找后继。求前驱时可能需要找双亲，因此不方便。
- **中序求前驱：** 左指针为线索时直接取得前驱；有左子树时，前驱为左子树中最右的结点。求后继与之对称：右指针为线索时直接取得后继，否则找右子树中最左的结点。
- **后序求前驱：** 有右孩子则前驱为右孩子；无右孩子但有左孩子则前驱为左孩子；没有孩子则沿左线索找前驱。求后继时可能需要找双亲，因此不方便。

**记忆：先序后继、后序前驱方便；中序两边都方便。**

**30.** 某二叉树的先序序列和后序序列正好相反，则该二叉树一定是（　）。

A. 空或只有一个结点

B. 高度等于其结点数

C. 任意一个结点无左孩子

D. 任意一个结点无右孩子

**答案：B。** 按结点身份区分遍历序列。若某结点同时有左右子树，先序中左子树先于右子树，而后序的逆序中右子树先于左子树，不可能完全相同。因此每个结点至多只有一个孩子，整棵树形成一条链；按根在第 1 层计算，高度等于结点数。链上的唯一孩子可以是左孩子，也可以是右孩子，所以 C、D 均不一定成立。

**09.** 若度为 $m$ 的哈夫曼树中，叶结点数为 $n$，则非叶结点的个数为（　）。

A. $n-1$

B. $\lfloor n/m\rfloor-1$

C. $\lceil(n-1)/(m-1)\rceil$

D. $\lceil n/(m-1)\rceil-1$

**答案：C。** $m$ 叉哈夫曼树构造时，每次合并 $m$ 棵树，产生一个非叶结点，使待合并的树的数量减少 $m-1$。若有 $n$ 个原始叶结点，必要时补入权值为 0 的虚拟叶结点，使叶结点总数 $n'$ 满足 $(n'-1)\bmod(m-1)=0$。

设非叶结点数为 $i$，补齐后每个非叶结点都有 $m$ 个孩子。由“边数＝总结点数减 1”可得

$$
mi=n'+i-1,\qquad i=\frac{n'-1}{m-1}
=\left\lceil\frac{n-1}{m-1}\right\rceil.
$$

**记忆：** $m$ 叉哈夫曼树的非叶结点数为 $\boxed{\lceil(n-1)/(m-1)\rceil}$；二叉哈夫曼树取 $m=2$，得到 $n-1$。若题目中的 $n$ 已包含补入的虚拟叶结点，则可直接写为 $(n-1)/(m-1)$。

## 综合题

### 04. 满 $m$ 叉树的层次编号

一棵高度为 $h$ 的满 $m$ 叉树有如下性质：根结点所在层次为第 1 层，第 $h$ 层上的结点都是叶结点，其余各层上每个结点都有 $m$ 棵非空子树。若按层次自顶向下，同一层自左向右，顺序从 1 开始对全部结点进行编号，试问：

1. 各层的结点数是多少？
2. 编号为 $i$ 的结点的双亲结点（若存在）的编号是多少？
3. 编号为 $i$ 的结点的第 $k$ 个孩子结点（若存在）的编号是多少？
4. 编号为 $i$ 的结点有右兄弟的条件是什么？其右兄弟结点的编号是多少？

**答案与推导：** 以下按通常的 $m\ge 2$ 讨论，孩子从左到右编号为 $1,2,\ldots,m$。

**（1）各层结点数。** 第 $j$ 层有 $m^{j-1}$ 个结点，其中 $1\le j\le h$。总结点数为

$$
N=1+m+\cdots+m^{h-1}=\frac{m^h-1}{m-1}.
$$

**（2）双亲编号。** 根结点 $i=1$ 没有双亲；其余结点的双亲编号为

$$
\boxed{\operatorname{parent}(i)=\left\lfloor\frac{i-2}{m}\right\rfloor+1
=\left\lceil\frac{i-1}{m}\right\rceil},\qquad 2\le i\le N.
$$

根的孩子编号为 $2$ 到 $m+1$，下一个结点的孩子编号为 $m+2$ 到 $2m+1$，每 $m$ 个连续编号的结点具有同一个双亲。

**（3）第 $k$ 个孩子的编号。** 编号为 $i$ 的结点，其孩子编号依次为 $m(i-1)+2,\ldots,mi+1$，所以

$$
\boxed{\operatorname{child}_k(i)=m(i-1)+k+1},\qquad 1\le k\le m.
$$

孩子存在的条件为

$$
1\le i\le\frac{m^{h-1}-1}{m-1},
$$

即 $i$ 不在第 $h$ 层。代入 $m=2$，得到熟悉的左孩子 $2i$、右孩子 $2i+1$。

**（4）右兄弟。** 根没有兄弟；其他结点只要不是双亲的第 $m$ 个孩子，就有右兄弟。条件为

$$
\boxed{i>1\quad\text{且}\quad(i-1)\bmod m\ne 0},\qquad i\le N.
$$

若存在，右兄弟的编号为 $\boxed{i+1}$。注意，同层相邻结点只有在双亲相同时才是兄弟；每组孩子中的最后一个结点不能把下一组的首结点当作右兄弟。

若 $m=1$，树退化为一条链：每层 1 个结点，总结点数为 $h$；非根结点的双亲编号为 $i-1$，非叶结点唯一孩子的编号为 $i+1$，所有结点均无兄弟。

### 05. 顺序存储二叉树的最近公共祖先

已知一棵二叉树按顺序存储结构进行存储，设计一个算法，求编号分别为 $i$ 和 $j$ 的两个结点的最近公共祖先结点的值。

**原理：大的编号整除以 2，直到两个编号相等。**

按根结点编号为 1 的顺序存储规则，非根结点 $k$ 的双亲编号为 $\lfloor k/2\rfloor$。

1. 若 $i>j$，令 $i=\lfloor i/2\rfloor$，即让编号较大的结点移向双亲。
2. 若 $j>i$，令 $j=\lfloor j/2\rfloor$。
3. 重复比较，直到 $i=j$；此时该编号对应的结点就是最近公共祖先。题目要求结点的值，因此最后读取该编号对应存储位置中的数据。

**为什么只移动较大的编号？** 祖先的编号一定小于后代的编号；当两个编号不等时，编号较大的结点不可能是另一个结点的祖先，将它移向双亲不会越过最近公共祖先。两条向根回溯的路径第一次相遇时，就找到了最近公共祖先。

例如，编号为 8 和 11 的两个结点：$(8,11)\to(8,5)\to(4,5)\to(4,2)\to(2,2)$，最近公共祖先编号为 2，返回编号 2 对应结点的值。若初始时 $i=j$，直接返回该结点的值。

### 从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不同

**答案：**

```cpp
void deleteElem(SqList &L)
{
    if (L.length == 0) return;

    int k = 0;
    for (int i = 0; i < L.length - 1; i++)
    {
        if (L.data[i] != L.data[i + 1])
        {
            L.data[k++] = L.data[i];
        }
    }

    L.data[k] = L.data[L.length - 1];
    L.length = k + 1;

    return;
}
```

### 二合一(不开新数组)

```cpp
void Merge(SqList &a, SqList &b)
{
    if (a.length + b.length > MaxSize) return;
    int i = a.length - 1;
    int j = b.length - 1;
    int k = a.length + b.length - 1;

    while (i >= 0 && j >= 0)
    {
        if (a.data[i] >= b.data[j])
        {
            a.data[k--] = a.data[i--];
        }
        else
        {
            a.data[k--] = b.data[j--];
        }
    }

    while (j >= 0)
    {
        a.data[k--] = b.data[j--];
    }

    a.length = a.length + b.length;
}
```

### 翻转

```cpp
void reverse(ElemType *a, int left, int right)
{
    while (left < right)
    {
        ElemType temp = a[left];
        a[left++] = a[right];
        a[right--] = temp;
    }
}
```

### 顺序表元素递增 完成用最少时间在表中查找数值为 $x$ 的元素 若找到则将其与后继元素位置相交换 若找不到 则将其插入表中并使表中元素仍然递增有序

```cpp
void LocateElem(ElemType *a, int &n, ElemType x)
{
    int low = 0, high = n - 1, mid;
    while (low <= high)
    {
        mid = (high - low) / 2 + low;
        if (a[mid] == x) break;
        else if (a[mid] > x)
        {
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    if (low <= high && mid != n - 1 && a[mid] == x)
    {
        ElemType temp = a[mid];
        a[mid] = a[mid + 1];
        a[mid + 1] = temp;
    }

    if (low > high)
    {
        for (int i = n - 1; i > high; i--) a[i + 1] = a[i];
        a[high + 1] = x;
        n++;
    }
}
```

### 在带头结点的单链表 $L$ 中，删除所有值为 $x$ 的结点 并释放其空间 假设值为 $x$ 的结点不唯一 试编写算法以实现上述操作

**答案：**

用指针 `p` 遍历数据结点，`pre` 始终指向 `p` 的前驱结点。若当前结点的值为 $x$，则修改前驱结点的指针，删除当前结点并释放空间；否则，两个指针一起后移。

```cpp
void deleteElem(LinkList &L, ElemType x)
{
    if (L == nullptr || L->next == nullptr) return;
    LNode *p = L->next;
    LNode *pre = L;
    while (p != nullptr)
    {
        if (p->data == x)
        {
            LNode *temp = p;
            pre->next = p->next;
            p = p->next;
            delete temp;
        }
        else
        {
            pre = p;
            p = p->next;
        }
    }
}
```

**关键：** 删除结点后，`pre` 保持不动，`p` 指向下一个待检查的结点，因此能够正确删除连续多个值为 $x$ 的结点。头结点保留，不参与值的比较。

**复杂度：** 设链表有 $n$ 个数据结点，遍历一次，时间复杂度为 $O(n)$；仅使用常数个辅助指针，空间复杂度为 $O(1)$。

**注意：** 结点由 `new` 创建，使用 `delete` 释放空间。

### 试编写算法将带头结点的单链表就地逆置，所谓“就地”是指辅助空间复杂度为 $O(1)$

**答案：**

采用头插法。先用 `p` 保存原链表的第一个数据结点，再将头结点的 `next` 置空。依次取出原链表中的结点，插入头结点之后，最终得到逆置的链表。

```cpp
LinkList reverse(LinkList L)
{
    if (L == nullptr || L->next == nullptr) return L;

    LNode *p = L->next;
    LNode *q;

    LNode *head = L;
    head->next = nullptr;

    while (p != nullptr)
    {
        q = p;
        p = p->next;

        q->next = head->next;
        head->next = q;
    }

    return head;
}
```

**关键：** 修改 `q->next` 之前，先让 `p` 指向原链表的下一个结点，避免丢失尚未处理的链表。`head` 与 `L` 指向同一个头结点，整个过程复用原有结点，不创建新结点。

**复杂度：** 设链表有 $n$ 个数据结点，每个结点处理一次，时间复杂度为 $O(n)$；仅使用常数个辅助指针，空间复杂度为 $O(1)$，满足就地逆置的要求。

### 给定两个单链表试分析找出两个链表的公共结点的思想

**答案：**

长度对齐，双指针同步前进，比较结点地址。

两个无环单链表若存在公共结点，则从第一个公共结点开始，后续结点全部共有，形成公共后缀。先分别遍历两个链表，求出长度；再让较长链表的指针先走长度差步，使两个指针到链尾的剩余结点数相同。随后两个指针同步向后移动，第一次指向同一个结点时，该结点就是第一个公共结点；若同时到达 `nullptr`，则没有公共结点。

**参考代码：**

```cpp
LNode* FindCommonNode(LinkList L1, LinkList L2)
{
    LNode *p = L1;
    LNode *q = L2;

    int lengthL1 = 0;
    int lengthL2 = 0;
    while (p != nullptr)
    {
        lengthL1++;
        p = p->next;
    }

    while (q != nullptr)
    {
        lengthL2++;
        q = q->next;
    }

    p = L1;
    q = L2;

    while (lengthL1 > lengthL2)
    {
        lengthL1--;
        p = p->next;
    }

    while (lengthL1 < lengthL2)
    {
        lengthL2--;
        q = q->next;
    }

    while (p != q)
    {
        p = p->next;
        q = q->next;
    }

    return q;
}
```

**关键：** 公共结点指两个链表共享的同一个结点，因此比较的是指针地址 `p == q`。仅有 `p->data == q->data` 不能说明是公共结点。长度对齐后，无公共结点时两个指针会同时变为 `nullptr`，循环结束并返回 `nullptr`。

**复杂度：** 设两个链表的长度分别为 $m$、$n$，时间复杂度为 $O(m+n)$，空间复杂度为 $O(1)$。

### **复用原结点与复制数据**

假设原链表为：

```text
L → 1 → 2 → 3 → nullptr
```

以下两段代码均为循环体片段，`p` 指向当前待处理的原链表结点。

#### **1. 破坏性操作：直接复用原结点（头插法）**

`head` 是目标链表的头结点，初始时 `head->next = nullptr`。

```cpp
LNode *temp = p;
p = p->next;

temp->next = head->next;
head->next = temp;
```

`temp = p` 只是让两个指针指向同一个结点，没有创建新结点。修改 `temp->next` 就会改变原结点的链接关系，因此原链表结构无法保持。必须先用 `p = p->next` 保存后续结点，再修改链接。

依次头插结点 1、2、3，目标链表为 `head → 3 → 2 → 1 → nullptr`。复用原结点，辅助空间复杂度为 $O(1)$。

#### **2. 非破坏性操作：复制数据，保留原链表（尾插法）**

目标链表带头结点 `head`，初始时 `head->next = nullptr`、`tail = head`。

```cpp
LNode *temp = new LNode;
temp->data = p->data;
temp->next = nullptr;

tail->next = temp;
tail = temp;

p = p->next;
```

`new LNode` 创建新结点，只把原结点的数据复制过来，不修改原结点的链接。`tail` 始终指向目标链表的尾结点。

依次尾插后，目标链表为 `head → 1 → 2 → 3 → nullptr`，原链表保持不变，两条链表的数据结点地址不同。复制 $n$ 个结点需要 $O(n)$ 的新结点存储空间；除输出链表外，辅助空间为 $O(1)$。

**记忆：** 是否破坏原链表，取决于是否复用并修改原结点；结果顺序则取决于插入方式，头插逆序，尾插保序。

### **单链表判环（必须记住：快慢指针法）**

单链表有环，是指单链表的最后一个结点的指针指向了链表中的某个结点（通常单链表的最后一个结点的指针域是空的）。试编写算法判断单链表是否存在环。

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明所设计的算法的时间复杂度和空间复杂度。

**答案：**

采用快慢指针法。令 `slow`、`fast` 都从 `L` 出发，慢指针每次走一步，快指针每次走两步。若存在环，两指针进入环后，快指针每轮相对慢指针多走一步，最终必然相遇；若不存在环，快指针会先到达链尾，循环结束。

```cpp
bool HasCycle(LinkList L)
{
    LNode *slow = L;
    LNode *fast = L;

    while (fast != nullptr && fast->next != nullptr)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
            return true;
    }

    return false;
}
```

**关键：** 循环条件先检查 `fast`，再检查 `fast->next`，保证快指针走两步时不会解引用空指针。两个指针初始时相等，因此必须先移动，再比较地址是否相等。

**复杂度：** 设从 `L` 出发能访问到的不同结点数为 $n$，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**必须记住：** 慢走一步，快走两步；先移动，后比较；相遇有环，到空无环。
