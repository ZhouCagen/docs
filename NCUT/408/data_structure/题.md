## 代码题

### 从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不同

**答案：**

```cpp
void deleteElem(SqList &L)
{
    if (L.length == 0) return;

    int k = 0;
    for (int i = 0; i < L.length - 1; i++)
    {
        if (L.data[i] != L.data[i + 1])
        {
            L.data[k++] = L.data[i];
        }
    }

    L.data[k] = L.data[L.length - 1];
    L.length = k + 1;

    return;
}
```

### 二合一(不开新数组)

```cpp
void Merge(SqList &a, SqList &b)
{
    if (a.length + b.length > MaxSize) return;
    int i = a.length - 1;
    int j = b.length - 1;
    int k = a.length + b.length - 1;

    while (i >= 0 && j >= 0)
    {
        if (a.data[i] >= b.data[j])
        {
            a.data[k--] = a.data[i--];
        }
        else
        {
            a.data[k--] = b.data[j--];
        }
    }

    while (j >= 0)
    {
        a.data[k--] = b.data[j--];
    }

    a.length = a.length + b.length;
}
```

### 翻转

```cpp
void reverse(ElemType *a, int left, int right)
{
    while (left < right)
    {
        ElemType temp = a[left];
        a[left++] = a[right];
        a[right--] = temp;
    }
}
```

### 顺序表元素递增 完成用最少时间在表中查找数值为 $x$ 的元素 若找到则将其与后继元素位置相交换 若找不到 则将其插入表中并使表中元素仍然递增有序

```cpp
void LocateElem(ElemType *a, int &n, ElemType x)
{
    int low = 0, high = n - 1, mid;
    while (low <= high)
    {
        mid = (high - low) / 2 + low;
        if (a[mid] == x) break;
        else if (a[mid] > x)
        {
            high = mid - 1;
        }
        else
        {
            low = mid + 1;
        }
    }

    if (low <= high && mid != n - 1 && a[mid] == x)
    {
        ElemType temp = a[mid];
        a[mid] = a[mid + 1];
        a[mid + 1] = temp;
    }

    if (low > high)
    {
        for (int i = n - 1; i > high; i--) a[i + 1] = a[i];
        a[high + 1] = x;
        n++;
    }
}
```

### 在带头结点的单链表 $L$ 中，删除所有值为 $x$ 的结点 并释放其空间 假设值为 $x$ 的结点不唯一 试编写算法以实现上述操作

**答案：**

用指针 `p` 遍历数据结点，`pre` 始终指向 `p` 的前驱结点。若当前结点的值为 $x$，则修改前驱结点的指针，删除当前结点并释放空间；否则，两个指针一起后移。

```cpp
void deleteElem(LinkList &L, ElemType x)
{
    if (L == nullptr || L->next == nullptr) return;
    LNode *p = L->next;
    LNode *pre = L;
    while (p != nullptr)
    {
        if (p->data == x)
        {
            LNode *temp = p;
            pre->next = p->next;
            p = p->next;
            delete temp;
        }
        else
        {
            pre = p;
            p = p->next;
        }
    }
}
```

**关键：** 删除结点后，`pre` 保持不动，`p` 指向下一个待检查的结点，因此能够正确删除连续多个值为 $x$ 的结点。头结点保留，不参与值的比较。

**复杂度：** 设链表有 $n$ 个数据结点，遍历一次，时间复杂度为 $O(n)$；仅使用常数个辅助指针，空间复杂度为 $O(1)$。

**注意：** 结点由 `new` 创建，使用 `delete` 释放空间。

### 试编写算法将带头结点的单链表就地逆置，所谓“就地”是指辅助空间复杂度为 $O(1)$

**答案：**

采用头插法。先用 `p` 保存原链表的第一个数据结点，再将头结点的 `next` 置空。依次取出原链表中的结点，插入头结点之后，最终得到逆置的链表。

```cpp
LinkList reverse(LinkList L)
{
    if (L == nullptr || L->next == nullptr) return L;

    LNode *p = L->next;
    LNode *q;

    LNode *head = L;
    head->next = nullptr;

    while (p != nullptr)
    {
        q = p;
        p = p->next;

        q->next = head->next;
        head->next = q;
    }

    return head;
}
```

**关键：** 修改 `q->next` 之前，先让 `p` 指向原链表的下一个结点，避免丢失尚未处理的链表。`head` 与 `L` 指向同一个头结点，整个过程复用原有结点，不创建新结点。

**复杂度：** 设链表有 $n$ 个数据结点，每个结点处理一次，时间复杂度为 $O(n)$；仅使用常数个辅助指针，空间复杂度为 $O(1)$，满足就地逆置的要求。

### 给定两个单链表试分析找出两个链表的公共结点的思想

**答案：**

长度对齐，双指针同步前进，比较结点地址。

两个无环单链表若存在公共结点，则从第一个公共结点开始，后续结点全部共有，形成公共后缀。先分别遍历两个链表，求出长度；再让较长链表的指针先走长度差步，使两个指针到链尾的剩余结点数相同。随后两个指针同步向后移动，第一次指向同一个结点时，该结点就是第一个公共结点；若同时到达 `nullptr`，则没有公共结点。

**参考代码：**

```cpp
LNode* FindCommonNode(LinkList L1, LinkList L2)
{
    LNode *p = L1;
    LNode *q = L2;

    int lengthL1 = 0;
    int lengthL2 = 0;
    while (p != nullptr)
    {
        lengthL1++;
        p = p->next;
    }

    while (q != nullptr)
    {
        lengthL2++;
        q = q->next;
    }

    p = L1;
    q = L2;

    while (lengthL1 > lengthL2)
    {
        lengthL1--;
        p = p->next;
    }

    while (lengthL1 < lengthL2)
    {
        lengthL2--;
        q = q->next;
    }

    while (p != q)
    {
        p = p->next;
        q = q->next;
    }

    return q;
}
```

**关键：** 公共结点指两个链表共享的同一个结点，因此比较的是指针地址 `p == q`。仅有 `p->data == q->data` 不能说明是公共结点。长度对齐后，无公共结点时两个指针会同时变为 `nullptr`，循环结束并返回 `nullptr`。

**复杂度：** 设两个链表的长度分别为 $m$、$n$，时间复杂度为 $O(m+n)$，空间复杂度为 $O(1)$。

### **复用原结点与复制数据**

假设原链表为：

```text
L → 1 → 2 → 3 → nullptr
```

以下两段代码均为循环体片段，`p` 指向当前待处理的原链表结点。

#### **1. 破坏性操作：直接复用原结点（头插法）**

`head` 是目标链表的头结点，初始时 `head->next = nullptr`。

```cpp
LNode *temp = p;
p = p->next;

temp->next = head->next;
head->next = temp;
```

`temp = p` 只是让两个指针指向同一个结点，没有创建新结点。修改 `temp->next` 就会改变原结点的链接关系，因此原链表结构无法保持。必须先用 `p = p->next` 保存后续结点，再修改链接。

依次头插结点 1、2、3，目标链表为 `head → 3 → 2 → 1 → nullptr`。复用原结点，辅助空间复杂度为 $O(1)$。

#### **2. 非破坏性操作：复制数据，保留原链表（尾插法）**

目标链表带头结点 `head`，初始时 `head->next = nullptr`、`tail = head`。

```cpp
LNode *temp = new LNode;
temp->data = p->data;
temp->next = nullptr;

tail->next = temp;
tail = temp;

p = p->next;
```

`new LNode` 创建新结点，只把原结点的数据复制过来，不修改原结点的链接。`tail` 始终指向目标链表的尾结点。

依次尾插后，目标链表为 `head → 1 → 2 → 3 → nullptr`，原链表保持不变，两条链表的数据结点地址不同。复制 $n$ 个结点需要 $O(n)$ 的新结点存储空间；除输出链表外，辅助空间为 $O(1)$。

**记忆：** 是否破坏原链表，取决于是否复用并修改原结点；结果顺序则取决于插入方式，头插逆序，尾插保序。

### **单链表判环（必须记住：快慢指针法）**

单链表有环，是指单链表的最后一个结点的指针指向了链表中的某个结点（通常单链表的最后一个结点的指针域是空的）。试编写算法判断单链表是否存在环。

1. 给出算法的基本设计思想。
2. 根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
3. 说明所设计的算法的时间复杂度和空间复杂度。

**答案：**

采用快慢指针法。令 `slow`、`fast` 都从 `L` 出发，慢指针每次走一步，快指针每次走两步。若存在环，两指针进入环后，快指针每轮相对慢指针多走一步，最终必然相遇；若不存在环，快指针会先到达链尾，循环结束。

```cpp
bool HasCycle(LinkList L)
{
    LNode *slow = L;
    LNode *fast = L;

    while (fast != nullptr && fast->next != nullptr)
    {
        slow = slow->next;
        fast = fast->next->next;

        if (slow == fast)
            return true;
    }

    return false;
}
```

**关键：** 循环条件先检查 `fast`，再检查 `fast->next`，保证快指针走两步时不会解引用空指针。两个指针初始时相等，因此必须先移动，再比较地址是否相等。

**复杂度：** 设从 `L` 出发能访问到的不同结点数为 $n$，时间复杂度为 $O(n)$，空间复杂度为 $O(1)$。

**必须记住：** 慢走一步，快走两步；先移动，后比较；相遇有环，到空无环。
