# 1.2 操作系统的发展与分类

## 1.2.1 手工操作阶段

### 1. 人工操作方式

用户手工完成程序的装入、运行等操作。

**缺点：**

- **用户独占全机**：一名用户使用时，其他用户只能等待。
- **人机速度矛盾**：人工操作慢，计算机运行快，导致计算机大量时间处于等待状态，资源利用率低。

### 2. 脱机 I/O 方式

利用外围机完成输入、输出准备工作，减少主机等待人工操作和慢速设备的时间。

> **“脱机”指输入、输出准备工作脱离主机进行，不是断开网络。**

## 1.2.2 批处理阶段

作业成批送入系统，由**监督程序**控制，自动、依次处理，减少人工干预。

### 1. 单道批处理系统

**特点：**内存中一次只有一道作业运行。

- **优点**：作业自动连续处理，减少作业之间的人工操作时间。
- **缺点**：程序进行 I/O 时，CPU 只能等待，资源利用率仍然较低。

### 2. 多道批处理系统

**特点：**内存中同时存放多道程序，并发执行、共享资源。

一道程序等待 I/O 时，CPU 可以转去执行另一道程序。

- **优点**：CPU 与 I/O 设备可并行工作，提高资源利用率和系统吞吐量。
- **缺点**：用户提交作业后不能直接干预运行，**缺乏人机交互，作业周转时间较长**。

> **单道：一道程序等待 I/O，CPU 跟着等。**
>
> **多道：一道程序等待 I/O，CPU 可以执行其他程序。**

## 1.2.3 分时操作系统

计算机以**时间片**为单位，轮流为各个用户或作业服务。

由于轮转速度快，每个用户都感觉自己在独立使用计算机。

- **优点**：用户请求能够得到及时响应，解决了人机交互问题。
- **不足**：不能保证紧急任务在规定期限内完成。

**主要特点：**

- **同时性**：多个用户可同时使用系统。
- **交互性**：用户可以在运行过程中与系统交互。
- **独立性**：用户操作相互独立，感觉像独占计算机。
- **及时性**：用户请求能在较短时间内得到响应。

## 1.2.4 实时操作系统

在事件或数据产生时及时处理，并在**规定期限内**完成任务。

**主要特点：及时性、可靠性。**

| 类型           | 对时间的要求                   |
| -------------- | ------------------------------ |
| **硬实时系统** | 必须在严格的规定期限内完成任务 |
| **软实时系统** | 允许偶尔违反时间规定           |

> **分时系统强调及时响应、方便交互；实时系统强调在规定期限内完成任务。**

## 1.2.5 网络操作系统和分布式操作系统

### 1. 网络操作系统

将多台计算机通过网络连接起来，实现：

- **资源共享**，如文件共享。
- **计算机之间的通信**。

各台计算机仍具有较强的独立性。

### 2. 分布式操作系统

将多台计算机统一管理、协调工作，对用户呈现为一个整体。

**主要特点：分布性、并行性。**

任务可以分配到不同计算机上，由它们并行、协调完成，用户通常不必关心任务具体在哪台计算机上执行。

> **网络操作系统侧重“联网、通信、共享”；分布式操作系统侧重“统一管理、协同完成任务”。**
