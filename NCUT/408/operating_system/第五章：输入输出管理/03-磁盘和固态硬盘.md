# 5.3 磁盘和固态硬盘

## 5.3.1 磁盘

### 一、基本结构

| 概念 | 含义                       | 易混点                                             |
| ---- | -------------------------- | -------------------------------------------------- |
| 盘片 | 涂有磁性材料的圆盘         | 一张盘片可有两个有效记录面，实际有效面数以题设为准 |
| 盘面 | 盘片上可记录数据的一面     | 通常每个有效盘面对应一个磁头                       |
| 磁道 | 盘面上的同心圆记录区域     | 磁头沿径向移动以选择磁道                           |
| 扇区 | 磁道划分出的固定大小区域   | 磁盘寻址和物理数据组织的基本单位                   |
| 柱面 | 各盘面上半径相同的磁道集合 | 访问同一柱面的不同盘面通常不必径向移动磁头臂       |

多盘面的磁头安装在同一磁头臂组件上，同步径向移动。传统物理地址表示为：**柱面号 + 盘面号（磁头号）+ 扇区号**。

读写过程：**移动到目标柱面 → 选择目标盘面的磁头 → 等待目标扇区旋转到磁头下 → 传输数据**。

**一个磁道放不下连续数据时，优先考虑同一柱面的其他盘面，以减少寻道；换磁头仍可能需要少量切换时间。**

### 二、容量计算

设柱面数为 $C$，有效盘面数为 $H$，每磁道扇区数为 $S$，每扇区数据区大小为 $B$ 字节。在各磁道扇区数相同的模型中：

$$
\boxed{\text{磁盘容量}=C\times H\times S\times B}
$$

例：1024 个柱面、4 个有效盘面、每磁道 128 个扇区、每扇区 512 B：

$$
1024\times4\times128\times512=2^{28}\text{ B}=256\text{ MiB}
$$

**柱面数等于单个盘面的磁道数；不要再把柱面数乘成全部盘面的磁道总数后重复乘盘面数。**

教材传统模型每磁道扇区数相同，因此外道线性记录密度较低。区域记录 **ZBR** 将盘面划为若干环带，外层环带的每磁道扇区数更多；这时容量应分环带求和，不能套用统一的 $S$。

### 三、逻辑扇区号与物理地址换算

在每磁道 $S$ 个扇区、每柱面 $H$ 个盘面的简单线性排列中，设逻辑扇区号 $L$ 从 0 开始，柱面号与磁头号从 0 开始，物理扇区号从 1 开始：

$$
c=\lfloor L/(HS)\rfloor
$$

$$
h=\lfloor L/S\rfloor-Hc
$$

$$
s=L-S\lfloor L/S\rfloor+1
$$

其中 $\lfloor x\rfloor$ 表示向下取整。计算顺序：**先求柱面号，再求该柱面内的磁头号，最后用除以每磁道扇区数的余数加 1，得到扇区号。** 上式用减法表达取余，避免取模命令的渲染兼容问题。

反算：

$$
L=(cH+h)S+(s-1)
$$

例：$H=4$、$S=8$、$L=37$，得到柱面 1、磁头 0、扇区 6。

若每簇含 $q$ 个扇区，簇号为 $k$，还需先按题设起点换算：

$$
L=L_0+(k-k_0)q+\delta
$$

其中 $L_0$ 是数据区起始逻辑扇区号，$k_0$ 是数据区首簇编号，$\delta$ 是簇内扇区偏移。**不能默认簇号就是整盘扇区号，也不能忽略分区和数据区起点。**

### 四、磁盘分类

- **固定头磁盘**：每个磁道配置磁头，无须通过磁头径向移动选道。
- **活动头磁盘**：通过移动磁头臂选择磁道。
- **固定盘磁盘**：盘片固定在驱动器内。
- **可换盘磁盘**：盘片可拆卸、更换。

“固定头 / 活动头”描述磁头是否移动；“固定盘 / 可换盘”描述盘片能否更换，是两个分类维度。

## 5.3.2 磁盘的管理

### 一、初始化、分区与格式化

教材典型顺序：**低级格式化 → 分区 → 逻辑格式化 → 建立并使用文件系统**。

| 阶段       | 又称       | 主要工作                                                             |
| ---------- | ---------- | -------------------------------------------------------------------- |
| 低级格式化 | 物理格式化 | 划分物理扇区，建立头部、数据区、尾部及校验信息等，通常由制造过程完成 |
| 分区       | —          | 将磁盘划分为逻辑区域，记录各区域的起始位置与大小                     |
| 逻辑格式化 | 高级格式化 | 在分区中建立文件系统，初始化根目录、空闲空间管理等结构               |

**划分扇区是物理格式化；建立文件系统是逻辑格式化；分区是另一步。**

文件系统可把若干连续扇区组成一个**簇 / 分配块**，以簇为单位分配空间，减少管理开销。非空小文件通常也至少占一个分配单位；是否为零字节文件分配数据簇取决于具体文件系统，不能一概而论。

### 二、引导块

启动时，固件中的初始程序加载后续引导代码，后者定位并装入操作系统。

教材的传统 **BIOS + MBR** 模型：

```text
固件中的初始程序 → 磁盘 0 号扇区的 MBR
               → 根据分区表定位活动分区
               → 分区引导块 → 后续引导程序 → 操作系统内核
```

MBR 包含引导代码、分区表等信息。**上述流程是传统引导模型，不应当作所有硬件和所有启动方式的统一规则。**

### 三、坏块处理

- **软件标记**：操作系统 / 文件系统将坏块标为不可用，避免分配。
- **控制器重映射**：控制器维护坏块表，将坏扇区替换为备用扇区，对上层保持逻辑地址不变。

**坏块处理的目标是避免继续使用损坏区域，并非把损坏的物理介质恢复如初。**

## 5.3.3 磁盘调度算法

### 一、磁盘存取时间（计算重点）

一次读写通常分为三部分：

$$
\boxed{T_a=T_s+T_r+T_t}
$$

| 时间           | 含义                 | 教材公式及条件                                                              |
| -------------- | -------------------- | --------------------------------------------------------------------------- |
| 寻道时间 $T_s$ | 磁头移动到目标磁道   | 线性近似 $T_s=mn+s$；$m$ 为跨一条磁道耗时，$n$ 为移动磁道数，$s$ 为启动时间 |
| 旋转延迟 $T_r$ | 等目标扇区转到磁头下 | 平均为半圈：$T_r=1/(2r)$，$r$ 的单位为转 / 秒                               |
| 传输时间 $T_t$ | 实际读写数据         | $T_t=b/(rN)$；$b$ 为传输字节数，$N$ 为每磁道字节数                          |

于是：

$$
\boxed{T_a=mn+s+\frac{1}{2r}+\frac{b}{rN}}
$$

此式使用平均旋转延迟，忽略控制器开销、排队等待及额外换道等代价；跨磁道读取时需按题意补充相应时间。

#### 转速换算

若转速为 $v$ rpm（转 / 分），则：

$$
r=\frac{v}{60},\qquad T_{\text{一圈}}=\frac{60}{v}\text{ s},\qquad
\overline{T_r}=\frac{30}{v}\text{ s}
$$

例：5400 rpm = 90 转 / 秒，一圈约 11.11 ms，平均旋转延迟约 5.56 ms。

#### 综合例题

磁盘转速 7200 rpm，每磁道 120 个扇区，每扇区 512 B，平均寻道时间为 5 ms，随机读取一个扇区：

$$
r=120\text{ 转/s},\quad T_r=\frac{1}{240}\text{ s}\approx4.167\text{ ms}
$$

$$
T_t=\frac{512}{120\times120\times512}\text{ s}\approx0.0694\text{ ms}
$$

$$
T_a\approx5+4.167+0.0694=9.24\text{ ms}
$$

**平均旋转延迟是半圈，不是一圈；寻道找磁道，旋转找扇区，传输才是实际搬数据。**

### 二、调度的主要目标

多个磁盘请求等待时，系统选择服务顺序。传统机械磁盘中寻道开销通常较大，因此调度主要通过**减少磁头移动，降低平均寻道时间**改善性能。

若初始位置为 $x_0$，移动路径为 $x_1,\ldots,x_k$：

$$
D=\sum_{i=1}^{k}|x_i-x_{i-1}|,\qquad
\text{平均寻道长度}=\frac{D}{\text{实际请求数}}
$$

**磁道端点和回扫起点可能只是途经位置，不算额外请求；平均寻道长度的单位是磁道，不是毫秒。**

### 三、六种常用调度规则

| 算法   | 选择规则                                               | 优点                           | 局限                                 |
| ------ | ------------------------------------------------------ | ------------------------------ | ------------------------------------ |
| FCFS   | 按请求到达顺序服务                                     | 简单、按到达顺序公平           | 磁头可能频繁往返，平均移动距离较大   |
| SSTF   | 每次选距当前位置最近的请求                             | 通常比 FCFS 寻道更短           | 贪心选择不保证全局最优；可能饥饿     |
| SCAN   | 沿当前方向服务，到磁盘端点后反向                       | 类似电梯，缓解 SSTF 的饥饿问题 | 刚被扫过的区域需等下一轮，等待不均匀 |
| C-SCAN | 只沿一个方向服务，到端点后回到另一端，回程不服务       | 等待时间分布更均匀             | 回扫仍有移动开销                     |
| LOOK   | 沿当前方向服务，到该方向最远请求处就反向               | 减少无请求区间的移动           | 仍需给定初始方向                     |
| C-LOOK | 单向服务，到最远请求后回到另一侧最远请求处，回程不服务 | 避免到物理端点的额外移动       | 返回路程通常仍计入距离               |

**SCAN / C-SCAN 看磁盘端点；LOOK / C-LOOK 看最远请求。** 有的题目将改进实现也称 SCAN，应以题目给出的规则为准，不能只凭名称猜端点处理方式。

### 四、同一请求序列的完整计算

教材请求序列：

```text
55，58，39，18，90，160，150，38，184
```

初始磁头位于 100，磁道范围为 **0～200（含端点）**。扫描类算法初始向磁道号增大的方向移动。请求均已到达，全部完成即停止计数；循环返回的移动距离计入总距离。

| 算法   | 磁头移动路径（包含初始位置和必要端点）                            | 总移动距离 | 平均寻道长度        |
| ------ | ----------------------------------------------------------------- | ---------- | ------------------- |
| FCFS   | 100 → 55 → 58 → 39 → 18 → 90 → 160 → 150 → 38 → 184               | 498        | $498/9\approx55.33$ |
| SSTF   | 100 → 90 → 58 → 55 → 39 → 38 → 18 → 150 → 160 → 184               | 248        | $248/9\approx27.56$ |
| SCAN   | 100 → 150 → 160 → 184 → **200** → 90 → 58 → 55 → 39 → 38 → 18     | 282        | $282/9\approx31.33$ |
| C-SCAN | 100 → 150 → 160 → 184 → **200 → 0** → 18 → 38 → 39 → 55 → 58 → 90 | 390        | $390/9\approx43.33$ |
| LOOK   | 100 → 150 → 160 → 184 → 90 → 58 → 55 → 39 → 38 → 18               | 250        | $250/9\approx27.78$ |
| C-LOOK | 100 → 150 → 160 → 184 → 18 → 38 → 39 → 55 → 58 → 90               | 322        | $322/9\approx35.78$ |

按单调区间分段计算更简洁：

$$
D_{\text{SCAN}}=(200-100)+(200-18)=282
$$

$$
D_{\text{C-SCAN}}=(200-100)+(200-0)+(90-0)=390
$$

$$
D_{\text{LOOK}}=(184-100)+(184-18)=250
$$

$$
D_{\text{C-LOOK}}=(184-100)+(184-18)+(90-18)=322
$$

**“回程不服务”不表示“回程距离为 0”。** 若题目明确忽略回程耗时或路程，才按题设另算。

#### 做题步骤

1. 写清磁头初始位置、扫描方向、磁道上下界。
2. 确认是静态请求队列还是有新请求不断到达。
3. 按算法列出服务顺序及必要的途经端点。
4. 求相邻位置差的绝对值之和。
5. 除以实际请求数；若要求时间，再使用题给的寻道模型。

SSTF 距离相同时按题设规则选择；未规定时说明自己的约定。

### 五、N-step-SCAN 与 FSCAN

若不断把新到达的局部请求加入当前服务集合，磁头可能长时间停留在某个区域，称为**磁臂黏着**。解决思路是冻结本轮服务集合，延后新请求。

| 算法        | 做法                                                   | 关键点                                                       |
| ----------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| N-step-SCAN | 按到达顺序分成长度至多为 $N$ 的子队列，队列内部用 SCAN | 新请求不插入正在处理的子队列；$N=1$ 时服务顺序退化为 FCFS    |
| FSCAN       | 使用当前服务队列和新请求队列                           | 当前队列用 SCAN 扫描，新请求加入另一队列；一轮完成后交换角色 |

### 六、减少旋转延迟

#### 1. 扇区交替编号

读取一个扇区后，控制器可能需要处理时间。若逻辑下一扇区紧挨着它，处理完时下一扇区可能已经转过磁头，只能再等一圈。

交替编号让**逻辑相邻扇区在物理位置上适当间隔**，使下一目标扇区在处理结束后到达磁头下。

#### 2. 盘面错位命名

切换磁头也需要时间。将不同盘面的扇区编号起点适当错开，使上一盘面读完并切换磁头后，下一盘面的目标扇区恰好接近磁头位置。

**交替编号解决同一磁道内的处理间隔；盘面错位命名解决跨盘面的切换间隔。** 二者都不改变磁盘转速。

### 七、提高磁盘 I/O 速度的方法

| 方法           | 改善点                                         |
| -------------- | ---------------------------------------------- |
| 磁盘高速缓存   | 命中时减少实际磁盘访问                         |
| 调整请求顺序   | 通过调度减少寻道                               |
| 提前读         | 利用空间局部性，预取后续可能访问的数据块       |
| 延迟写         | 合并多次修改，减少写盘次数；需在规定时机写回   |
| 优化物理块分布 | 尽量集中相关数据，减少换道与旋转等待           |
| RAM 盘         | 用内存模拟磁盘，适合临时数据；普通内存断电丢失 |
| 磁盘阵列 RAID  | 部分组织方式可通过多盘并行提高吞吐率           |

**磁盘高速缓存是由系统管理的缓存内容；RAM 盘是应用可像磁盘一样使用的存储空间。** 延迟写时“写入内存成功”不等于“已经持久写入磁盘”。

## 5.3.4 固态硬盘（SSD）

### 一、结构与基本特性

SSD 使用闪存保存数据，没有机械磁头和旋转盘片。教材抽象结构为：**闪存翻译层 FTL + 闪存芯片**。

```text
主机发出逻辑块读写请求
    → FTL（维护逻辑地址到物理闪存位置的映射）
    → 闪存块
        → 多个闪存页
```

**闪存页是这里的存储组织单位，不要与虚拟内存中的页直接混同。**

| 对比项       | 机械磁盘 HDD           | 固态硬盘 SSD                               |
| ------------ | ---------------------- | ------------------------------------------ |
| 存储介质     | 磁性盘片               | 非易失性闪存                               |
| 定位方式     | 寻道、旋转定位         | 电子寻址，无机械寻道和旋转延迟             |
| 随机访问     | 受机械定位开销影响明显 | 随机读取延迟通常较低                       |
| 写入特点     | 无闪存式擦除块约束     | 写前须有已擦除空间，更新涉及地址映射和回收 |
| 耐用性关注点 | 机械部件及介质故障     | 擦写寿命有限，需管理磨损                   |
| 其他特点     | 有机械运动与噪声       | 无机械噪声，抗震性较好                     |

SSD 仍有控制器处理、排队和传输时间，**没有机械寻道不等于访问时间为 0**；以减少磁头移动为目标的传统调度不再直接适用。

### 二、页读写、块擦除

闪存组织为块，每个块含多个页：

- **读 / 写（编程）的基本单位：页。**
- **擦除的基本单位：块。**
- 已写入页不能像普通 RAM 那样任意原地覆盖；重复使用其空间前需擦除所属块。
- 块的擦写次数有限，反复使用少数块会造成磨损不均。

**本节的闪存“块”是擦除单位，不必等于操作系统看到的逻辑块大小。**

### 三、更新数据与垃圾回收

典型更新过程：

1. 在已擦除的空闲页中写入新数据。
2. FTL 修改逻辑地址映射，使该逻辑页指向新位置。
3. 将旧位置标记为失效，等待后续回收。
4. 回收某块时，先将其中仍有效的页迁到其他位置，再擦除整块供以后使用。

**修改一页不一定立即搬迁其整个块；搬迁有效页、整块擦除通常是垃圾回收的一部分。**

随机写入往往比读取复杂，因为更新可能引入额外迁移、擦除与映射维护。实际写入闪存的数据量可能大于主机提交的数据量，称为**写放大**：

$$
\text{写放大系数}=\frac{\text{实际写入闪存的数据量}}{\text{主机提交的写入数据量}}
$$

### 四、磨损均衡（Wear Leveling）

目标：**让擦写负担尽量分散到不同物理块，避免少数块提前耗尽寿命**。它不增加单个闪存单元本身的擦写上限。

| 类型         | 做法                                                               | 覆盖范围                         |
| ------------ | ------------------------------------------------------------------ | -------------------------------- |
| 动态磨损均衡 | 为新写入选择合适的空闲块，优先使用擦写次数较少者                   | 主要在参与新写入的空闲块之间均衡 |
| 静态磨损均衡 | 还迁移长期不变的冷数据，使原本被冷数据占用的低磨损块也参与后续写入 | 将冷数据所在块纳入均衡范围       |

理解静态均衡：**冷数据长期占着低磨损块，会让其他块反复承受写入；可将冷数据迁往较高磨损但仍可用的块，腾出低磨损块承担后续频繁写入。** 重点是冷数据也会迁移，不要只背某个固定的迁移方向。

### 五、寿命估算的条件

在忽略写放大、备用空间及其他损耗的理想模型下：

$$
\text{累计写入量}\approx\text{可用容量}\times\text{平均可擦写次数}
$$

若写放大系数为 $A$，可粗略估算：

$$
\text{主机可写入总量}\approx
\frac{\text{参与均衡的闪存容量}\times\text{平均可擦写次数}}{A}
$$

**这是简化计算模型，不是实际硬盘寿命保证。** 计算时应统一 GB / TB 或 GiB / TiB 的换算体系，不能混用十进制和二进制单位。

## 易混点速记

- **柱面：各盘面同半径磁道的集合；同柱面换盘面通常不需重新寻道。**
- **物理格式化划扇区，逻辑格式化建文件系统。**
- **存取时间 = 寻道 + 旋转延迟 + 传输；平均旋转延迟为半圈。**
- **SSTF 是局部贪心，不保证最优，也可能饥饿。**
- **SCAN 到端点，LOOK 到最远请求；循环扫描回程不服务，但通常仍计移动距离。**
- **SSD 按页读写、按块擦除；FTL 维护地址映射。**
- **磨损均衡延长整体可用寿命，不提高单个单元的擦写上限。**
